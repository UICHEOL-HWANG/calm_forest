# 게이트형 분석 진행

이 프로젝트에서 분석이 실패하는 방식은 정해져 있다. **한 턴에 EDA부터 모델까지 달려가서,
사람이 읽을 수 없는 결과 덩어리를 남긴다.** 분석이 틀려서가 아니라 전달되지 않아서 실패한다.

그래서 여기서는 분석을 **게이트**로 끊는다. 각 게이트는 끝에서 반드시 멈춘다.

## 절대 규칙 4개

### 0. 가설은 혼자 쓰지 않는다
Claude 는 근거(실측 숫자)와 반증 조건을 붙인 **후보**를 낼 뿐이다.
채택·기각·문구 수정은 사용자와의 대화로 정한다.

- **후보는 한 번에 하나씩** 제시한다. 7개를 표로 던지고 "고르세요"는 위반이다 —
  그게 바로 읽기 어려운 덩어리를 넘기는 행동이다.
- 합의된 것만 가설표에 올린다.
- 합의 전에 가설을 전제로 다음 게이트를 시작하지 않는다.

### 1. 한 턴에 게이트 하나
승인 없이 다음 게이트를 시작하지 않는다. **"이어서 G3도 해봤습니다"는 위반이다.**
게이트가 빨리 끝났어도 멈춘다. 남는 시간에 다음 게이트를 하는 게 아니라, 이번 게이트를 더 잘 전달한다.

### 2. 통과/기각 기준은 게이트를 시작하기 전에 적는다
결과를 보고 기준을 만들면 p-hacking 이다. **기각도 정상적인 결과다.**
`docs/CHURN_ANALYSIS_PLAN.md` §5 의 사전 기준은 결과가 나빠도 고치지 않는다.

### 3. 산출물 구조는 고정
`plain-analysis-report` 스킬의 구조를 그대로 쓴다:

```
한 줄 답                     ← 물은 것에 먼저 답한다
(차트 + 쉬운 말 설명 + 그 숫자를 만든 코드) × 논점 수
그래서 크기가 얼마나 되나      ← 원래 단위 · 양 끝 비교 · 설명력
이 숫자로 말할 수 없는 것      ← 비우지 않는다
다음에 확인할 것
```

**마지막 두 절을 비우면 그 산출물은 미완성이다.**

## 게이트

| | 게이트 | 끝났다는 뜻 |
|---|---|---|
| G0 | 가설 확정 | 사용자가 가설표에 서명 |
| G1 | 데이터 신뢰성 | 함정 점검 전부 초록 또는 한계로 문서화 |
| G2 | EDA | 분포·단변량 비교까지. **모델이 학습돼 있으면 실패** |
| G3 | 피처·라벨 파이프라인 | 재실행 시 동일 표본, 누수 테스트 통과 |
| G4 | 베이스라인 | 다수 클래스 + 단일 피처 두 개 |
| G5 | 모델·검증 | 사전 기준으로 채택/보류/기각 판정 |
| G6 | 적용 | 별도 기획 |

## 게이트마다 하는 일

1. **시작 전** — 이번 게이트의 통과/기각 기준을 한 줄로 적는다.
2. **작업** — 아래 스킬을 로드해서 쓴다.
   - 질문 하나를 처리하는 실행 루프 → **`analysis-step`** (쿼리→결과→차트 PNG→한계→멈춤)
   - G2 → `eda-analyst` (SRK 7단계)
   - 모든 산출물 → `plain-analysis-report` + 차트 전 `dataviz`
   - Artifact 페이지 → `artifact-design`
3. **W&B 런 1개** — `calm_ml.tracking.start_run(f"g{n}-<슬러그>", tags=["gate"])`.
   모델 실험뿐 아니라 G1·G2 의 표본 수·라벨 분포도 남긴다. 나중에
   "언제 기준이 바뀌었나"를 추적할 수 있는 유일한 방법이다.
4. **Artifact 1장 발행** — 게이트당 한 장. 링크를 사용자에게 준다.
5. **원장 갱신** — `docs/ANALYSIS_GATES.md` 에 상태·날짜·링크·런 이름.
6. **멈춘다.**

## 이 프로젝트에서 반드시 지킬 것

- **분석 원천은 BigQuery 다.** `calm_ml.bq`. Supabase(`calm_ml.db`)는 7일만 보관해서
  리텐션·이탈을 재면 조용히 틀린 숫자가 나온다.
- **사람 단위 키는 `client_id`**(BQ) / `user_pseudo_id`(GA4). **`user_id` 금지** —
  익명 auth uid 가 세션마다 재발급돼 기기 237대가 uid 604개로 부풀었다.
- **표본 정의는 `ml/sql/churn_sample.sql` 한 곳에만.** 노트북에 쿼리를 복사하면 갈라진다.
- **차트는 `calm_ml.report`** 로 그린다. 한글 폰트·마이너스 글리프·팔레트·n 표기를 강제한다.
- **렌더된 PNG 를 실제로 열어본다.** 코드가 성공해도 라벨은 겹친다. 선택이 아니다.
- **`session_logs` 는 upsert 라 BQ 에 중복 존재** → `ROW_NUMBER() … = 1` 로 최신행만.
- **`variant` 컬럼은 현재 분석 불가** (`i18n.js:detectLang()` 이 한국어 브라우저를
  `assignVariant()` 앞에서 걸러 양쪽이 같은 화면을 봄). A/B 결론을 내지 않는다.
- **베타 유급 테스터 10명은 이탈 지표의 표본이 아니다.** 돈 받고 일주일 하기로 한 사람은
  이탈하지 않는다. 모델 학습·검증에 쓰지 않고, 적용·관찰 대상으로만 쓴다.
