# 데이터 질문 하나 처리하기

사용자가 수치를 물었을 때의 순서다. **한 번에 한 질문만** 처리하고 멈춘다.

## 순서

### 1. 쿼리를 먼저 보여준다
돌리기 전에 SQL 을 채팅에 낸다. 주석으로 왜 그렇게 걸렀는지 적는다.
특히 **무엇을 제외했고 왜 제외했는지**를 적는다. 제외 기준이 결과를 만든다.

### 2. 돌리고 결과를 보여준다
원시 수치를 먼저 낸다. 해석은 그다음이다.

### 3. 차트를 그린다
- `calm_ml.report` 를 쓴다. 한글 폰트·마이너스 글리프·검증 팔레트·n 표기가 강제된다
- **저장한 PNG 를 Read 로 직접 열어본다.** 선택이 아니다
- `SendUserFile` 로 보낸다. 경로만 알려주지 않는다
- 차트 코드도 같이 보여준다

### 4. 읽은 것을 적는다
```
한 줄 답            ← 물은 것에 먼저 답한다
크기                ← 원래 단위 · 양 끝 비교 · 전체 중 비중
이 숫자로 말할 수 없는 것   ← 비우지 않는다
```

### 5. 멈춘다
"여기서 멈추겠습니다"로 끝낸다. 다음에 볼 만한 것을 **적기만** 하고 고르지 않는다.

## 하지 않는 것

| | |
|---|---|
| **모델링** | 명시적으로 시키기 전까지 절대. 학습·예측·피처중요도 전부 |
| **다음 질문 미리 하기** | 시간이 남아도 안 한다. 남는 시간엔 이번 답을 더 잘 전달한다 |
| **선택지 기울이기** | A에 이유 셋, B에 치명타 하나로 적으면 고르라는 게 아니라 답을 정해놓은 것이다. 양쪽에 같은 무게로 쓴다 |
| **위젯으로 가짜 의논** | 다 써놓고 승인 버튼만 누르게 하는 건 의논이 아니다 |
| **차트 여러 장 합치기** | 논점 하나에 차트 하나, 따로 보낸다 |

## 이번 프로젝트에서 실제로 틀렸던 것 (반복 금지)

### 집계 카테고리에 이름을 붙이기 전에 안을 열어본다
`login` 이 마지막 행동인 32대를 **"로그인만 하고 끝"** 이라고 라벨했다. 틀렸다.
32대 전부가 다른 행동을 이미 했고, 로그인만 한 기기는 0대였다.
`login` 이 재방문 시 자동 발화하는 이벤트였기 때문이다.

> 막대에 이름을 붙이기 전에 그 막대 안의 기기가 실제로 뭘 했는지 한 번 조회한다.

### 지표 요약을 보고 그 지표가 뭘 재는지 다시 확인한다
`span_sec` 중앙값이 3,249초로 나왔는데 최대가 880,382초(10일)였다.
한 방문의 체류시간이 아니라 첫 방문부터 마지막까지의 간격이었다.
**분포가 이상하면 해석하기 전에 정의를 다시 본다.**

### 렌더를 열어보면 코드가 성공해도 그림은 깨져 있다
이번에 실제로 잡은 것 넷: 한글 세로축이 90도로 누워 읽기 어려움 ·
축 이름이 부제와 겹침 · 가로막대인데 수량 축 이름을 세로축에 붙임 · 축이 `0.31` 로 나옴(→ `31%`).

### 절대 수와 비율을 둘 다 본다
절대 수는 제일 큰 덩어리가 다 먹어서 나머지가 안 보인다.
비율로 바꾸면 순위가 통째로 바뀐다. 둘 다 내고 어느 쪽 그림인지 밝힌다.

### 분자가 한 자리수면 신뢰구간을 붙인다
윌슨 구간을 가로선으로 같이 그린다. **구간이 겹치는 항목끼리는 순위를 말하지 않는다.**
제목에 "~만 눈에 띄게 높다"고 쓰기 전에 2위와 구간이 겹치는지 본다.

### 틀린 걸 발견하면 그 자리에서 정정하고 기록에 남긴다
채팅에서만 정정하고 노트북에서 지우면, 나중에 그 노트북을 읽는 사람이 같은 오답을 다시 집는다.
**정정 절을 노트북에 남긴다.**

## 노트북에 기록하기

질문 몇 개가 쌓이면 `ml/notebooks/` 에 정리한다.

- 쿼리·결과·차트·해석이 한 흐름으로 이어지게 쓴다
- 차트는 `R.show(R.save(...))` 로 **인라인으로 박는다.** 경로만 남으면 나중에 열었을 때 그림이 없다
- `nbconvert --execute --inplace` 로 돌려서 출력을 넣고, 에러 0·차트 수를 확인한다
- 채팅에서 말한 숫자와 노트북 출력이 일치하는지 대조한다

### 한국어는 이렇게 쓴다
`습니다` 단조 반복 대신 평서체로 리듬을 바꾼다. 아래는 빼거나 줄인다.

- 번역투 — `~을 통해`, `~에 대해`, `~에 있어서`, `~가지고 있다`, `~되어진다`, `~에 의해`
- 남발 — `~할 수 있다`, `~것이다`, `~들`
- AI 상용어 — `핵심적`, `효과적`, `혁신적`, `지속가능한`, `중요하다`
- 3박자 나열, 불필요한 쉼표, `~라고 할 수 있다` 류 결말
