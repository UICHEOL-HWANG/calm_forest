# 고요한 숲 초보자 안내서 — 슬라이드 생성 프롬프트

Gamma · Canva AI · ChatGPT/Claude 슬라이드 생성기에 그대로 붙여 넣는 프롬프트입니다.
색상은 전부 **게임 코드(js/game.js `PAL`, index.html CSS 토큰)에서 가져온 실제 값**이고, 스크린샷은 `docs/beginner-guide/img/`에 있습니다.

## 1. 붙여 넣을 프롬프트 (전체)

```
다음 조건으로 16:9 슬라이드 20장짜리 "게임 초보자 안내서"를 만들어 줘.
게임 이름은 "고요한 숲 (calm forest)" — 동물의 숲 느낌의 로우폴리 3D 브라우저 게임이야.
독자는 게임을 처음 켜 본 사람. 말투는 게임 안 문구처럼 "~해요 / ~하세요"체, 짧은 문장, 한 슬라이드에 핵심 3~5개만.

[디자인 팔레트 — 게임 배경 그대로, RGB]
- 바탕(잔디 연두):        RGB(191, 232, 201)  #BFE8C9   ← 슬라이드 배경 또는 큰 면
- 잔디 그늘 연두:         RGB(169, 220, 182)  #A9DCB6   ← 배경 위 은은한 도형·구분 면
- 나뭇잎 초록 1:          RGB(143, 214, 160)  #8FD6A0   ← 포인트 도형, 아이콘 배경
- 나뭇잎 연두 2:          RGB(183, 230, 168)  #B7E6A8   ← 카드 배경(밝은)
- 나뭇잎 민트 3:          RGB(160, 224, 208)  #A0E0D0   ← 보조 포인트
- 하늘(안개색):           RGB(223, 243, 255)  #DFF3FF   ← 밝은 카드·표 헤더
- UI 크림(패널 바탕):     RGB(255, 247, 236)  #FFF7EC   ← 본문 카드, 흰색 대신
- UI 잉크(본문 글자):     RGB(74, 90, 79)     #4A5A4F   ← 본문 텍스트
- 제목용 진한 초록:       RGB(47, 107, 74)    #2F6B4A   ← 제목·번호 배지 (안내서용 추가색)
- 아주 진한 초록:         RGB(31, 74, 51)     #1F4A33   ← 표지·구분 슬라이드 배경
- 나무 줄기 갈색:         RGB(216, 166, 121)  #D8A679   ← 따뜻한 포인트(구분선·라벨)
- 흙 갈색:                RGB(156, 107, 74)   #9C6B4A   ← 번호 콜아웃·강조 배지
- 작물 주황(강조 1개):    RGB(255, 158, 94)   #FF9E5E   ← 경고·주의 문구 아이콘 한 군데만
- 지붕 산호:              RGB(255, 158, 158)  #FF9E9E   ← 거의 안 씀, 표지 장식 정도

규칙: 배경은 크림(#FFF7EC) 또는 잔디 연두(#BFE8C9) 둘 중 하나로 통일. 제목은 진한 초록(#2F6B4A), 본문은 잉크(#4A5A4F).
순백(#FFFFFF)과 회색은 쓰지 말고 크림·연두 계열로 대체. 그라디언트 금지. 둥근 모서리 10px, 그림자는 아주 옅게.
강조색(주황·산호)은 한 슬라이드에 한 곳만.

[타이포]
- 한글 산세리프 한 종류만: Pretendard(없으면 Noto Sans KR / Apple SD Gothic Neo).
- 제목 34~40pt 굵게, 본문 15~16pt, 캡션 12~13pt. 이모지는 게임 UI가 쓰는 것이라 그대로 써도 됨.
- 키보드 키는 키캡 모양 박스로: [W][A][S][D] [Space] [1] [2]~[5].

[레이아웃]
- 왼쪽 글 열(약 40%) + 오른쪽 스크린샷(약 60%). 스크린샷은 16:9 원본 비율 유지, 잘라내지 않기.
- 순서가 있는 내용은 초록 원형 번호 배지(①②③④)로, 순서가 없는 내용은 그냥 불릿.
- 주의 문구는 왼쪽에 4px 세로 띠가 있는 연한 상자(팁=연두 #E6F4EA 바탕, 주의=살구 #FBEBDD 바탕).
- 매 슬라이드 아래 왼쪽에 작게 "고요한 숲 초보자 안내서", 오른쪽에 쪽 번호.
```
