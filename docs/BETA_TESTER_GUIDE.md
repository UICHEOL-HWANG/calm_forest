# 고요한 숲 베타 테스트 안내 (2026-09-09 ~ 09-15)

안녕하세요! 일주일 동안 「고요한 숲」을 같이 놀아 주실 분께 드리는 안내예요.

## 언제
- **9월 9일(수)부터 9월 15일(화)까지 7일**이에요.
- 매일 **최소 한 번** 접속해서 놀아 주세요. 더 하셔도 물론 좋아요.

## 어떻게 시작하나요
1. 9월 9일(수)에 https://calmforest.cloud 를 열어요. (폰·PC 아무거나. 크롬 권장)
2. **안내받은 구글 계정**으로 로그인해요. 다른 계정으로 하면 기록이 안 남아요.
3. 캐릭터를 고르고 튜토리얼을 따라가요. 그다음은 마음대로 놀면 돼요.
4. 콘텐츠가 며칠에 걸쳐 차례로 열려요. 잠긴 곳은 화면에 "N일차에 열려요"라고 떠요.

## 매일 저녁, 일지 3분
- 게임 왼쪽 위 ☰ 메뉴 → **📝 오늘 일지** 를 눌러요. (같은 구글 계정으로 열려요)
- 질문 4개예요. 짧게 써도 돼요. 마지막 날엔 2개가 더 있어요.
- 그날 안에 쓰면 제일 좋고, 놓쳤으면 다음 날 써도 돼요.

## 부탁
- 버그나 이상한 점은 일지 2번 칸에 적어 주세요. 스크린샷이 있으면 더 좋아요.
- 다른 테스터와 게임 이야기를 나누는 건 자유지만, 일지는 본인 느낌으로 써 주세요.

## 보상
- 7일 접속 + 일지 7회를 채우면 약속한 보상을 드려요. 마지막 날 설문 뒤에 이번 테스트가 무엇을 봤는지도 알려드릴게요.
