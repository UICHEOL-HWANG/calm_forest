> 한국어가 기본 언어, 영어는 추가 언어로 등록한다(itch·토스는 이미 영어판이 있다).

```
고요한 숲
```

## 짧은 설명 (80자 제한)

검색 결과·추천 카드에 노출된다. 후보 3개 — **A 안 추천**.

**A. 무엇을 하는 게임인지 먼저** (44자)
```
걷고, 심고, 낚고, 짓는 포근한 3D 마을. 서두를 일이 없어요.
```

**B. 정서를 먼저** (46자)
```
서두르지 않아도 되는 3D 힐링 마을. 농사짓고 낚시하고 집을 지어요.
```

**C. 짧고 담백하게** (32자)
```
포근한 로우폴리 3D 마을에서 보내는 느긋한 하루.
```

영어(A 안 기준, 63자):
```
A cozy 3D village to farm, fish and build. Nothing to rush for.
```
