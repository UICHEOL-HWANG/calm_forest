# 고요위키 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 도감 80문서짜리 읽기 전용 위키 `/wiki/` 를 빌드 시 정적 생성하고, 게임 SEO 수정과 한 번에 배포한다.

**Architecture:** build-web.mjs 가 Node 로더 훅(`three` → vendor)으로 게임 데이터 모듈을 import → 엔트리 정규화 → `wiki/content/<cat>.md` 본문과 합쳐 HTML·검색 JSON·sitemap 을 dist/ 에 쓴다.

**Tech Stack:** Node 22 ESM, node:test, Cloudflare Workers static assets.

**Spec:** docs/superpowers/specs/2026-10-18-goyo-wiki-design.md
