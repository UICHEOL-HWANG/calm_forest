# 고요위키 콘텐츠 확장 설계

## 의도

애드센스 재검토와 실제 플레이어의 공략 탐색에 도움이 되도록 고요위키를 원문 정보가 풍부한 공식 게임 위키로 보강한다. 글자 수 자체보다 플레이 방법, 조건, 활용처를 한 페이지 안에서 충분히 이해할 수 있게 만드는 데 초점을 둔다.

## 범위

- 13개 분류 대문에 분류별 종합 공략과 추천 진행 순서를 추가한다.
- 81개 개별 문서에 게임 데이터에서 가져온 장소, 시간, 날씨, 계절, 재료, 효과, 가격, 박물관 위치를 문장형 공략으로 추가한다.
- 위키 표시명 `강가 줍기`를 `배타기`, `땅속 보물`을 `광석 캐기`로 변경한다.
- 기존 URL과 분류 ID는 유지해 검색 색인과 외부 링크가 깨지지 않게 한다.
- 게임 본편의 별도 의뢰 제목과 내부 데이터 이름은 변경하지 않는다.

## 접근 방식

1. 개별 문서만 늘리는 방식은 반복 설명이 많아져 제외한다.
2. 분류 대문만 늘리는 방식은 개별 검색 유입 페이지가 여전히 얇아 제외한다.
3. 분류 대문에는 사람이 쓴 종합 공략을 두고, 개별 문서에는 실제 게임 데이터를 기반으로 한 고유 공략 문장을 생성한다. 사용자가 선택한 방식이다.

## 제약과 검증

- 코드와 데이터에서 확인되지 않는 수치나 확률은 새로 만들지 않는다.
- 기존 본문, URL, 검색, 구조화 데이터, 관련 문서 링크를 유지한다.
- 위키 빌드, 전체 테스트, 생성 HTML의 명칭과 본문 노출을 검사한다.
- 검증 후 Cloudflare 웹 배포를 실행하고 실제 URL을 확인한다.
