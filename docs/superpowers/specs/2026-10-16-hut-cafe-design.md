# 🏔️ 설산 정상 산장 카페 설계

- 날짜: 2026-10-16
- 브랜치: feat/mountain-sled (설산 1단계 위에 얹는다)
- 시안: `dev/active/mountain-sled/proto/hut-shop.html?v=c`, 비교 `dev/active/mountain-sled/proto/shots-shop/compare.html`
- 결정: 시안 C 다락 카페 · 점원 북극여우 바리스타(이름표 `북극여우`, 2026-10-16 솜눈에서 변경) · 상품 11종 · 문구 기본안(각 1번 후보) · 카페 창 부제 없음

## 1. 목적
정상 산장(C 등불 산장, `js/mountain/camp-art.js`)에 들어갈 수 있는 작은 실내 카페를 만든다. 썰매로 번 코인을 쓸 곳이 생기고, 산 정상이 "들렀다 가는 곳"이 된다.

## 2. 원칙
1. **썰매 기록에 닿는 것은 팔지 않는다.** 썰매 기록은 리더보드에 올라가므로 썰매 속도·부스터·기록에 영향을 주는 물건은 없다. 음료는 등산·산책에만 쓰이는 추위 지수(§6-1)를 녹일 뿐이고, 같은 일을 모닥불·카페가 공짜로 한다.
2. 착용 상품은 기존 꾸미기 시스템(`js/cosmetics/*`)에 넣는다. 저장·옷장·캐릭터 적용을 다시 만들지 않는다.
3. 기념품은 기존 🧺 보관함 흐름에 넣는다(실내 `house.stored`, 야외 `outdoorStored`).
4. game.js 는 훅·필터 한 줄만. 새 코드는 `js/mountain/*`, `js/cosmetics/*` 에 둔다.
5. 새 코드에 주석을 달지 않는다. 화면 문구에 엠대시를 쓰지 않는다. 월드 말풍선은 이모지만.

## 3. 공간
### 3-1. 정상 마당과 산장 문
- 지금은 정상에서 등산로 띠(폭 1.5) 밖으로 못 나가 산장 문에 닿을 수 없다. 정상에 **마당(원형 걸을 수 있는 영역)** 을 더한다.
- 마당은 등산로 끝과 이어지고, 산장 앞 문 자리와 썰매지기를 포함한다. 높이는 정상 데크 높이(30)로 평평하다.
- 산장 앞 문 자리에 서면 프롬프트 `☕ 산장 카페 들어가기`.
- 문 자리와 출발대(`🛷 썰매 타고 내려가기`) 프롬프트 반경은 겹치지 않는다.
- 산장 충돌 원은 정사각형 몸체에 맞게 줄이고, 데크(포치) 충돌 원은 없앤다(데크는 밟고 서는 곳).

### 3-2. 실내
- 실내는 산 공간과 따로 둔 방이다. 월드 좌표 `MOUNTAIN + (300, 0, 0)` 에 바닥 높이 0 으로 짓는다(주변에 다른 공간 없음, 카메라 far 200 밖).
- 안에 있는 동안 산 그룹(`$w.mountainGroup`)은 숨기고 방 그룹만 보인다. `$w.atMountain` 은 그대로 true (game.js 새 플래그 없음).
- 조명은 시간대와 무관한 따뜻한 실내 고정값(`applyLook` 에 고정 테마, 하늘 텍스처 없음).
- 구성은 시안 C 그대로: 11×8.5 바닥, A자 지붕 아래쪽만 남긴 단면, 뒤쪽 큰 유리 박공과 설산 풍경, 뒤쪽 다락·사다리, 오른쪽 카운터와 커피 기계, 둥근 탁자 3개와 의자, 전구 줄.
- 그리기 횟수: 방 전체 단단한 메시 1 + 빛나는 메시 1 + 이름표. 점광원 없음.
- 이동 제한: 방 바닥 사각형 안 + 가구 충돌 원(카운터, 탁자, 의자, 다락 기둥, 사다리).
- 프롬프트: 앞쪽 가운데 `🚪 나가기`, 카운터 앞 `☕ 주문하기`.
- 나가면 산장 문 자리 바로 앞(마당)으로 돌아온다.
- 썰매 판 진행 상태(`run`)는 카페에 들어가도 유지된다. 산장 도착 후(`hut` 단계) 카페를 다녀와도 출발대에서 그대로 출발할 수 있다. 썰매 타는 중에는 카페에 들어갈 수 없다(출발 전·결과 후에만).

### 3-3. 점원
- 북극여우 바리스타, 이름표 `북극여우`. 시안 `fox()` 조형(흰 몸, 뾰족 귀, 머스터드 목도리, 갈색 앞치마, 큰 꼬리).
- 카운터 뒤에 서 있고, 플레이어가 주문 자리에 오면 머리 위 이모지 말풍선 ☕ (기존 `bubble-fx` 통통 연출).

## 6. 음료 연출
1. 음료를 사면 창이 닫히고, 플레이어가 가장 가까운 빈 탁자 의자로 옮겨 앉아 탁자를 본다.
2. 탁자 위에 산 음료 컵(코코아 갈색, 유자차 노랑)과 김 3줄기가 4초 동안 보인다.
3. 사진 버튼이 반짝인다(`ui.photoNudge`).
4. 토스트 `☕ 몸이 따뜻해졌어요`. 추위 지수가 바로 0 이 되고 3분 동안 오르지 않는다(§6-1).

## 6-1. 🌡️ 추위 지수 (2026-10-16 확정)
- 산 바깥에서만 쌓인다. 카페 안·썰매 타는 중·결승 후 미끄러지는 중에는 쌓이지 않는다. 썰매 기록·리더보드에는 영향이 없다.
- 0~100. 초당 상승: 낮 +0.6 · 노을 +0.8 · 밤·눈 오는 날 +1.2 (산 테마 키 `day`·`dusk`·`night`·`snow` 를 따른다).
- 단계: 0~59 효과 없음 · 60~79 🥶 오들오들(입김 연출만) · 80~100 걷는 속도 25% 느려짐(걷기·등산만).
- 몸 녹이기: 🔥 광장 모닥불 곁(반경 3) 초당 −5 무료 · 🏠 산장 카페 안 초당 −8 무료 · ☕ 음료 한 잔 바로 0, 3분 동안 오르지 않음(10🪙).
- 화면: 산에 있을 때만 상단에 작은 🌡️ 막대. 마을로 나가면 0 으로 돌아간다.
- 안내 문구는 구현 전에 따로 검수받는다. 후보:
  - 처음 60 을 넘을 때 1회: `🥶 추워요. 모닥불이나 산장 카페에서 몸을 녹여요`
  - 80 을 넘을 때: `🥶 너무 추워서 걸음이 느려졌어요`
- 기록: 정상 도착 이벤트 `mountain_hut` 에 `cold`(그때 지수, 정수) 를 더한다. 산 방문 한 번에 80 을 처음 넘으면 `mountain_cold` { stage: 'slow' } 1회.

## 7. 저장
- `gameState.mountain.hut = { sleds: ['basic', ...], sled: 'basic' }`. `restoreMountain` 이 낯선 id 를 버리고 `basic` 을 항상 넣는다. 고른 색이 가진 목록에 없으면 `basic`.
- `gameState.mountain.sled.perfect = true` 는 깃발 12개 완주를 한 번이라도 하면 켜진다(`sledSettle`). 기존 세이브는 false.
- 착용 상품: `gameState.cosmetics` (기존).
- 기념품: `gameState.house.stored` / `gameState.outdoorStored` (기존). 저장 복원은 카탈로그에 있는 id 만 남기므로 DECOR·OUTDOOR 에 등록한다.

## 8. 기록 (GA4·원장)
- `hut_cafe_enter` { from: 'door' } · `hut_cafe_open` {} · `hut_cafe_buy` { item_id, tab, price_coins, coins_after } (파라미터 4개, 한도 25 안)
- 코인 소비는 원장에 `logEcon('hut_cafe', item_id, -price, coinsAfter)`.
- 썰매 색 고르기 `hut_sled_pick` { item_id }. 꾸미기를 사면 기존처럼 바로 입히고 `cosmetic_equip` { via: 'hut_cafe' }.
- `sled_runs` 에 썰매 색 컬럼은 이번에 넣지 않는다(DB 변경 없음). GA4 `sled_start` 에 `sled_skin` 파라미터 하나를 더한다(현재 9 → 10).

## 9. 그리기·성능
- 실내: 방 2 + 점원은 방 메시에 합침 + 이름표 1 + 말풍선 2(보일 때). 산 그룹을 숨기므로 산 안보다 가볍다.
- 썰매 색은 썰매 메시의 지오메트리만 바꾼다(그리기 횟수 그대로).
- 기념품 조형은 각각 메시 3개 이하로 합친다(박물관 리디자인 규칙과 같음).
