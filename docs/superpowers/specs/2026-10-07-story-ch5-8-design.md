# 📖 메인 스토리 5~8장 — 설계

- 날짜: 2026-10-07
- 상태: 사용자 승인(구성·조건·보상·잠금·소급 A안) → 문구 검수 대기
- 후속: 8장의 실제 기능 = 🏡 이웃 마을 구경하기(별도 스펙)

## 1. 목적과 근거

4장(안개 정화)에서 이야기가 끝나고 칩이 영구히 숨겨진다. 그 뒤에 생긴 공간(📐측량소·🍎과수원·🏛️박물관·🔭천문대)은
어떤 장에도 묶이지 않아 소개되지 않는다. 5~8장은 **새 시스템이 아니라 이미 있는 공간에 순서와 서사를 얹는다**(기존 4장과 같은 원칙).

데이터(2026-10-07, 최근 30일 세이브 1,135, 페르소나 제외):
- 4장 완료 11명(1%). 도감 중앙값 1 → **이 작업은 숙련 유저용**이며 초반 이탈 개선 효과는 기대하지 않는다.
- 4장 완료자 도감 중앙값 52 → 도감 N종 조건은 즉시 소급되어 무의미 → 6장은 ✨특별 진열대로.
- 4장 완료자 중 밭 2단계 2명·나무 2명·별자리 1명 → 5·7장은 실제 목표로 작동.

## 2. 장 구성

| # | id | 제목 | 칩 목표(goal) | 완료 조건(기존 상태에서 파생) | 진행 표시 | 보상 |
|---|---|---|---|---|---|---|
| 5 | `living` | 🌾 마을의 살림 | 밭 넓히고 과일나무 심기 | `farm.stage ≥ 2` **그리고** `orchard.trees.length ≥ 1` | `밭 n/2 · 나무 n/1` | 🪙100 |
| 6 | `memory` | 🏛️ 숲의 기억 | 박물관 특별 진열대 채우기 | `Object.keys(museum.special).length ≥ 1` | `특별 진열 n/1` | 🪙120 |
| 7 | `stars` | 🔭 별을 잇는 밤 | 천문대에서 별자리 잇기 | `Object.keys(star.cleared).length ≥ 1` | `별자리 n/1` | 🪙120 |
| 8 | `neighbors` | 🏡 이웃의 숲 | 이웃 마을에 놀러 가기 | 이웃 방문 1회 (**기능 출시 전엔 `soon: true`로 잠금**) | `방문 n/1` | 🪙150 |

새 카운터 없음. 8장의 방문 카운터는 이웃 마을 스펙에서 정의한다.

## 3. 동작 규칙

### 3.1 데이터 (`js/data/dex.js` `STORY`)
- 4개 항목 추가. 8장에 `soon: true`.
- 상단 주석 "4개의 장" → "이어지는 장".

### 3.2 판정 (`js/game.js`)
- `storyDone(i)` / `storyProgressText(i)` 를 인덱스 분기에서 **id 기반 표(`STORY_RULES`)** 로 바꾼다 — 장이 8개로 늘면 인덱스 분기는 읽기 어렵다. 동작은 동일.
- `soon` 장은 `storyDone` 이 항상 false → `syncStory` 의 while 이 거기서 멈춘다.
- `storyView()`:
  - `allDone`: `ch >= STORY.length` **또는** `STORY[ch]?.soon` → 칩 숨김(잠긴 장을 칩 목표로 보여주지 않는다).
  - 잠긴 장의 `state` 는 `'soon'`(모달에서 "🔒 곧 열려요").
- 기존 유저 소급(A안): 이미 있는 부팅 소급 경로 그대로 — 조용히 완료 + 보상 + `story_chapter_complete{retro:1}`.
  - 추가: 부팅 시 **4장 완료 상태에서 새 장이 처음 열리면** 토스트 1회 `📖 새 이야기가 이어져요 — 5장 「마을의 살림」`. 판정은 `started.living` 이 아직 없을 때(이미 있는 `started` 를 재사용, 새 필드 없음).
- 완료 모달: 기존 형식 그대로. 7장을 마치고 다음이 `soon` 이면 "다음 이야기" 줄 대신 `🏡 다음 이야기는 곧 열려요.`

### 3.3 훅 (진행이 바뀌는 곳에서 `syncStory()` 호출)
- 밭 단계 증축 완료, 과수원 묘목 심기, `museum.special` 기록(noteSpecial 결과가 바뀐 경우), 별자리 첫 클리어.
- 부팅 소급은 기존 `game.js` 부팅 호출이 처리.
- 정확한 호출 위치는 구현 계획에서 확정.

### 3.4 UI (`index.html`)
- 모달 부제 `숲에서 이어지는 네 개의 장` → `숲에서 이어지는 이야기` (i18n 키 교체).
- `renderStory()`: `state === 'soon'` 행 = 🔒 아이콘 + `곧 열려요` 문구.
- 8행이 되므로 **모달 본문 스크롤 확인**(폰 세로 375×812 실측 필수). 온보딩 `showStoryMapOnce` 도 같은 모달 — 신규 유저에겐 5~8장이 🔒로 보인다(앞으로의 여정 예고, 의도).

### 3.5 i18n (`js/i18n-en.js`)
- 새 제목·goal·start·done·진행 표시 조각·토스트·부제 전부 영어 사전에 추가. 진행 표시는 기존처럼 조각 단위(`밭`, `나무` …) — ⚠️ `" · "` 글루 함정(beta-feedback-r3) 주의.

### 3.6 트래킹
- 기존 `story_chapter_start` / `story_chapter_complete{chapter,n,retro}` 가 새 id 로 그대로 나간다. 새 이벤트 없음.
- 다음날 BQ 재검증: `chapter in ('living','memory','stars')` 적재, retro=1 이 4장 완료자 수 이하인지.

## 4. 문구 시안 (검수 대상)

| 장 | start (진행 중 줄) | done (완료 모달) |
|---|---|---|
| 5 🌾 마을의 살림 | 이제 이 숲이 내 집이에요. 밭을 넓히고, 오래 함께할 과일나무를 한 그루 심어보자. 측량소는 밭 울타리 옆에 있어요. | 밭이 넓어지고 어린 나무가 뿌리를 내렸어요. 계절이 바뀌어도 여기 있을 거예요. |
| 6 🏛️ 숲의 기억 | 박물관엔 날씨가 남긴 기억을 두는 특별 진열대가 있대요. 비나 눈, 안개 낀 날에 얻은 것을 가져가 보자. | 진열대에 첫 기억이 놓였어요. 그날의 날씨까지 함께 남았어요. |
| 7 🔭 별을 잇는 밤 | 수호목이 말했어요. "밤하늘에도 잎사귀가 있단다." 천문대에 올라 별을 이어보자. | 별을 이으니 잎사귀 모양이 떠올랐어요. 수호목이 웃었어요. "잎사귀를 받은 건 너 하나가 아니란다." |
| 8 🏡 이웃의 숲 | 같은 잎사귀를 받고 숲에 온 이웃들이 있대요. 그들의 마을에 놀러 가보자. | (이웃 마을 스펙에서 확정) |

- 7장 done 이 8장(다른 플레이어 = 같은 잎사귀를 받은 이웃)으로 서사를 넘긴다 — 프롤로그 잎사귀 복선의 2차 회수.
- 토스트: `📖 새 이야기가 이어져요 — 5장 「마을의 살림」`
- 잠긴 장: `곧 열려요`
- 7장 이후: `🏡 다음 이야기는 곧 열려요.`
