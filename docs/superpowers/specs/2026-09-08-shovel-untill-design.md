# 🪏 삽 — 빈 밭 철거(메우기) 설계

- 작성: 2026-09-08
- 상태: 구현 완료(feat/shovel-untill, 2026-09-08) — 실기기 실측·토스 번들·안내서 스크린샷/PDF 남음
- 시뮬: `sims/shovel-sim.html` (모션 ①·2타 연출 검증용, 버리는 코드)
- 브랜치(예정): `feat/shovel-untill`

## 배경

베타 테스터 건의: 로그인 유저가 마을 곳곳에 괭이질을 무분별하게 해서 밭이 잔뜩 생겼는데 되돌릴 방법이 없다.

현재 사실 관계(`js/game.js`):
- 괭이(`tryHoe`)는 빈 땅에 밭을 만들고, 밭을 **없애는 경로는 없다**. 상태는 `empty → growing → mature`, 시들면 `wilted → 괭이로 다시 empty`.
- 밭은 `gameState.plots`로 세이브에 통째로 들어가 로그인 유저는 영구히 남는다. 게스트는 새로고침하면 사라지므로 이 문제는 로그인 유저 문제다.
- 밭은 장식 배치 장애물(`obstacles`)에 안 들어가서 기능 피해는 없고 **시각적으로 마을이 밭투성이가 되는 문제**다.
- 농사 세트 슬롯은 괭이·씨앗·물조리개·낫 4칸이 꽉 차 있다. 야외도구 세트(도끼·망치·낚싯대·포충망)도 4칸 꽉 참.

## 결정 사항(확정)

| 항목 | 결정 |
|---|---|
| 입력 방식 | 🪏 **삽**을 새 도구로 추가 (괭이 재사용·컨텍스트 프롬프트 기각) |
| 철거 대상 | **빈 밭(`empty`)만**. 작물·시든 밭은 거부 |
| 철거 동작 | **두 번 파기**. 1타 후 **6초 안에** 2타가 없으면 원상 복구 |
| 반쯤 판 상태 | **저장하지 않음**. 세이브 스키마 변경 없음 |
| 슬롯 | 농사 세트를 **5칸**으로(괭이·씨앗·물·낫·삽), 숫자키 2~6 |
| 모션 | 시뮬 **① 밟아 꽂고 퍼 던지기**, 길이 0.6초, 타격 시점 진행도 0.30 |
| 보상 | 재료·코인 없음. **도감 「땅속에서」 3종**만 낮은 확률로 |
| 안내 | 튜토리얼 단계 추가 없음. **첫 삽 모달 + 파는 중 프롬프트 + 안내서 단락** 3겹 |

## 1. 도구·슬롯·HUD

- `TOOLS`에 `{ id:'shovel', name:'삽', ico:'🪏', grp:'farm' }`를 낫 뒤에 추가. 농사 세트가 5칸이 되어 숫자키는 2~6.
- 하단바는 페이지당 최대 5슬롯을 그린다. 야외도구 세트는 4칸 그대로(빈 5번째 칸 없이 4개만 표시).
- 모바일 폭: 5슬롯이 들어가게 슬롯 폭·간격을 줄이고, 폰 세로 실기기에서 조이스틱·액션 버튼과 안 겹치는지 실측한다. 안 맞으면 슬롯 크기만 조정하고 구조는 유지.
- 손에 드는 삽 메시는 시뮬 `shovelMesh()`를 그대로 이식(자루+그립 혹·밴드+이음쇠+날+발판, 축척 1.18 = 도끼와 동일). 등 수납(✋맨손)은 기존 `measureStowLen`·`updateStowPose`가 자동 처리.
- `🪏` 이모지는 iOS 15.4+/Android 12+에서만 있다. 구형 기기 폴백으로 낫(`ICO_SICKLE`)처럼 인라인 SVG `ICO_SHOVEL`을 준비하고 도구 표시는 SVG를 쓴다.

## 2. 상태머신·타이밍·세이브

`tryDig()` — 반경 1.6 안의 밭을 찾는다(`tryHoe`와 같은 기준).

| 상황 | 동작 |
|---|---|
| 밭 없음 | 토스트 "여긴 밭이 없어요 — 빈 밭 위에서 파요" |
| `growing` / `mature` / `wilted` | 토스트 "작물이 있어요 — 수확하거나 괭이로 정리한 뒤 메울 수 있어요" |
| `empty`, `digAt` 없음 (1타) | `plot.digAt = clock.elapsedTime`, 이랑 흐트러짐 연출, 프롬프트 줄에 카운트다운 |
| `empty`, `digAt` 살아 있음 (2타, 6초 이내) | 밭 제거·연출·도감 굴림, 토스트 "밭을 메웠어요 🌱" |
| 1타 후 6초 경과 | `digAt` 삭제, 이랑 0.4초 동안 원위치 보간, 토스트 "밭을 그대로 두었어요" |

- 밭 제거 = 씬에서 그룹 제거 + `plots`에서 삭제 + 덮개(`setPlotCover`)·경고(`setPlotWarn`)·씨앗 힌트 아이콘 정리. `getGameState()`가 `plots`를 다시 직렬화하므로 다음 자동 저장 때 로그인 유저의 서버 세이브에서 빠지고, 토스·웹 모두 반영된다.
- `digAt`은 런타임 필드다. `getGameState()`에 넣지 않는다. 새로고침하면 반쯤 판 상태는 사라지고 밭은 온전한 빈 밭으로 돌아온다(의도).
- `trySeed()`는 `digAt`이 살아 있는 밭을 건너뛴다(반쯤 판 밭에 실수로 심기 방지).
- 삽 액션도 `doPlayerAction(plot.x, plot.z, 'dig')`으로 방향을 밭 쪽으로 돌린다.

## 3. 모션·연출

- `actKind = 'dig'` 분기 추가. 시뮬 ①의 곡선을 그대로 이식:
  - 0~.22 팔 앞으로 뻗어 자루를 세움(날 아래·살짝 앞) → .22~.32 밟아 꽂기(몸 툭 내려앉음·스쿼시) → .32~.62 젖혀 퍼 올리기(몸 뒤로, 자루 눕힘) → .62~.82 왼쪽 앞으로 던지기(몸 회전) → 복귀.
  - 자루 방향은 팔 각도에 종속시키지 않고 시뮬의 `aimTool`처럼 **손 월드 회전을 상쇄해 월드 방향으로 직접 지정**한다.
  - 길이 0.6초(`actAnim` 감쇠율 1/0.6). 타격 시점은 진행도 0.30에서 상태 전이.
  - 🐤 병아리(날개-팔)는 기존 팔 없는 폴백 스윙을 그대로 쓴다.
- 1타 연출: 이랑 3줄이 각각 다른 각도로 기울고 어긋남 + 흙더미·파인 자리 메시 표시 + `spawnDust` 10개 + `Sound.till`.
- 2타 연출: 밭 제거 + `spawnDust` 22개 + 연한 흙 자국(원판)이 1.5초 동안 페이드 + 새싹 7개 톡톡 등장 후 2초 뒤 제거 + `Sound.harvest`.
- 6초 만료 복구: 이랑 위치·회전을 0.4초 동안 원위치로 보간, 흙더미·파인 자리 숨김.

## 4. 도감 「땅속에서」

- `DEX.dig` 추가:

| id | 이름 | 아이콘 | 확률 |
|---|---|---|---|
| `worm` | 지렁이 | 🪱 | 10% |
| `shard` | 사금파리 | 🏺 | 5% |
| `old_coin` | 옛 동전 | 🪙 | 2% |

- 2타로 밭이 사라진 직후 **한 번만** 굴린다. 위 순서대로 검사하되 이미 등록된 항목은 건너뛴다. 당첨되면 `dexDiscover('dig', id)` 호출(토스트·반짝이·GA4 `dex_discover`는 기존 로직).
- 코인 지급 없음. 「옛 동전」은 이름만 동전이다.
- 세이브 기본값(`gameState.dex`)과 복원 병합(`saved.dex` 스프레드) 양쪽에 `dig: {}` 추가.
- 도감 모달 `DEX_CAT_LABEL`에 `dig: '🪏 땅속에서'`. `js/i18n-en.js`에 이름 3개. `functions/api/dex-notes.js`에 설명문 3줄.
- `DEX_TOTAL`이 자동으로 43→46종이 된다(코드 주석의 "33종"은 오래된 값). 이미 완성한 유저는 다시 미완성 표시가 되지만 배지·🪙150은 회수하지 않는다.

## 5. 안내 3겹 + 튜토리얼 + 안내서

### 1겹 · 첫 삽 안내 모달 (`hintsSeen.shovel`, 1회)
삽을 처음 골랐을 때 `showHintModal`로 띄운다. `[액션]`은 기기별 "Space" / "오른쪽 동그란 버튼"으로 치환.

> 🪏 **삽 — 빈 밭을 풀밭으로 되돌려요**
> ① 삽을 들고 빈 밭 앞에서 [액션]
> ② 6초 안에 한 번 더 [액션] → 밭이 사라져요
> · 작물이 있는 밭은 안 돼요. 수확하거나 괭이로 정리한 뒤에요.
> · 가끔 땅속에서 도감 수집품이 나와요 📖

### 2겹 · 파는 중 프롬프트 줄
1타 후 6초 동안 프롬프트 슬롯(`setDoorPrompt`)에 "🪏 한 번 더 파면 밭이 사라져요 (5)" 카운트다운. 모바일 레이아웃 규칙대로 컨텍스트 슬롯만 쓴다.

### 3겹 · 상황 토스트
밭 없음 / 작물 있음 / 6초 만료 복구, 위 2절의 문구.

### 역방향 진입점
빈 밭 위에서 괭이질하면 뜨는 "이미 갈아둔 밭이에요 — 🌰 씨앗을 심어요"에 " · 없애려면 🪏삽"을 덧붙인다.

### 튜토리얼
단계 추가 없음. "도구는 2~5" → "2~6". 낫 "(5)" 표기는 유지.

### 안내서 (`docs/beginner-guide/guide-source.html` 원본 → `guide/guide.html` + PDF 재생성)
- 도구 표에 "🪏 삽 6 · 빈 밭 두 번 파면 풀밭으로" 한 줄.
- 농사 섹션 끝에 "밭 없애기" 소단락: 두 번 파기, 6초 안에, 빈 밭만, 도감 수집품. 구현 뒤 실제 화면 1장.
- FAQ 표에 "밭을 없애고 싶어요 → 🌾농사 세트 🪏삽(6)으로 빈 밭을 두 번 파요".
- 도감 섹션에 「땅속에서」 3종.
- `guide-text.txt`·`slide-prompt.md`도 같이 갱신.
