# 겨울 분수 시즌 (winter-2026) 설계

작성 2026-11-15 · 사용자 승인 섹션 1~7 (대화) · 시안 `sims/winter-fountain-v2/` (merge-main 워크트리, 커밋 안 함)

## 목적
전 유저 공동 시즌을 다시 연다. 수확제(harvest-2026)는 참여 8명·기부 193개로 1단계(500개)도 넘지 못했다. 원인은 로그인 전용 기부, 혼자서는 진행이 안 보이는 구조, 너무 큰 목표였다. 겨울 분수는 혼자서도 완성되는 "내 분수"와 모두가 함께 켜는 "마을 등불"로 나눈다.

## 사용자 결정
- 참여 구조: 내 분수 + 마을 분수(등불) 두 갈래.
- 내 분수 자리: 수확제 광장(PLAZA (23,-4)). 완공하면 마당 꼬마 분수 꾸미기를 받는다. 시즌 뒤에도 광장 분수는 그 사람의 단계로 남는다.
- 마을 몫: A안 마을 등불 9개, 3단계, 단계마다 보탠 사람 모두 보상, 12/31 불꽃.
- 게스트: 내 분수·마을 등불 모두 참여. 꾸미기 보상은 로그인 후 보관함(음악회와 같은 규칙).
- 구현: 수확제 기부 구조(서버 테이블·RPC·/api/plaza) 재사용 + 클라이언트 시즌 목록 일반화.
- 광고: 귀찮은 사람을 위해 선택형 보상형 광고(앱·토스만).
- 연말 음악회(12/31 분수 앞 특별 공연)는 범위 밖, 분수 뒤 별도.
- 기존 확정: 기간 12/18 00:00 ~ 1/1 00:00 KST, 분수 모델 b(2단 + 둘레 등불 4개, `js/plaza/fountain.js`), 공사 단계 시안 C(윤곽 먼저, 단계마다 등불 하나, `js/plaza/fountain-stages.js`), 윤곽 낮 화면 opacity 0.55·0x9cc6e2.

## 1. 시즌 구조
- 클라이언트 `PLAZA_SEASON='harvest-2026'` 고정(js/data/plaza.js, js/plaza/index.js, rules)을 **시즌 목록**으로 바꾼다. 항목: `{ id, opensKst, closesKst, kind: 'harvest'|'winter', guests, copy, visual }`. 현재 시즌은 날짜로 고른다. 시즌 밖이면 마지막 시즌의 완료 모습을 보여 준다(지금 동작 유지).
- `localhost` 전용 `?plazaSeason=` 덮어쓰기는 유지(테스트 시즌 검증용).
- 문구: 시즌별 copy 객체. 수확제 문구는 그대로 두고 겨울 문구를 새로 둔다.
- 서버: `plaza_seasons`에 `winter-2026` 행, `allow_guests boolean default false` 열 추가. `plaza_donate`는 시즌의 `allow_guests`가 참이면 익명 세션도 받는다(하루 상한 30 그대로). 수확제 규칙은 바뀌지 않는다.
- `/api/plaza`(60초 캐시)는 시즌 인자를 그대로 받는다.

## 2. 내 분수
- 진행의 원본은 세이브(`plaza.winter`)다. 기존 `plaza_mine`·`_plaza_current_stage`는 전 유저 합산으로 단계를 정하고, 게스트가 로그인하면 세이브만 새 계정으로 옮겨지고 서버 기부 행은 익명 uid에 남기 때문이다(계획 작성 중 코드 확인, 2026-11-15). 서버는 새 RPC `plaza_give(p_season, p_stage, p_item, p_qty)`로 1인 상한·하루 30·게스트 허용·마을 누적만 지킨다. `plaza_seasons`에 `per_user` 열을 더하고 기존 `plaza_donate`는 `per_user` 시즌을 거절한다.

| 단계 | 재료 | 모습 |
|---|---|---|
| 1 | 목재 20 · 돌 15 | 받침돌 + 전체 윤곽, 등불 1 |
| 2 | 돌 25 · 석탄 10 | 아랫단·기둥, 등불 2 |
| 3 | 물고기 10 · 채집물 15 | 윗단 완성, 등불 3 |
| 완공 | 3단계 채우면 | 얼음·눈, 등불 4 |

- 합계 95개, 하루 상한 30 → 최소 4일.
- 단계는 순서대로만 받는다(지금 단계 재료만 기부 가능).
- 시즌이 끝나도 자동 완공하지 않는다. 시즌 뒤 광장에는 각자 도달한 단계가 남고, 기부는 닫힌다.
- 완공 보상: 마당 꼬마 분수 꾸미기 `winterfountain` 1개(로그인 계정 보관함, 원장 source 'plaza'). 게스트는 "로그인하면 받아요".
- 3D: 각 클라이언트가 자기 단계로 `buildFountain(stage)`. 마당용은 같은 모델을 0.55배로(position·scale 덮어쓰기).

## 3. 마을 등불
- 9개, 3단계. 마을 전체 누적 기부: 300 → 3개, 800 → 6개, 1,500 → 9개.
- 보상(그 단계가 켜질 때까지 한 번이라도 보탠 사람):
  - 1단계: 코인 30
  - 2단계: 고급 씨앗 3
  - 3단계: 겨울 등불 꾸미기 `winterlamp` 1 + 12/31 불꽃 연출
- 보상 자격은 처음 보탤 때 서버가 돌려주는 `village_before`(그때까지 마을 누적)를 세이브 `joined`에 남겨, `joined` < 단계 임계값이면 자격이 있다. 지급은 접속 때 "켜진 단계 + 받은 기록"을 보고 클라이언트가 한다. 꾸미기는 로그인 계정만, 코인·씨앗은 게스트도 세이브로.
- 3D: 광장 둘레 r 5.4에 등불 9개(수확제 말뚝 8개 자리 대체). 켜지는 순서는 흩어 놓아 세로 폰 화면에서도 진행이 보이게. 꺼진 등 회색 갓+눈, 켜진 등 노란 갓+빨간 리본. 밤에는 기존 창문 발광 경로로 빛남.

## 4. 광장 겨울 정리
- 운영 광장은 수확제가 기간 종료로 완공 처리돼(stage 4) 1단계 잔재가 없다(시안은 1단계로 그려 다르게 보였다). 겨울 바탕은 완공 광장에서 분수 등불과 겹치는 호박만 빼고 눈 원판으로 덮는다. 완공 광장엔 기부함 대신 명판이 있으므로 분수 자체를 기부 지점으로 한다. 좌판(🍂 토큰 상점)·올빼미 초대·환전은 겨울에 돌지 않는다.
- 충돌체(js/plaza/solids.js)도 같이 맞춘다(말뚝 제거, 등불·분수 추가).

## 5. 안내
- 이번에 만든 규칙을 따른다: 안내 중재(`js/guide/arbiter.js`)에 `fountain` 안내를 이야기 목표보다 낮게 등록, 팝업·배너 큐 사용, 튜토리얼 중 금지, 집 완성 뒤(`featureGuidesOpen`).
- 기존 유저: 시즌 첫 접속 배너 "❄️ 겨울 분수를 함께 지어요" + 광장으로 금색 화살표, 최대 2번, 목적지 문구 "광장으로 가요".
- 첫 방문 한 줄: "재료를 보태면 내 분수가 올라가요".
- 의뢰 버튼(터치)·의뢰 패널(PC): 시즌 동안 "❄️ 내 분수 n/4" 줄.
- 마을 단계가 켜지면 보탠 사람에게 토스트 "🏮 등불 n개가 켜졌어요! 선물을 받았어요"(팝업 큐 순서).
- 문구 규칙: 해요체, 엠대시 금지, "놀다" 금지, 화살표 이모지 금지.

## 6. 광고 (선택형, 앱·토스만, 50:50 실험 유지)
- `fountain_short`: 기부 창에서 지금 단계 재료가 모자랄 때 "광고 보고 재료 채우기". 모자란 만큼 최대 10개, 하루 2회. 텐진 묶음 `rv_house`.
- `fountain_double`: 기부 창의 마을 등불 칸에서, 단계 보상 받을 때 "광고 보고 한 번 더 받기". 단계마다 1회(꾸미기는 제외, 코인·씨앗만). 텐진 묶음 `rv_double`.
- `adQuiet`(튜토리얼·팝업 대기 중 숨김), `SLOT_CAPS`, `rvGroup` 규칙에 등록.

## 7. 측정
- 기존 `plaza_*` 이벤트에 season 값(winter-2026)만 바뀜.
- 새 이벤트: `plaza_fountain_stage{stage}`, `plaza_lamp_stage{stage}`(기존 테스트가 js/plaza 이벤트를 `plaza_` 접두사로 고정). GA4 파라미터 한도 안.
- 성공 기준: 참여(기부) 25명 이상, 내 분수 완공 10명 이상, 마을 등불 2단계 이상.

## 8. 일정·배포
- 구현·검증 12/10까지, 5곳 동시 배포 12/11~12(새 저장 칸·꾸미기 id `winterfountain`·`winterlamp` 때문에 5곳 동시 필수). 시즌은 12/18 00:00 KST 날짜로 자동 시작.
- 서버 SQL(시즌 행·allow_guests·needs)은 배포 전에 직접 적용(pg8000 풀러), 셀프테스트는 DO 블록 하나로 스스로 정리.
- 실제 서버 경로 검증: 테스트 시즌 + `?plazaSeason=`(localhost), 끝나면 시즌·기부·테스트 계정 정리.

## 범위 밖
연말 음악회, 계절 작물, 수확제 좌판·토큰 재사용, 광고 횟수 서버 검증.
