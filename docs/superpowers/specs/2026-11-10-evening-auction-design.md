# 저녁 경매 (실시간 호가 · 광장 등불 무대)

작성 2026-11-10 · 상태: 방향 확정(2026-11-10 사용자) · 구현·배포·커밋 전

시안
- 방식 비교: `sims/auction-compare.html` (A 실시간 호가 채택, B 봉투·C 떨이 기각)
- 무대 배경 비교: `sims/auction-stage-compare.html` (1 등불 무대 채택, 장날 링·포구 기각)
- 3D 시안: `sims/auction-stage-3d.html` + `sims/auction-stage/models.js`

## 0. 왜 만드나

| 근거 | 수치(측정일) |
|---|---|
| 시세판이 고민거리를 못 만든다 | 최근 30일 판매자 198명 중 192명이 시세 +15% 이상 품목만 팖. 시세는 품목별 매일 무작위(`priceRate`, js/game.js:640)라 쌓아 둘 이유가 없음 (GA4, 2026-10-11~11-09) |
| 코인을 쓸 곳이 없다 | 최근 14일 저장 632건 코인 잔액: 중앙값 5 · p75 35 · p90 217 · p95 964 · 300 이상 57건(9%) · 1,000 이상 30건 (Supabase game_saves, 2026-11-10) |
| 손으로 하는 콘텐츠가 더 쓰인다 | 작업대에서 미니게임이 있는 조각 탭 61명 > 버튼만 있는 도구 58·야외 47·선물 41명 (GA4 30일) |

목표: 코인이 남는 상위 약 10%에게 **하루 한 번 저녁에 돌아올 이유**와 **코인을 쓸 곳**을 준다. 나머지 90%에겐 구경거리이자 "코인 모으면 저걸 살 수 있다"는 목표가 된다.

## 1. 확정된 것

| 항목 | 결정 |
|---|---|
| 방식 | 실시간 호가(영국식). +10 · +30 · +50. 아무도 안 부르면 4초 뒤 낙찰, 누가 부르면 카운트가 4초로 돌아감. 한 판 상한 45초 |
| 장소 | 마을 광장의 상설 등불 무대(빨간 막·줄 등불 3줄·받침대·연단·종) |
| 경매인 | 방랑 상인 |
| 겨루는 주민 | 큐레이터(크게, +50) · 별 보는 아이(자주, +10) · 목수 아저씨(막판, +30) |
| 손 들기 | 3D 입찰 팻말. 주민은 몸 옆→머리 옆으로 올림, 곰(플레이어)은 팔로 듦. 팻말 테두리 = 그 주민 몸 색 |
| 무대 위 표시 | 글자 없음. 숫자·이름·기록은 HUD 창에만(메모리 world-bubble-emoji-only) |
| 연출 | 시작 종·망치 톡, 마지막 3초 망치 듦·조명 깜빡임, 낙찰 망치 내려침·조명이 낙찰자로 이동·꽃가루, 1등 발밑 금빛 고리 |
| 카메라 | 참가하면 게임 시점 → 무대 시점으로 이동, 끝나면 복귀. 모바일은 더 멀리 |
| 창 배치 | PC 오른쪽 세로 창, 모바일 아래 창 |

## 2. 규칙

### 2-1. 하루 한 점
- 날짜 키(시세와 같은 날짜 기준)로 그날의 경매품 1점을 고른다. 모든 플레이어가 같은 날 같은 물건을 본다.
- 경매는 **저녁 시간대**에만 열린다(정확한 판정 함수는 구현 계획 §통합). 그 밖에는 무대가 비어 있고 등불만 켜진다.
- 하루 한 번만 참가할 수 있다. 낙찰이든 패찰이든 구경이든 참가하면 그날은 끝(`gameState.auction.lastDate`).

### 2-2. 값
- 경매품마다 감정가(appraisal)가 있다. 시작가 = 감정가 × 0.5(10 단위 반올림).
- 주민 3명의 최고가 = 감정가 × [0.75, 1.40] 구간에서 날짜 키로 정한 값(10 단위). 같은 날은 몇 번 열어도 같은 값.
- 플레이어는 지갑보다 많이 부를 수 없다(버튼 비활성).
- 첫 풀(MVP) 3점:

| id | 이름 | 감정가 | 비고 |
|---|---|---|---|
| `moonswing` | 달빛 그네 | 400 | 시안 모델. 밤에 달·별 장식이 은은하게 빛남 |
| `lanternarch` | 등불 아치 | 300 | 무대 등불과 같은 등 5개를 단 마당 아치 |
| `starvane` | 별 풍향계 | 220 | 바람에 도는 별 모양 풍향계 |

### 2-3. 참가 조건과 구경
- 지갑 < 시작가: "참가하기" 대신 **구경하기**. 주민끼리 겨루는 같은 경매를 본다(입찰 버튼 없음). 구경도 그날 참가로 친다.
- 지갑 ≥ 시작가: 참가.

### 2-4. 결과
- 낙찰: 코인 차감, 경매품을 🧺 보관함에 넣음(마당에 놓는 건 작업대 장식 탭과 같은 흐름).
- 패찰·유찰: 아무것도 잃지 않음.

## 3. 측정

| 이벤트 | 파라미터(≤5) | 언제 |
|---|---|---|
| `auction_open` | `item_id`, `coins` | 경매 시간에 무대 근처에서 창을 열었을 때 |
| `auction_join` | `item_id`, `mode`(bid/watch), `coins` | 참가하기·구경하기 |
| `auction_result` | `item_id`, `outcome`(win/lose/none/watch), `price`, `my_bids`, `run_id` | 판이 끝났을 때 |

- 원장: 낙찰 시 `logEcon('auction_win', item_id, -price, balance)`.
- 판정 지표(배포 2주 뒤): 경매 시간 접속자 중 참가율, 코인 300+ 보유자의 D1·D7, 코인 유출/유입 비율.

## 4. 안 하는 것 (이번 범위 밖)

- 시세판 철거·시세 규칙 변경: 경매가 자리 잡은 뒤 따로 정한다.
- 작업대·상점 코인 도구 중복 정리: 별도 결정 대기.
- 플레이어끼리 경매, 서버 실시간 동기화.
- 봉투 입찰·떨이 방식.
- 경매품 풀 확장(4점째부터)과 계절 한정품.

## 5. 지켜야 할 기존 규칙

- 새 코드는 `js/auction/` 아래 파일로 나눈다(game.js 에 쌓지 않음). 주석 없음.
- 순수 규칙은 별도 모듈 + `node:test`.
- 새 UI 문구는 코드 전에 후보 표로 검수.
- 무대 위 말풍선은 이모지만. 등불·발광 재질은 블룸 임계 0.85를 넘기지 않게 밝기 검수(PC·모바일).
- 새 이벤트 파라미터 5개 이하, `item_id`·`run_id` 로 퍼널 연결.
- 배포는 웹·토스·itch·안드로이드·iOS 전부.
