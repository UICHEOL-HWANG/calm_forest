## 1. 목적

세계수 부엌 가지 이후의 반복 콘텐츠로 **식당 영업**을 열고, 그 재료를 **배 타고 가는 포구 섬**에서 구하게 해 "바다 낚시·섬 의뢰 → 식재료 → 저녁 영업 → 코인·평판 → 마을 꾸미기" 루프를 만든다.

## 2. 확정한 결정 (2026-11-09)

| 항목 | 결정 |
|---|---|
| 식당 vs 카페 | **별도 건물**. 카페=외지 손님·느긋·차와 간식·찬장 즉시 서빙. 식당=돌아온 마을 이웃·"저녁 영업" 한 판·식사·코인 대량·평판·확장 |
| 영업 조작 | **직접 걷기**. 조이스틱 + 상황 버튼 하나(집기·놓기·썰기·내가기). PC는 WASD+스페이스 |
| 식당 구조 | 왼쪽 홀(테이블) / 벽 / 오른쪽 주방(재료 상자·도마·팬·냄비·접시·쓰레기통) + 벽 사이 **배식대** |
| 조리 방식 | **썰기(버튼 누르고 있기) + 자동 익힘**. 팬·냄비는 올려 두면 익고, 초록으로 깜빡일 때 꺼내면 완벽, 늦으면 너무 익음→탐. 기존 요리 미니게임은 카페에 그대로 둔다 |
| 평판 | **별 1~6 단계**. 단계마다 조건 2~3개 + 보상 묶음. 별이 오를 때마다 플레이가 바뀌는 기능 하나(설비·직원·테이블). 탭: 별 / 손님 명단 / 정보 |
| 난이도 | **두 축 분리**: 별(콘텐츠 종류) ↔ 개인 DDA(같은 별 안의 여유) |
| 식재료 수급 | **포구 섬**(새 맵)에서 바다 낚시 + 주민 의뢰 + 포장마차 구매 |
| 배 | 레퍼런스의 **빨간 둥근 통배**, 앞쪽에 낮게 단 등불. **노 젓기 없음, 조이스틱 방향으로 그냥 움직임** |
| 바다 | **직접 몰면서 낚시하는 곳**. 항로는 등불 부표로만 표시하고 따라갈지는 자유 |
| 섬 가게 | **C안**(포장마차 + 어부 기둥집). **C2(붉은 지붕 밤장) 확정(2026-11-09)** |
| 섬 규모 | 반지름 20, 구역 5개, 주민 의뢰로 식재료를 받는 구조 |
| 온보딩 | **첫 방문 단계별 길 안내 필수**(이탈 분석 결론: 화살표로 어디인지 안 알려 주면 이탈이 크다) |

## 3. 식당 영업

### 3.1 흐름
```text
식재료 창고 확인 → 저녁 영업 시작(100초 내외)
  → 손님이 앉으면 머리 위 메뉴 이모지 + 위쪽 주문표(테이블 번호·메뉴)
  → 재료 상자 → (도마) → 팬/냄비 → 접시 → 테이블 또는 배식대
  → 손님 별점(1~5) → 코인 + 식당 평점
  → 영업 결과 → DDA 조정 → 별 조건 확인
```

### 3.2 메뉴 (1차)
| 메뉴 | 단계 | 열리는 별 |
|---|---|---|
| 🐟 생선구이 | 생선 → 팬 → 접시 | ★1 |
| 🍙 주먹밥 | 쌀 → 도마 → 접시 | ★1 |
| 🍲 생선국 | 생선 → 도마 → 냄비 → 접시 | ★2 |
| (후속) 오징어·조개·큰 물고기 메뉴 | 포구 섬 바다 전용 재료 | ★3~ |

### 3.3 손님 별점
- 기본 5점에서 깎는다. 대기 25초×인내 배율 넘으면 −1, 45초 넘으면 −2. 완벽하게 꺼내지 못한 음식이면 −1. 최소 1점.
- 코인 = 별점 × 5 (밸런스 검토 전 임시값).
- 오래 기다려도 손님이 화내며 나가지 않는다(만족도만 내려감).
- 손님은 **마을 이웃**. 영업 중에는 그 이웃을 마을에서 숨긴다(카페 손님 복제 문제를 다시 만들지 않기 위해).

### 3.4 평판 별 (1~4는 시뮬 값, 5~6은 자리만)
| 다음 별 | 조건 | 보상 / 열리는 것 |
|---|---|---|
| ★2 | 식당 평점 40 · 주먹밥 5번 | 🍲 냄비·생선국, 🪑 테이블 +1, 🪙 100 |
| ★3 | 평점 100 · 별점 4 이상 연속 4명 | 🍳 팬 +1, 🦦 서빙 직원(배식대→테이블 자동), 🪙 200 |
| ★4 | 평점 200 · 생선국 8번 | 🪑 테이블 +1, 🎐 장식, 🪙 300 |
| ★5·★6 | 평점 350~ | 단체 손님, 축제 영업 |

## 4. 난이도

### 4.1 별(콘텐츠): 할 일의 종류를 늘린다
| | ★1 | ★2 | ★3 | ★4 |
|---|---|---|---|---|
| 테이블 | 2 | 3 | 3 | 4 |
| 메뉴(단계) | 구이(2)·주먹밥(2) | +생선국(3) | 같음 | 같음 |
| 설비 | 팬 1 | +냄비 | +팬 1·서빙 직원 | 같음 |
| 손님 간격(초, 영업 처음→끝) | 14→11 | 12→9 | 11→8 | 10→7 |

할 일이 늘 때 새 설비를 같이 줘서 손이 모자라지 않게 짝을 맞춘다.

### 4.2 개인 DDA: 같은 별 안에서 여유만 조절
- 대상 3개: 손님 간격, 손님 인내, 완벽 구간 너비. 각각 **0.8~1.2배** 안에서만, 영업 한 번에 **최대 ±0.08**.
- 규칙: 영업 평균 별점(못 받은 주문은 1점으로 계산) < 3.2 → 쉽게(+0.08). ≥ 4.3 이면서 오래 기다린(😟) 손님 0명·못 받은 주문 ≤1 → 어렵게(−0.06). 그 사이 → 그대로.
- 평판 조건 숫자는 DDA와 무관하게 모두에게 같다.
- 구현 전 기존 `js/difficulty.js`·`js/tuning.js`(블록 셔플 probe 구조)와 맞춘다.

### 4.3 조리 기본 수치 (시뮬)

|---|---|---|---|
| 팬 | 5초 | 2.6초×DDA | 6.5초 |
| 냄비 | 7초 | 3.2초×DDA | 8초 |
| 도마 | 누르고 있기 1.3초 | | |

## 5. 포구 섬

### 5.1 항해
- 마을 부두에서 둥근 통배를 탄다. 조이스틱 방향으로 바로 움직인다(노 젓기 연출 없음). 섬까지 직진하면 약 9초.
- 항로는 주황 등불 부표로만 표시. 바다 어디든 갈 수 있다.
- **첫 방문을 마치면 "🗺️ 바로 가기"**가 열린다(편도 약 4초 자동 항해, 낚시 없음). 바다는 낚시하고 싶을 때만 직접 나간다.

### 5.2 바다 낚시터
| 구역 | 표시 | 잡히는 것 | 자리당 |
|---|---|---|---|
| 가까운 바다(항로 근처) | 하늘색 물결 원 | 🐟 생선 75% · 🦐 새우 25% | 2마리 |
| 먼 바다(항로 밖) | 큰 물결 원 | 🦑 오징어 45% · 🐟 30% · 🐠 큰 물고기 25% | 3마리 |
| 밤에만 뜨는 등불 자리 | 금색 물결 + 불빛 | 🦑 오징어 80% · 🐠 20% | 2마리 |
| 섬 부두 끝 | 하늘색 | 🐟 85% · 🦐 15% | 2마리 |

- 낚시: 버튼으로 찌 던지기 → ❗가 뜨면 바로 버튼(입질 창 0.9초). 첫 낚시는 입질 창 2.2초로 반드시 성공하게.
- 먼 바다·밤 어종은 섬 의뢰·포장마차로 구할 수 없는 **고급 메뉴 전용 재료**다. 바다에서 시간을 쓸 이유.
- 기존 바다터 대어 줄다리기는 그대로 유지. 큰 물고기를 줄다리기로 잇는 건 후속 검토.

### 5.3 섬 구역 (반지름 20)
| 구역 | 내용 |
|---|---|
| ⚓ 포구(서쪽) | 부두, 🏮 포장마차(코인 30 → 쌀 2·채소 2, 방문당 1회), 🛖 어부 기둥집 |
| 🪨 갯바위(남서) | 바위와 물웅덩이, 조개 |
| 🏖️ 해변(동남) | 떠내려온 부표 |
| 🌱 밭(북쪽) | 울타리 친 배추밭 |
| 🗼 등대(동북) | 밤에만 불을 켜는 등대 |

### 5.4 주민 의뢰 (보상 = 식재료)
| 주민 | 의뢰 | 보상 |
|---|---|---|
| 🦦 수달 어부 | 동쪽 해변 부표 3개 | 🐟5 🦐2 |
| 🦝 포장마차 너구리 | 갯바위 조개 4개 | 🍚3 🐚3 |
| 🐐 밭 할머니 염소 | 배추 3포기 | 🥬5 |
| 🦉 등대지기 부엉이 (밤에만) | 어부 집 기름통 | 🦑3 |

- 의뢰는 "말 걸기 → 다른 구역에서 줍기 → 돌려주기"라서 넓은 섬을 한 바퀴 돌게 된다.
- 보상은 포장마차 구매보다 넉넉하게(의뢰를 할 이유).
- 실제 게임: 의뢰는 **하루 한 번 날짜 시드로 바뀜**, 단골일수록 보상 증가 검토.
- 시뮬 실측: 첫 방문(안내 따라감) 왕복 44초·영업 약 1.3회분 / 의뢰 4개 다 하면 섬 약 53초·왕복 80초·영업 약 2.6회분.

### 5.5 식재료 창고
- 받은 재료는 공용 창고로. 영업 1회 ≈ 재료 8개. 한 번 다녀오면 영업 2~3회분.
- 기본 메뉴는 흔한 재료로 만들 수 있게 해 재료 고갈로 영업이 막히지 않게 한다.
- 평판이 오르면 **정기 배송**(어부가 하루 한 번 생선 상자를 마을로) 검토.

### 5.6 조형 (확정)
- 통배: 빨간 타원 통 + 밝은 주황 테두리 + 뒤쪽 둥근 꼬리 + 앞 오른편 낮은 등불, 밤엔 수면에 빛 번짐.
- 포장마차(C2, 형태는 C1과 같고 지붕·등이 붉음): 가파른 박공지붕(기와 줄·용마루) · 붉은 기둥 4 · 처마 끝 종이등 2(띠) · 노렌 3장 · 큰 바퀴살 · 뒤 손잡이 · 앞 둥근 의자 2 · 김 나는 어묵 냄비.
- 어부 기둥집: 둥근(배럴) 지붕 + 띠 3줄 · 반듯한 벽(창틀·문은 벽면에 맞춤, 2026-11-09 교정) · 대각 버팀목 기둥 · 넓은 데크 · 구명튜브 · 깃발 · 불 켜진 창 · 물고기 간판.
- 비스듬한 3/4 각도로 세워 위에서 봐도 지붕 모양과 바퀴가 보이게.

## 6. 첫 방문 길 안내 (온보딩)

### 6.1 원칙 (이탈 분석 반영)
1. **한 번에 목표 하나.** 화면 위 금색 카드에 지금 할 일 한 줄 + 단계(예: 6/12).
2. 목표가 화면 안이면 **⬇️ + 남은 거리 + 바닥 금색 고리**, 화면 밖이면 **가장자리 방향 화살표 + 거리**.
3. 캐릭터(배) **발밑 화살촉**이 목표 방향을 가리킨다. 섬에서는 건물을 돌아가는 **경유점**을 가리킨다(직선이 막히면 우회).
4. 눌러야 할 순간에만 버튼 옆 **👆 손가락**. 지금 단계와 무관한 버튼(부두 낚시·귀항·바로 가기)은 숨긴다.
5. 안내 중에는 다른 말풍선·힌트 줄을 띄우지 않는다(카드 하나만 말한다).
6. 첫 낚시는 반드시 성공하게(입질 창 확대).
7. 조이스틱은 처음에 왼쪽 아래 "끌어서 이동" 점선 원으로 위치를 알려 준다.

### 6.2 단계
| # | 할 일 | 목표 표시 | 완료 조건 |
|---|---|---|---|
| 1 | 포구 섬 가는 배가 생겼어요. 부두로 가 보세요 (마을, 걸어서) | 바다터 후미 통배 부두 끝 | 부두 끝 도착 |
| 2 | 배에 타고 바다로 나가 볼까요? | 통배 + ⛵ 버튼 👆 | 출항 |
| 3 | 화면 왼쪽을 끌어 배를 움직여 보세요 (PC: WASD나 방향키로…) | 가장 가까운 물결 원 | 5m 이동 |
| 4 | 물결이 이는 곳이 낚시터예요. 다가가 보세요 | 물결 원 | 🎣 버튼이 켜짐 |

## 9. 코드 구조

```text
js/restaurant/   index · state · service(영업 세션) · stations(도마·팬·냄비·배식대) · orders
                 satisfaction · reputation(별 조건·보상) · dda · view
js/port/         index · sail(통배 이동·바로 가기) · sea-spots(낚시터·어종표) · island(구역·충돌)
                 quests(의뢰·날짜 시드) · pantry(식재료 창고) · models(sims/port-shop-models.js 이식)
js/guide/        steps(단계 정의 데이터) · arrow(⬇️·고리·가장자리 화살표·발밑 화살촉·경유점), 식당·포구 공용
```

- 판정(별점·평판·DDA·의뢰 진행·경유점)은 DOM·Three.js 없는 순수 함수로 두고 테스트.
- `game.js`에는 진입·종료 훅만. 새 코드는 기능별 폴더로.
- 새 인스턴스 공간 함정 8곳(SEA_FISHING_PLAN §7) 점검, 드로우콜 측정.
