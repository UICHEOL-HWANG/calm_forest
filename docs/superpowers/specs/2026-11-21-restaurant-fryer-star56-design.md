# 🍽️ 식당 튀김기·새 메뉴·별 5·6 기획

## 1. 목적

별 4단계에서 멈춘 식당 성장을 잇고, 포구 창고에 쌓이는 새우·오징어·채소를 식당에서 쓰게 한다. 새 조리대 튀김기로 지금(팬·도마·냄비)과 다른 손맛을 더한다.

## 2. 사용자 결정 (2026-11-21)

| 항목 | 결정 |
|---|---|
| 방식 | 새 조리대 튀김기 + 반죽 그릇 |
| 조작 | 한 요리에 차례로: 튀김옷(박자 2번) → 불 맞추기(누르고 있다 초록에서 떼기) → 거품 때 흔들기 2번 → 금빛에 꺼내기 |
| 구성 | 아래 표 그대로 |
| 주방 배치 | 시안 3개 이상 PC·모바일 비교 후 결정 |

| 별 | 열리는 것 | 새 메뉴 | 승급 조건 | 보상 |
|---|---|---|---|---|
| 5 | 튀김기 1, 반죽 그릇, 상자 🦐·🦑 | 🍤 새우튀김, 🦑 오징어튀김 | 평점 320 + 🍲 생선국 15접시 | 400코인 |
| 6 | 튀김기 2, 상자 🥬 | 🥬 채소튀김 | 평점 480 + 🍤 새우튀김 10접시 | 600코인 |

## 3. 규칙

- 메뉴: `shrimpfry`(from shrimp), `squidfry`(from squid), `vegfry`(from veg). 튀김 메뉴 코인은 별점당 `COIN_PER_STAR × 1.5`.
- 식탁 4개 유지. 별 5·6 손님 간격은 별 4보다 조금 짧게.
- 오늘의 특선·세트 주문은 새 메뉴도 후보로 받는다. 단골 좋아하는 메뉴는 그대로.
- 재고: 새 재료도 포구 창고(`port.pantry`)에서 꺼낸다. 영업 전 재고 안내에 새 재료 줄을 더한다.
- 🐠 큰 생선·🐚 조개는 범위 밖.

## 4. 튀김 단계

1. 상자에서 재료(🦐·🦑·🥬)를 든다.
2. 반죽 그릇에 올리고 박자에 맞춰 두 번 누른다 → 튀김옷 입은 재료를 든다(도마 썰기와 같은 박자 판정, 탭 수만 2).
3. 튀김기에 넣는다 → 불 맞추기: 누르고 있으면 온도 막대가 오르고, 손을 떼면 그 자리에 멈춘다. 초록 칸에서 멈추면 좋음, 벗어나면 품질이 깎인다(한 번만).
4. 튀기는 동안 거품이 두 번 오른다. 거품이 떠 있을 때 누르면 흔들기 성공. 놓치면 품질이 깎인다.
5. 금빛 구간에 꺼낸다. 늦으면 탄다(팬처럼 버리기).
6. 품질은 불·흔들기·꺼내기 결과로 1 / 0.75 로 정한다(지금 품질 체계와 같음).

정확한 시간 값과 막대 구간은 구현 때 시뮬레이션으로 맞추고 계획서에 적는다.

## 5. 화면 (시안 필수)

- 주방 배치: 튀김기·반죽 그릇·상자 3개 자리. 시안 3개 이상을 실제 식당에 놓고 PC·모바일로 비교.
- 튀김기 머리 위 표시(온도 막대·거품·금빛)는 지금 팬 뒤집기 막대처럼 HUD 위젯으로. 시안 필요.
- 새 안내 문구(다음 단계 안내, 메뉴 카드 팁, 승급 조건 줄)는 후보 검수 후.
- 칠판 메뉴 줄은 메뉴 수에 맞게 늘린다.

## 6. 트래킹

- 기존 `restaurant_service`·`restaurant_star_up` 이 메뉴 키를 그대로 받으면 새 이벤트 없음. 구현 때 확인.

## 7. 테스트

- 튀김 단계 상태 기계(반죽·불·흔들기·꺼내기·탐), 품질 계산.
- 별 5·6 데이터, 승급 조건, 메뉴 열림, 재고 필터, 특선·세트 후보.
- 저장: 메뉴 키가 늘어난 `served` sanitize, 옛 세이브 호환.
- 미리보기: 별 5·6 주방 PC·모바일, 튀김 한 접시 끝까지.

## 8. 범위 밖

큰 생선·조개 메뉴, 식탁 5개 이상, 튀김기 업그레이드.
