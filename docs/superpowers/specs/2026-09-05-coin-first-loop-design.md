## 2. A. 상인 방문 이벤트

**발동 조건**(매 프레임 검사, 모두 참일 때 1회):
- `mode === 'play'`, 마을 안(실내·텃밭·동굴·카페 아님)
- `inventory.wood >= 5 || inventory.fish >= 1`
- `!gameState.hintsSeen.merchantVisit` (세이브에 영구 기록)
- 모달이 열려 있지 않음(열려 있으면 닫힐 때까지 대기). 튜토리얼 코치 진행 중이어도 발동한다(sell 단계 자체가 이 이벤트).

**연출**:
1. 방랑 상인 NPC 객체에 `visit` 상태 추가. 배회를 멈추고 플레이어를 향해 이동(속도 2.0/s, 장애물은 기존 `npcBlocked`로 회피). 플레이어와 거리 1.6 이하면 도착. 12초 안에 도착 못 하면 그 자리에서 진행(모달은 뜬다).
2. 도착 시 상인 전용 모달(§7 디자인)을 연다. 이동 정지(`Input.setAnalog(0,0)`).
3. 거래 버튼 1개: 목재가 조건을 만족했으면 "🪵 목재 5개 팔기 (+30🪙)", 아니면 "🐟 물고기 1마리 팔기 (+25🪙)". 둘 다 만족하면 목재. 환영가는 1회 한정.
4. 거래 처리: 인벤토리 차감, 코인 가산, `logEcon('shop_sell', '<item>|welcome', gain, balance)`, `trackEvent('shop_sell', {item, qty, gain, rate: 300, via: 'merchant'})`, `trackEvent('merchant_visit', {item, gain})`, `questEvent('sell', qty)`, `ui.act('sell')`(튜토리얼), 사운드·플로팅 텍스트.
5. 거래 후 같은 모달이 2단계 문구로 바뀌고 버튼 2개: "🛒 좌판 구경"(상점 메뉴 구매 탭을 연다) / "다음에".
6. 모달을 닫으면 상인은 좌판 홈으로 걸어 돌아가고, 좌판 위에 🛒 안내 스프라이트가 60초 동안 떠서 위치를 알려준다. 배너 시스템(`firstHintBanner`)은 키 `merchantShop`으로 1회 "동쪽 좌판에서 언제든 팔 수 있어요" 표시.

**거부 시나리오**: "다음에"를 눌러도 이벤트는 소진된다(재방문 없음). 좌판은 늘 열려 있으므로 손해 없음.

## 3. B. 좌판 활성화 · 튜토리얼

- 상인 홈 위치를 좌판 뒤(북쪽) 1.4 거리로 옮기고 배회 반경을 0.6으로 줄여 상주시킨다. 좌판 콜라이더와 겹치지 않는 좌표는 구현 시 확인한다.
- 좌판 위 캔버스 스프라이트 말풍선: 오늘 시세 최고 품목. 예 "🐟 오늘 비싸요 +17%". 값은 `priceRate`(날짜 해시)로 스폰 시 계산.
- 튜토리얼 `TUT_STEPS` 순서: move → toolpage → chop → **sell** → till → seed → water → harvest → market → quest → mine → carve → dex → fish → build → enter → decor. 번호 ①~⑰ 재부여. sell 문구는 §8.
- 상인 퀘스트 체인은 그대로 둔다.

## 4. C. 신상품 2종

`SHOP_BUY` 맨 앞에 추가:

| id | 이름 | 가격 | give | 설명 |
|---|---|---|---|---|
| `fert1` | 🌱 비료 1개 | 20 | `{fert: 1}` | 자라는 작물을 바로 수확 가능하게 |
| `bait5` | 🪱 미끼 5회분 | 25 | `{bait: 5}` | 5번 동안 희귀 물고기 확률↑ |

인벤토리: 초기값 `fert: 0, bait: 0` 추가, `RES_LABEL`에 라벨 추가, 가방에 🌱·🪱 표시. `SELL_PRICE`에는 넣지 않는다(판매 불가).

**비료 사용(명시적)**: 자라는 밭(`state === 'growing'`) 반경 1.8 안 + `fert > 0`이면 상호작용 프롬프트 "🌱 비료 주기"(데스크톱 Space · 모바일 오른쪽 상호작용 버튼). 실행 시 `fert -= 1`, `plot.growth = 1`, 단계 갱신·반짝임·토스트, `trackEvent('use_fert', {left})`. 프롬프트 우선순위는 NPC·상점·문 다음.

**미끼 사용(자동)**: 캐스팅 시 `bait > 0`이면 `bait -= 1`, 이번 캐스트에 `baitActive = true`, 낚시 프롬프트에 "🪱 미끼 (남은 N회)" 표기, `trackEvent('use_bait', {left})`. 낚아채기 판정에서 `buffOn('luck') || RAIN_DAY || baitActive`로 이중 굴림. 성공·실패·취소 어느 경우든 캐스트 종료 시 `baitActive = false`(회당 소모).

**다음 목표 한 줄**: 상점 구매 탭 하단 고정 텍스트 "다음 목표: 🐔 닭장 60 · 🏡 넓은 집 80 · ✨ 정령 등불 60".

**배포일 기록**: 배포 후 docs/GA4_GUIDE.md 변경 이력에 "YYYY-MM-DD 상인 방문·비료/미끼 배포 — 초반 세션 이동 분포 변화, 이탈 모델 전후 세그먼트 구분" 한 줄 추가.

## 7. F. 디자인 · 모바일 · 토스 요구사항

**디자인**
- 상인 모달은 기존 `#hint-modal` 톤(민트 배경 토큰 `--mint`, 둥근 모서리, 큰 이모지 헤더)을 따르되 버튼 2개 레이아웃을 갖는 별도 `#merchant-modal`. 새 색 도입 없음.
- 좌판 말풍선 스프라이트는 시세판과 같은 크림/우드 팔레트(`#f5efe0` 바탕, `#2fa564` 상승 초록).
- 가방·상점 아이콘은 이모지 🌱·🪱로 통일(SVG 추가 없음).

**모바일**
- 모달 폭 `min(400px, 92vw)`, 버튼은 세로 스택·높이 48px 이상(탭 타깃).
- 비료 프롬프트는 기존 상호작용 버튼(🚪 오른쪽 버튼) 라벨을 "🌱 비료"로 바꿔 표시 — 새 버튼 추가 없음.
- 튜토리얼 문구는 `TOUCH` 분기 유지(숫자키 언급 금지).
- 실측: 375×812 뷰포트에서 상인 모달·상점 구매 탭·낚시 프롬프트가 하단 컨트롤과 겹치지 않는지 스크린샷 확인.

**토스(앱인토스)**
- 상단 인셋: 모달·배너 위치는 `--top-inset`(safe-area + `--toss-reserve`) 기준. 우상단 네이티브 ··· ✕ 영역(약 52px)과 겹치지 않게 모달은 화면 중앙 고정.
- 플랫폼 분기 없음: 새 로직은 `PLATFORM`과 무관하게 동작해야 하며, 토스 진입(로그인 화면 없이 즉시 플레이) 직후 첫 벌목에서도 이벤트가 정상 발동해야 한다.
- 검증: `?platform=toss`로 `body.platform-toss` 상태에서 데스크톱·모바일 뷰포트 각각 확인. 배포는 `npm run build` → 번들 검수 제출(기존 절차, 이번 스펙 밖).

**i18n**: 새 한국어 문구는 모두 `t()`를 거치고 `js/i18n-en.js`에 영문 키를 등록한다. `node scripts/i18n_check.mjs` 통과.
