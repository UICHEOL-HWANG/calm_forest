# ⛏️ 동굴 탐험(지하 20층) 설계

- 작성: 2026-10-25
- 상태: 설계 확정 · 구현 전
- 시안: `sims/cave-pest-compare-v2.html`(방해꾼·규칙) · `sims/cave-pest-compare.html`(v1, 동굴 도롱뇽 원형) · `sims/miner-npc-compare.html`(광부) · `dev/active/cave-delve/mockup/index.html`(실제 게임 화면 안내 목업 PC·폰 10장)

## 1. 목표

스타듀밸리 광산처럼 "한 층만 더" 내려가게 만드는 탐험을 넣는다. calm forest 톤에 맞게 전투는 없고, 위험 요소는 **광석 조각을 훔쳐 가는 순한 방해꾼**이다.

- 지금 동굴(방 하나, 광맥 15개)을 **0층**으로 두고 그 아래에 **지하 1~20층**을 붙인다.
- 새 주민 **⛏️ 광부 아저씨**가 퀘스트 라인으로 층과 방해꾼 대응을 하나씩 가르친다.
- 기존 메인 스토리와 주민 의뢰와 **겹치지 않는 별도 트랙**으로 돌린다.

## 2. 층 구조

| 항목 | 규칙 |
|---|---|
| 0층 | 지금 동굴 그대로(광맥 15개) + 광부 아저씨 + 승강기 |
| 지하 1~20층 | 지금 동굴보다 작은 방. 들어갈 때마다 새로 만든다. 위에서 내려온 사다리로 도착 |
| 내려가는 곳 | 바위를 깨면 나온다. **다섯 번째 바위 안에 반드시** 나온다(헤매지 않게) |
| 내려가는 곳 위치 | **도착점 반대편 절반**, 도착점에서 **방 대각선의 60% 이상** 떨어진 곳에만 생성 |
| 생김새 구분 | 내려가는 곳 = **나무 틀 + 사다리가 걸린 갱도 입구** / 방해꾼 굴 = 테두리만 있는 흙 구멍. 굴은 도착점 근처에 생기지 않는다 |
| 정류장 | 5·10·15·20층. 다음 입장 때 0층 승강기에서 도달한 정류장을 고른다 |
| 나가기 | 어느 층에서든 올라온 사다리 → 0층. 체력·시간 제한 없음 |
| 새로고침·앱 종료 | 지하 층에 있었으면 마을의 동굴 입구 앞으로 복귀(층 모양은 저장하지 않음, 꿈의 숲·이웃 마을과 같은 처리) |
| 층 시드 | (날짜, 층, 그날 입장 횟수) → 같은 조건이면 같은 배치(재현·테스트용) |
| 테마 | 1~10층 흙 동굴 / 11~20층 어두운 수정 동굴 |
| 상자 | 10·20층 보물상자(나루터 보물상자 구조 재사용) |

## 3. 방해꾼 4종

공통 규칙: **바닥에 떨어진 광석 조각만** 노린다. **가방은 어떤 경우에도 털리지 않는다.** 들고 간 조각은 그 층을 떠나면 사라진다.

| 몹 | 층 | 생김새 | 대응(몹마다 하나) |
|---|---|---|---|
| 🦎 동굴 도롱뇽 | 1~10 | 분홍 아가미 술 + 긴 꼬리. 물웅덩이에 숨으면 **아가미만 수면 위로** | **A-1 놀래키기**: 웅덩이 아가미를 괭이로 톡 → 광석을 뱉고 도망 |
| 💎 수정집게 | 1~10 | 바위 등껍질 + 수정 다발. 훔친 조각을 다발에 꽂는다. 느린 옆걸음 | **C 미끼**: 근처에 있을 때만 액션 버튼이 "🍄 미끼 던지기"로 바뀐다(도구 슬롯 추가 없음). 던질 때 **🍄 채집물(`forage`) 1개 소비**. 낚시 미끼(🪱 `bait`)와는 다른 것. 채집물이 없으면 느리니 먼저 줍기 |
| 🦇 잎귀박쥐 | 11~20 | 몸보다 큰 잎 모양 귀 + 날개. 평소엔 바위에 거꾸로 매달린 "열매" | **B 빨리 줍기**: 조각 둘레 노란 원이 줄기 전에 밟으면 줍는다. 원이 다 줄면 가져가고 되찾기 없음 |
| 🐛 등불벌레 | 11~20 | 통통한 마디 애벌레, 꼬리 마디가 등불. 도망가며 빛 방울을 흘린다 | **A-2 굴 되찾기**: 빛 자국 끝 굴을 괭이로 파면 되찾고 덤 1개 |

- 조형 원본: `sims/cave-pest-art.mjs`(구현 때 `js/delve/pest-art.js`로 옮기고 방문객처럼 정점색으로 구워 종당 2~3콜).
- ⚠️ 갓도롱뇽(버섯 갓) 안은 기각. 생김새는 v1 동굴 도롱뇽, 숨기는 버섯 대신 **웅덩이**.

## 5. ⛏️ 광부 아저씨 + 퀘스트 라인(별도 트랙)

### 5-1. 조형: A안 헤드램프 광부

- 몸통 카키 `0x6b7448`, 남색 둥근 헬멧 `0x41556b`, 이마의 작은 헤드램프(빛), 콧수염, 볼 그을음, 어깨에 곡괭이, 가죽 끈.
- 주민 공통 틀(몸통·머리·눈)을 그대로 쓴다. 👷 목수(노란 안전모)와 나란히 놓아도 구분된다(시안 확인).
- 자리: 0층 승강기 옆. 주민 목록(`NPCS`)에는 넣지 않는다.

### 5-2. 기존 퀘스트와 겹치는 곳과 해결

| 겹치는 곳 | 해결 |
|---|---|
| 메인 스토리 2장은 "주민 의뢰 3번 완료"(종류 무관, `story.q`) | 광부 단계 완료는 `story.q`를 올리지 않는다 |
| `questEvent('mine')` 한 번에 일일·반복·히든이 함께 오른다 | 광부 목표는 `mine` 타입을 쓰지 않는다. 전부 동굴 전용 상태형 |
| 주민당 진행 의뢰 칸 1개(`npcState`) | 광부 진행은 `gameState.delve`에 따로 저장 |
| 퀘스트 패널 칸 수(PC 3 · 폰 2 · 작은 화면 1) | 광부 카드는 **동굴 안에서만** 맨 위 고정, 밖에서는 숨김 |
| 반복 의뢰 하루 3명 로테이션 | 광부는 로테이션 밖. 완주 후 **동굴 안에서만 하루 1건** 일감 |
| 튜토리얼 코치의 "첫 채굴" 단계 | 광부 라인은 튜토리얼이 끝난 뒤 첫 동굴 입장 때 자동 시작 |

의도적으로 남기는 겹침: 지하 층에서 광석을 캐도 `questEvent('mine')`은 그대로 → 일일 의뢰 "광석 캐기"가 함께 찬다.

### 5-3. 단계(전부 상태로 판정: 의뢰 받기 전 행동도 인정)

| 단계 | 의뢰 | 판정 | 배우는 것 | 열리는 것·보상 |
|---|---|---|---|---|
| 1 | 갱도 다시 열기 | 가방에 석탄 3개 → 받을 때 차감 | 채굴 | 승강기 수리, 1층 개방 |
| 2 | 웅덩이 속 도둑 | `counts.tap ≥ 1` | A-1 놀래키기 | 보석 1 |
| 3 | 첫 정류장 | `maxFloor ≥ 5` | 내려가는 곳 찾기 | 5층 정류장 |
| 4 | 먹보 달래기 | `counts.bait ≥ 1` | C 미끼 | 🍄 채집물 3 |
| 5 | 10층 보물상자 | `chests[10]` | | 10층 정류장, 수정 동굴, **광부 헤드램프 꾸미기** |
| 6 | 반짝이 사수 | `counts.grab ≥ 3` | B 빨리 줍기 | 수정 2 |
| 7 | 빛을 따라 | `counts.reclaim ≥ 1` | A-2 굴 되찾기 | 15층 정류장 |
| 8 | 바닥까지 | `maxFloor ≥ 20` | | **광산 수레 야외 장식** |

- 완주 후 일감(동굴 안, 하루 1건): "○층에서 광석 n개", "되찾기 2번" 등. 보상은 광석·보석·수정(코인 없음).

## 6. 보상·경제

- 기준: 판매가 돌 3 · 석탄 6 · 보석 40, 올빼미 일일 의뢰 5건 합계 약 70코인.
- **목표**: 동굴 하루 수입 ≤ 일일 의뢰 합계의 1~1.5배(약 70~100코인 상당).
- 확정 수치(시뮬 S3, `dev/active/cave-delve/sim/income-sim.mjs`):
  - 층마다 광맥 **2개**, 광맥 하나에 광석 **1개 고정**(0층의 1~2개·오믈렛 버프는 지하에 적용 안 함). 나머지는 빈 바위(내려가는 곳 찾기용).
  - 광석은 **그날 처음 간 층에서만**. 같은 날 재방문 층은 캔 상태.
  - 보석 확률: 1~10층 4→8%, 11~20층 10→18%. 1~10층은 0층과 같이 **🌫️ 안개 날에만**(도감 게이트 유지), 11~20층은 날씨 무관("깊은 곳은 날씨를 타지 않는다").
  - 새 광물 **수정**(11층+, 10%, 판매가 25, 도감·박물관 연결).
- 시뮬 결과(2만 일, 하루 수입 코인 환산):

  | 플레이어 | 평균 | 올빼미 대비 |
  |---|---|---|
  | 가끔(정류장에서 1~2층) | 20 | 0.28배 |
  | 보통(정류장에서 5층) | 78 | 1.11배 |
  | 최악(0층→20층 전부) | 364 | 5.2배 |

  - 기준선(실데이터 BigQuery, 최근 30일, 채굴자 20명·사람×날 43건): 0층 채굴자의 하루 광석 중앙값 55개(≈229코인), 상위 10% 255개. 최악 경우도 0층 채굴 상위권 범위 안이라 경제를 흔들지 않는다.
  - 기각: 초안(광맥 2~3·1~2개)은 보통 플레이어가 올빼미의 2.4배.
- 광부 라인 보상은 코인 대신 개방·보석·수정·꾸미기.
- 지하 층 광석은 0층보다 분당 수입이 적다. 내려갈 동기는 보석(깊은 층은 날씨 무관)·수정·상자·광부 라인에서 나온다.

## 7. 구조

| 파일 | 역할 | 테스트 |
|---|---|---|
| `js/data/delve.js` | 값 표: 층 테마, 방해꾼 4종, 광부 8단계, 깊이별 광석 확률, 보상 | |
| `js/delve/rules.js` | 순수: 층 배치(내려가는 곳 거리 규칙·반드시 나오는 규칙·굴 위치), 정류장, 광부 단계 판정, 저장값 정리 | 노드 |
| `js/delve/pests.js` | 순수: 방해꾼 단계(대기→접근→물기→도망→굴), 대응 판정 | 노드 |
| `js/delve/pest-art.js` | 방해꾼 조형(정점색으로 구워 종당 2~3콜) | 캡처 |
| `js/delve/miner.js` | 광부 조형·대화·패널 카드 | 캡처 |
| `js/spaces/delve.js` | 3D: 층 방 생성·정리, 사다리, 승강기, 층 이동, 매 프레임 갱신 | 캡처·실측 |

새 코드는 `js/game.js`에 넣지 않는다. 붙이는 곳은 최소: 퀘스트 패널 카드 합치는 자리(과수원 온보딩 옆), 배너·프롬프트, 액션 아이콘, 영어 사전.

### 저장

```
gameState.delve = {
  maxFloor: 0,
  stops: [],                              // [5, 10, …] 실제 도달한 층까지만 인정
  stage: 0,                               // 광부 라인(0 = 아직 안 걸림)
  counts: { tap: 0, bait: 0, grab: 0, reclaim: 0 },
  chests: {},                             // { 10: true }
  visited: { date: null, floors: [] },    // 그날 광석을 받은 층
  jobDate: null,
}
```

- 🚨 **4곳 동시 배포 필수**(웹·토스·Play·itch). 지금 로드는 아는 칸만 복원해서, 옛 클라이언트가 열었다 저장하면 `delve`가 지워진다(할로윈 가구와 같은 유형). iOS도 같은 날 심사 제출.
- 가방(`inventory`)은 모르는 키도 살려 두므로 `crystal`은 옛 클라이언트에서도 남는다.
- 불러올 때 정리: 음수·범위 초과 층 걸러내기, 정류장은 `maxFloor` 이하만.

### 데이터 흐름

```
0층 승강기/사다리 → spaces/delve.js 가 층 생성(rules.js)
  → 바위 깨기 → 조각 떨어짐 → pests.js 가 방해꾼 움직임
  → 대응 성공/실패 → gameState.delve.counts 증가
  → rules.js 가 광부 단계 판정 → 패널 카드(동굴 안에서만) 갱신
광석 획득은 questEvent('mine') 도 그대로(일일 의뢰와 의도된 겹침)
```

### 오류 처리

- 층 생성 실패 → 기본 배치로 대신(갇히지 않게).
- 저장값 이상 → 정리 함수가 안전한 값으로.
- 방해꾼이 들고 간 조각 → 층을 떠나면 소멸, 가방은 손대지 않음.

## 8. 트래킹(GA4, 이벤트당 파라미터 5개 이하, 기존 키 재사용)

| 이벤트 | 파라미터 | 보려는 것 |
|---|---|---|
| `delve_enter` | 출발 층, 열린 정류장 수 | 입장 퍼널 시작 |
| `delve_floor` | 층, 이전 층 머문 초, 깬 바위 수 | 층별 이탈, 내려가는 곳 찾기 난이도 |
| `delve_exit` | 이번 최고 층, 나간 이유, 광석 수 | 한 번에 어디까지 가나 |
| `pest_meet` | 방해꾼, 층 | 첫 만남 |
| `pest_counter` | 방해꾼, 방법, 성공/실패 | 대응법 이해도 |
| `delve_step` | 광부 단계, 시작 후 경과 | 퀘스트 라인 퍼널 |
| `delve_chest` | 층 | 10·20층 도달 |

- 퍼널: 0층 → 1층 → 5층 → 10층 → 20층.
- dev 세션(`?weather=` 등)은 기록하지 않는다. 배포 다음 날 BigQuery로 재검증.
