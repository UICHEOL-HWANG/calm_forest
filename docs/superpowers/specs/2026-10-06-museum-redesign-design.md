# 🏛️ 박물관 리디자인 — 설계

작성: 2026-10-06 · 상태: 사용자 검토 대기
시안: `sims/museum-redesign-layout-sim.html` · `sims/museum-redesign-exhibits-sim.html` (캡처 `dev/active/museum-redesign/look/`)

## 1. 왜 하나

사용자 지적 3가지(2026-10-06).

1. **층마다 밖으로 나가는 문이 있다.** 계단으로 올라왔는데 2·3층·특별전 남쪽에도 1층과 같은 "🚪 나가기"가 뜬다 — `js/spaces/doors.js:230` 이 `museumFloor` 를 보지 않고, `buildMuseumHall` 이 모든 층에 같은 문 자리를 비운다.
2. **마지막 층이 너무 빽빽하다.** 방 하나(15×13)에 층 전시물을 전부 넣는다. 층별 칸 수는 1층 17 · 2층 17 · **3층 31** · 특별전 11. 벽에 13칸만 들어가고 나머지는 가운데 섬(5열)에 쌓여, 높이 1.9m 유리장이 뒷줄을 가린다.
3. **전시물이 거의 전부 원석이다.** 작물·물고기·광물 말고 10개 카테고리(채집·반딧불이·땅속·흔적·강·정령·날씨·주민·요리·방문객)는 `museumExhibitMesh` 의 폴백인 색만 다른 20면체 하나다. 광물조차 돌·석탄은 20면체다.

## 2. 결정 사항 (시안 비교로 확정)

| 항목 | 결정 |
|---|---|
| 층 구조 | **한 건물, 정문은 1층에만.** 2·3층·특별전의 남쪽은 난간+유리창으로 막고 층 이동은 계단만 |
| 층 분위기 | 층마다 바닥·벽색·조명색을 달리한다(`MUSEUM_FLOORS[].theme`) |
| 1·2층 배치 | **벽 유리장** — 방 15×13, 뒷벽 5 + 좌우 6/6 = 최대 17칸. 가운데 섬 없음 |
| 3층·특별전 배치 | **C 회랑형** — 방 20×14, 벽 유리장 + 가운데 **뚜껑 없는 낮은 탁자**(높이 0.8) |
| 전시물 조형 | **카테고리별 대표 조형 + 종별 변형**(색·소품). 약 11개 틀 |

탈락: A(현재 섬 배치), B(알코브 3구역 — 칸막이가 어수선, 방이 22폭), D(층 늘리기 — 약 8층이 되어 계단 부담).

## 3. 설계

### 3.1 문·층 구조
- 나가기 판정은 `museumFloor === 1` 일 때만(`doors.js:229~230`). 상층에서 `museumexit` 은 생기지 않는다.
- `buildMuseumHall` 남쪽 벽: 1층은 지금처럼 문 자리(폭 2.8) + 문턱, 상층은 문 없는 난간(0.9) + 유리창(1.0). ⚠️ 카메라가 남쪽에서 41° 로 내려다보므로 벽을 세우지 않는다(기존 주석 규칙).
- 상층 입장(계단 도착) 지점은 지금 그대로 — 도착은 계단 앞 빈 바닥이다.
- 플레이어 시작 위치 `enterMuseum`(`cafe.js:547`)은 1층 정문 안쪽이라 변경 없음.

### 3.2 배치 — 순수 모듈로 분리
새 파일 `js/museum/layout.js`(THREE 의존 없음, Node 테스트 가능). 파일 분리 규칙에 따라 `cafe.js` 에 더 얹지 않는다.

```
museumLayout(floorDef, count) → {
  W, D,                               // 방 크기. 벽 유리장층 15×13, 회랑층 20×14
  slots: [{ x, z, ry, kind }],        // kind: 'case'(유리장) | 'open'(탁자 위)
  tables: [{ x, z, w, d }],           // 회랑층만
}
```
- `floorDef.layout === 'wall'`: 뒷벽 최대 5 + 좌우 최대 6/6. `count` 가 17 을 넘으면 던진다(층 정의 오류 — 테스트가 잡는다).
- `floorDef.layout === 'gallery'`: 벽 칸 = `min(15, ceil(count / 2))`(뒷벽 → 좌우 순), 나머지는 탁자 위. 탁자는 8칸 이하면 1개, 초과면 2개 줄. 3층(31) = 벽 15 + 탁자 16, 특별전(11) = 벽 6 + 탁자 5.
- 1층의 ✨특별 진열대 3칸(가운데)은 `js/museum/extras.js` 가 그대로 쓴다 — 1층은 섬이 없으므로 `reserveCenter` 분기가 사라진다.
- 방 크기는 층별이라 상수 `MUSEUM_HALF_W/D` 를 **현재 층 값**으로 바꾼다: `museumDims()` 를 export 하고 소비처 5곳(`game.js` 5461 · 5558 · 5744~5745, `doors.js:230`, `cafe.js` 계단·시작)이 이 값을 읽는다. 층을 바꿀 때 `museumFloor` 와 함께 갱신된다.

### 3.3 전시물 조형
- 새 파일 `js/museum/exhibits.js`: `buildExhibit(cat, id) → THREE.Group | null`. 시안(`museum-redesign-exhibits-sim.html`)의 모델을 이식한다.
- `museumExhibitMesh` 는 작물·물고기(기존 `cropMini`·`fishMesh`)를 먼저, 그다음 `buildExhibit`, 실패하면 지금의 20면체 폴백 순서. 폴백은 남긴다(새 카테고리가 추가돼도 터지지 않게).
- ⚠️ **드로우콜**: 시안은 도형마다 메시라 한 전시물이 10~30콜이다. 3층은 31개라 그대로 옮기면 수백 콜이 되고, 이 게임의 병목은 드로우콜이다(메모리: draw-call-optimization). 이식 규칙 — **전시물 하나 = 메시 최대 3개**(불투명 정점색 1 + 발광 1 + 유리 1). 색은 정점에 실어 한 재질로 병합한다(기존 박물관 코드의 정점색 패턴).
- 종별 변형은 `id → 팔레트·소품` 표(데이터)로 둔다. 도감 id 가 늘어도 폴백이 받는다.
- 광물 3종(돌·석탄·보석)도 표본 조형으로 교체한다(작물·물고기는 그대로).

### 3.4 층 테마
`MUSEUM_FLOORS` 에 `theme: { floor, wall, light }` 와 `layout` 을 추가한다. 1층은 지금 색을 기본으로 두고, 상층은 시안에서 색 후보를 비교해 확정한다(구현 단계 첫 작업).

## 4. 건드리지 않는 것
- 해금 규칙(`openFloors`·`need`), 도감 카테고리 배정, 큐레이터 의뢰.
- 🔍 확대 관람(`openMuseumView`) 로직 — 단 탁자 칸은 `inward` 방향이 칸마다 달라 `slot.ry` 로 계산하도록 입력만 맞춘다.
- 명판 판정은 거리 기반이라 유지(탁자 칸 간격 1.12 → 판정 반경을 칸 간격 이하로 줄이는 조정이 필요한지는 구현에서 실측).
- 세이브 구조·GA4 이벤트 이름(`museum_exhibit_view`).

## 5. 위험과 확인 항목
| 위험 | 대응 |
|---|---|
| 탁자 칸이 1.12 간격이라 명판·🔍 대상이 옆 칸과 헷갈린다 | 최근접 1개만 선택(지금도 최소거리) + 반경 상한을 간격의 0.5 로. 실측으로 확정 |
| 방 크기 변경으로 이동 제한·미니맵·충돌체가 어긋난다 | `museumDims()` 단일 출처 + 층 이동 때 미니맵 재생성. 각 층 진입 스모크 |
| 미획득 전시물은 만들지 않는다는 기존 규칙 | 유지(천만 덮은 받침). 탁자 칸은 빈 자리에 천 대신 작은 받침 표식 |
| 전시물 조형 이식이 커서 일부 카테고리가 늦어진다 | 카테고리 단위로 나눠 진행 가능. 미완 카테고리는 폴백 20면체로 남는다 |
| 드로우콜 | 전시물당 ≤3 메시를 테스트로 잠금, 3층 31개 합계를 dev 세션에서 실측 |

## 6. 테스트(TDD)
`tests/museum.test.mjs` 를 확장하고 `tests/museum-layout.test.mjs` 를 추가한다.
1. 층별 `count` 가 규칙을 넘지 않는다(wall ≤17). 모든 층의 슬롯이 방 안(벽·이동 제한 안쪽)에 있고, 서로·계단 박스·탁자와 겹치지 않는다.
2. 회랑층: 벽 + 탁자 칸 수 합이 `count` 와 같다. 탁자 칸 간격 ≥ 1.0.
3. 나가기: `gameSource()` 로 `doors.js` 의 `museumexit` 가 `museumFloor === 1` 조건 안에 있음을 잠근다. 상층 남쪽 벽에 문 자리가 없다.
4. 모든 `DEX` 카테고리·id 가 `buildExhibit` 로 비어 있지 않은 그룹을 낸다(폴백 포함 던지지 않는다). 전시물당 메시 ≤3.
5. 기존 `exhibitCenterY` 회귀 테스트(월드좌표 버그)는 그대로 통과.

검증: dev 세션 `__gs().dex` 로 도감을 채워 4개 층을 PC·모바일(375)로 캡처, 확대 관람 스모크, 드로우콜 측정.
