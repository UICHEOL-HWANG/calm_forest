# 광산 지하 20층 뿌리 터 설계

작성일: 2026-11-18 · 상태: 설계 확정, 구현 계획 전 · 바탕 설계: `2026-10-25-cave-delve-design.md`

## 목적

광산 지하 탐험(동굴 1~20층)은 지금 세계수 이야기와 이어지지 않는다. 바닥(20층)에 닿아도 광부 대사는 "진짜 광부일세"로 끝나고, 왜 이 갱도가 있는지 설명이 없다. 이 작업은 두 가지를 더해 지하 탐험을 세계수 줄거리에 잇는다.

1. 20층에 옛 광부들이 세계수 뿌리를 돌보던 벽화와 마른 뿌리를 두고, 처음 도착할 때 뿌리에 빛이 도는 짧은 연출을 보여 준다.
2. 광부 대사 몇 줄을 바꿔 "광부들은 원래 뿌리지기였다"는 이야기를 탐험 중간과 끝에 흘린다.

뿌리가 마른 원인은 정하지 않는다. 세계수 이야기 쪽에서 아직 정의되지 않았기 때문이다.

## 범위

포함
- 20층 고정 소품 "뿌리 터": 갱목 3컷 벽화(M1), 둥근 육각 돌바닥, 굵은 마른 뿌리, 등불 기둥 하나
- 20층 첫 도착 자동 연출(약 5초, 탭으로 건너뛰기)
- 광부 대사 추가·교체, 안내 한 줄, 영어 번역
- 이벤트 하나 `delve_root_cine`

제외
- 광산 수레 보상, 매일 일감 흐름(그대로 둠)
- 뿌리를 만지는 상호작용(도착 즉시 연출로 결정)
- 서버·DB 변경, 새 꾸미기 id

## 장면 구성

### 자리

- 20층 북쪽 벽, 도착 지점 옆. 도착 지점이 x ≤ 0 이면 뿌리 터 중심 x = +4.2, 아니면 x = −4.2. 벽화는 z = −DELVE_HALF + 0.7 부근, 돌바닥 중심은 벽화 앞 약 2.3.
- `layoutFloor` 는 floor 20 일 때 뿌리 터 영역(돌바닥 중심 기준 반경 약 2.6과 벽화 앞 띠)을 비운다. 바위·사다리 바위·굴·웅덩이가 이 영역에 생기지 않는다. 다른 층 배치는 같은 시드에서 지금과 똑같이 나와야 한다.
- 20층 보물상자 자리(`chestSpot`)도 뿌리 터 영역을 피한다.

### 소품 (목업의 C 바닥 + M1 벽화를 옮김)

- 벽화: 세 칸(각 1.2 × 0.94)을 갱목 기둥 4개와 위아래 가로대로 묶는다. 판 전체를 위로 약간(−0.14 rad) 젖힌다.
  - 1칸 "내려감": 마을과 세계수, 수직 갱도 사다리를 내려가는 광부 둘. 세계수 뿌리가 오른쪽으로 내려가 칸 밖으로 이어진다.
  - 2칸 "찾음": 땅속의 큰 뿌리, 등불을 든 광부 둘, 반짝 표시.
  - 3칸 "돌봄": 무릎 꿇고 뿌리를 돌보는 광부, 등불을 든 광부, 뿌리가 위로 올라가 세계수와 새싹에 닿는다.
  - 세 칸의 뿌리는 칸 경계 높이(캔버스 y 168/200)에서 이어진다.
- 벽화 재질: 평소 색 캔버스(map)와 빛 캔버스(emissiveMap)를 따로 그린다. 빛 캔버스에는 그림 속 뿌리, 등불, 반짝 표시만 금빛으로 들어간다. 켜짐은 emissive 흰색, 세기 0.8.
- 바닥: 육각 돌 세 겹 고리와 가운데 돌, 테두리.
- 뿌리: 굵은 마른 뿌리가 돌바닥을 가로지른다. 켜지면 윗면 결이 금빛이 되고 작은 반짝이가 나온다.
- 등불 기둥: 벽화 옆에 하나. 20층 바닥이 어두워 벽화가 보이게 하는 용도.
- 켜짐 상태에서 뿌리 터 앞에 따뜻한 점광원 하나를 더 켠다.

## 흐름

1. 플레이어가 20층에 들어온다(`enterFloor(20, via)`).
2. 뿌리 터를 놓는다.
3. `gameState.hintsSeen.mineRootLit` 가 없으면 도착 연출을 튼다.
   - 카메라가 벽화 1칸 → 2칸 → 3칸을 지나 플레이어 뒤로 돌아온다(약 5초). 가로 화면은 세 칸 전체를 보며 옆으로 흐르고, 세로 화면은 한 칸씩 화면을 채운다.
   - 2칸을 지날 때 실제 뿌리와 그림 속 뿌리가 함께 켜진다.
   - 화면을 탭하면 바로 끝으로 넘어가 켜진 상태로 돌아온다.
   - 연출 중에는 이동·도구 입력을 막는다.
   - 끝나면 `hintsSeen.mineRootLit = true`, 저장 요청, 안내 한 줄 "🌱 마른 뿌리에 다시 빛이 돌아요".
4. 기록이 있으면 연출 없이 처음부터 켜진 상태로 놓는다.
5. 이미 20층에 닿았던 예전 세이브도 기록이 없으므로 다음에 20층에 오면 연출을 본다.

## 대사 (확정, A안)

광부 말투(~하게체)를 따른다. 엠대시 금지.

| 위치 | 한국어 | 영어 |
|---|---|---|
| `reopen` ask 2번째 줄로 추가 | 옛날엔 등불이 꺼지지 않던 곳이지 | This place never used to go dark. |
| `grab` ask 2번째 줄로 추가 | 우린 그걸 쓰고 뿌리 곁을 지켰다네 | We wore those to keep watch over the root. |
| `bottom` ask 끝에 추가 | 맨 아래엔 우리가 지키던 게 있다네 | Down at the bottom lies what we used to guard. |
| 20층 도착 안내(새 문구) | 🌱 마른 뿌리에 다시 빛이 돌아요 | 🌱 Light flows through the dry root again |

`MINER_DONE_LINES` 교체:

1. 뿌리에 빛이 돌았다고? 자네가 해냈군 / The root is glowing again? You did it.
2. 우리 광부들은 원래 뿌리지기였다네 / We miners were root keepers, you see.
3. 저 위 세계수까지 이어진 뿌리지 / It reaches all the way up to the World Tree.
4. 뿌리가 마르자 갱도가 어두워져 다들 떠났다네 / When it dried, the tunnels went dark and everyone left.
5. 🛒 이 광산 수레는 자네 거라네 (기존 유지)
6. 이제 매일 일감을 하나씩 맡기겠네 (기존 유지)

`bottom` 단계는 20층 도달로 끝나므로, 마지막 대사를 듣는 시점에는 연출을 이미 본 상태다.

## 기록

- 이벤트 `delve_root_cine`: `skipped`(0/1), `sec`(본 시간, 정수). 연출이 끝나거나 건너뛸 때 한 번.
- 기존 `delve_floor` 이벤트는 그대로.

## 오류·예외 처리

- 연출 중 방이 치워지면(층 이동 등) 연출을 끝내고 이벤트만 남긴다(skipped=1). 본 기록은 남기지 않아 다음 도착 때 다시 튼다.
- 등불 광원은 층마다 미리 만들어 둔 세기 0 광원을 20층에서 켜는 방식으로, 층 이동 때 광원 수가 바뀌지 않게 한다(셰이더 재컴파일 방지).
- 연출 중 키 입력은 건너뛰기로 쓰되, Cmd·Ctrl·Alt 조합과 F 키는 막지 않는다.
- 캔버스 생성이 실패하면(드문 웹뷰) 벽화 없이 뿌리와 바닥만 놓고 연출은 그대로 진행한다.
- 저장이 실패해 기록이 사라지면 다음 도착 때 연출이 한 번 더 나온다. 이 경우는 허용한다.

## 검증

단위 테스트
- `layoutFloor` floor 20, 시드 200개: 뿌리 터 영역 안에 바위·굴·웅덩이·사다리가 없다.
- floor 10, 19: 같은 시드의 결과가 변경 전과 같다.
- `rootShrineSpot`: 도착 x 부호에 따라 반대쪽에 놓인다.
- 연출 카메라 경로: 가로·세로 화면비에서 세 칸 순서로 지나고 home 으로 끝난다.
- 새 문구: 엠대시 없음, "놀다" 없음, 영어 키 모두 존재.

캡처(CDP, `?dbg`)
- PC 1280×800, 세로 모바일 375×812: 도착 직후, 연출 1·2·3칸, 연출 뒤, 두 번째 도착.
- 20층 상자를 아직 열지 않은 세이브에서 상자가 뿌리 터와 겹치지 않는지.
