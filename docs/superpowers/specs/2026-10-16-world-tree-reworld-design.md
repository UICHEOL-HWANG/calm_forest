# 🌳 세계관 개편 — 시든 세계수를 되살려라 (설계 초안)

- 상태: **초안 · 사용자 확인 대기**
- 레퍼런스: 포코피아의 *구조*(황폐한 세계 → 복원 → 주민 귀환)를 벤치마킹. 이름·캐릭터·고유 설정은 가져오지 않는다(IP).
- 배경: 베타 피드백 "목적이 뭔지 모르겠다". 할 일(집·농사·요리·낚시…)은 많은데 그걸 묶는 한 줄이 없다.

## 1. 한 줄 목적

> **시들어 버린 세계수를 되살려, 떠난 이웃들을 숲으로 돌아오게 한다.**

인트로 · 장(chapter) · HUD 가 모두 이 한 문장을 반복한다. 모든 기존 활동은 "세계수를 되살리는 수단"으로 의미가 다시 붙는다(새 시스템을 늘리는 게 아니라 이유를 붙인다).

## 2. 세계관

- 숲 한가운데엔 숲 전체에 생명을 나눠주던 **세계수**가 있었다.
- 어느 날 세계수가 시들기 시작했고, 그 자리에서 **안개**가 피어올라 숲을 덮었다. 이웃들은 하나둘 숲을 떠났다.
- 세계수는 마지막 힘으로 **씨앗 하나**를 틔웠다. 그 씨앗이 깨어나 *누군가의 모습*을 빌린 것이 주인공이다(선택한 캐릭터가 그대로 출연).
- 끝까지 세계수 곁을 지킨 건 🦉 **의뢰 올빼미** 하나 — 그대로 안내자 역할.
- 큰 미스터리: **"세계수는 왜 시들었을까? 다들 어디로 갔을까?"** — 주민이 돌아올 때마다 조각을 하나씩 들려준다.
- 기존 `수호목`(안개 숲 중앙) → **세계수의 심장**으로 재정의. 안개 정화 미니게임은 그대로 "세계수 심장에 빛을 되돌리는 일"이 된다.

## 3. 인트로 대본 (~22초 · 인게임 세트 · 스킵 가능)

도시 세트(`buildCitySet`) → **시든 세계수 세트**로 교체. 무조명 재질·라이트 1개 원칙은 유지.

| 초 | 화면 | 자막 |
|---|---|---|
| 0–5 | 잿빛 안개, 잎이 다 떨어진 거대한 세계수 실루엣, 불 꺼진 빈집 | 숲에 생명을 주던 세계수가, 시들어 버렸다. |
| 5–9 | 세계수 뿌리 사이, 작은 초록 빛(씨앗)이 깜빡 | 마지막 남은 씨앗 하나가 눈을 떴다. |
| 9–13 | 빛이 사람 모습으로 변하며 플레이어 캐릭터 등장 | …나는, 누구지? |
| 13–19 | 세계수 가지 끝 잎 하나가 희미하게 빛남 | "깨어났구나. 시들어 가는 나를… 다시 살려주겠니?" |
| 19–22 | 안개 너머 빈집 하나에 창불이 꺼져 있음 | 다들… 어디로 간 걸까? |

기존 인트로 장치(첫 20초에 질문 심기, 프롤로그 잎사귀 모델 `makeIntroLeaf`)는 재활용 — 잎사귀는 "세계수의 마지막 잎"이 된다.

## 4. 목적이 보이게 하는 장치

### 4-1. 세계수 생명력 (메인 진행도)
- 마을 북쪽 배경에 **거대한 세계수 랜드마크**를 세운다. 단계에 따라 잎이 돋고 색이 회색 → 초록 → 꽃으로 바뀐다(예: 5단계).
- HUD 에 `🌳 세계수 37%` — 탭하면 "돌아온 이웃 / 되살린 구역" 목록.
- 플레이어가 매일 마을에서 **눈으로 진척을 본다**는 게 핵심(포코피아의 "황무지가 초록으로" 쾌감).

### 4-2. 구역을 되살리면 이웃이 돌아온다
| 되살리는 일 | 돌아오는 이웃 | 기존 기능 |
|---|---|---|
| (처음부터 곁에 있음) | 🦉 의뢰 올빼미 | 안내자 |
| 첫 집 짓기 | 👷 목수 아저씨 | 건축 |
| 밭 일구기·첫 수확 | 🧑‍🌾 농부 삼촌 | 농사 |
| 나무 베고 숲 정돈 | 🦡 숲지기 오소리 | 벌목 |
| 첫 요리 | 🐼 요리사 판다 | 요리·카페 |
| 강가 물고기 서식지 | 🎣 낚시꾼 할아버지 | 낚시·서식지 |
| 닭장 만들기 | 🐔 목장 아주머니 | 닭장 |
| 나루터 복구 | 🦆 사공 오리 | 바다·나룻배 |
| 코인 경제 돌기 시작 | 🧙 방랑 상인 | 상점 |
| 박물관 진열대 | 🧑‍🦳 큐레이터 할아버지 | 박물관 |
| 천문대 별 잇기 | ⭐ 별 보는 아이 | 천문대 |

이웃이 돌아올 때마다 세계수 생명력 ↑ + "떠난 이유" 조각 대사 1개.

### 4-3. 장(chapter) 문구 재작성 (`js/story/chapters.js`)
| 장 | 지금 | 바뀐 후 |
|---|---|---|
| 1 나의 첫 집 | 떠돌이 생활은 오늘로 끝 | 세계수 곁 빈터에 첫 집을 — 불이 켜진 집이 있어야 이웃이 돌아와요 |
| 2 숲의 이웃들 | 먼저 자리 잡은 이웃들 | 돌아온 이웃들의 부탁 들어주기 |
| 3 첫 요리 | (유지) | 따뜻한 밥 냄새가 숲 밖까지 퍼져요 |
| 4 잎사귀의 주인 → **세계수의 심장** | 잎사귀를 누가 보냈나 | 안개 속 세계수의 심장에 빛을 되돌리기 → 세계수가 왜 시들었는지 첫 진실 |
| 5–6 | (유지·문구만) | 세계수 뿌리가 닿는 곳을 넓히기 |
| 7 별을 잇는 밤 | 잎사귀 받은 건 너 하나가 아니란다 | 세계수는 씨앗을 하나만 틔운 게 아니란다 |
| 8 이웃의 숲 | 같은 잎사귀를 받은 이웃 | 다른 씨앗이 되살리고 있는 숲에 놀러 가기 |

## 5. 단계별 진행 (권장)

1. **1단계 — 서사만 바꾸기**: 인트로 세트·자막, 장 문구, `수호목→세계수` 용어, i18n-en. 게임 로직 변경 없음.
2. **2단계 — 세계수 랜드마크 + 생명력 HUD**: 기존 진행(장 완료·NPC 의뢰 등)에서 생명력을 계산(순수 함수 + 테스트).
3. **3단계 — 이웃 귀환 게이팅**: 신규 유저만 NPC 가 조건 충족 시 등장. **기존 유저는 전원 "이미 돌아옴"으로 처리**(이야기 연속성).

## 6. 리스크 · 결정 필요

- **E3 실험 오염**: E3 가 오늘(2026-10-16) 시작, 신규 기기만 등록. 인트로는 신규 유저 첫 경험이라 **E3 종료 후 배포**.
- **IP**: 포코피아 고유 요소(변신하는 주인공 생물, 식물 박사, 기술 배우기 명칭 등)는 쓰지 않는다. "씨앗이 사람 모습을 빌린다"는 우리식 변형.
- **기존 유저 4장 이후**: 잎사귀 → 세계수로 서사가 바뀌어도 완료 기록은 그대로 두고 문구만 교체.
- **결정 필요**: 세계수 랜드마크 위치(마을 북쪽 배경 vs 안개 숲 안에만), 생명력 단계 수, 3단계(이웃 게이팅) 진행 여부.
