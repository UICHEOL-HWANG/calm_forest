# 리텐션 로드맵 — A 밤사이 가공 → C 시즌 → B 이웃 마을

**작성** 2026-09-20 · **상태** 설계 확정, A 1단계 구현 대기

세 시스템을 순서대로 만든다. 순서는 취향이 아니라 **의존관계**에서 나왔다.

## 왜 리텐션인가 — 관측 근거

2026-09-20, GA4 `calm-forest.analytics_547127440` 최근 30일 기준.

| 지표 | 값 |
|---|---|
| 방문(`first_visit`) | 252명 |
| 실제 진입(`character_select`) | 109명 (43%) |
| 그중 **하루만 플레이** | **85명 (78%)** |
| 2일 | 11명 (10.1%) |
| 3–4일 | 6명 (5.5%) |
| 5–7일 | 2명 (1.8%) |
| 8일+ | 5명 (4.6%) |

활동별 도달 인원이 계단처럼 떨어진다.

```
로그인 128 → 농사 56 → 벌목 49 → 광산 24 · 낚시 24 → 반딧불 17 → 안개 13 → 박물관 12
```

**결론: 병목은 "할 게 없어서"가 아니다.** 콘텐츠는 이미 14종 이상이고, 문제는 다음 날 돌아올 이유가 없다는 것이다.
새 콘텐츠를 또 만들면 12~17명이 보는 콘텐츠가 하나 늘어날 뿐이다. 그래서 **재방문 이유를 만드는 축**을 고른다.

보조 신호(약함 — 표본 24명, 상관이지 인과 아님): 첫날 행동 중 재방문자와 1일 이탈자의 격차가 가장 큰 것은
`badge_earn`(58% vs 9%)과 `zone_enter`(71% vs 24%). 성취 표식을 받고 마을 밖으로 나가본 사람이 돌아온다.

## 순서와 의존관계

```
A. 밤사이 가공  ──▶  C. 시즌·한정  ──▶  B. 이웃 마을(조건부)
   독립               A가 소비처          A·C의 성공에 의존
```

### A. 밤사이 가공 — 1순위

- **의존 없음.** 기존 일꾼 12시간 정산(`js/farm-worker.js`, `Date.now()` 기준) 문법을 재사용한다.
- D1 이탈 78%를 정면으로 겨냥한다.
- 기존 콘텐츠(벌목 49명·농사 56명·광산 24명)의 산출물이 전부 **입력으로 재활용**되어 같이 살아난다.
- 스펙: [2026-09-20-overnight-craft-design.md](./2026-09-20-overnight-craft-design.md)

### C. 시즌·한정 — 2순위

- **A가 없으면 성립하지 않는다.** 시즌 한정 재료가 나와도 쓸 곳이 없기 때문이다.
  A의 가공소가 있어야 "이번 계절에만 만들 수 있는 가공물"이 된다.
- 현재 시간 축은 낮/밤 8분 주기(`DAY_SPEED = 0.002`)와 날씨 4종뿐. 작물·어종·방문객 어디에도 계절 필드가 없다.
  도감 70종 중 시간 한정 축은 weather 4종·night 플래그뿐 → "이번 달에만" 류의 복귀 훅이 존재하지 않는다.
- **위험:** 시즌마다 콘텐츠를 계속 만들어야 한다. 1인 운영에서 두세 시즌 뒤 멈추면 살아 있던 게임이 방치된 것처럼 보인다.
  → 4계절 순환(한 번 만들고 반복)으로 설계해 운영 부담을 고정한다. 매 시즌 신규 제작은 하지 않는다.

### B. 이웃 마을(비동기 소셜) — 조건부

- **리텐션 레버로는 가장 강하지만, 지금 하면 실패한다.** 30일 활성 255명, 재방문 24명이다.
  방문할 이웃이 없어 빈 마을만 보게 되고, 그건 "아무도 없네"라는 최악의 신호다.
  NPC 마을로 채우는 것은 기만이므로 하지 않는다.
- **착수 조건: 일일 활성 30명 이상이 2주 연속 유지.** 일정이 아니라 조건으로 건다.
- 공백 자체는 확실하다 — `functions/api/` 11개 중 유저를 잇는 것은 `leaderboard.js` 하나뿐이고,
  집 6단계·가구 32종·애드온 12종을 사는데 남에게 보여줄 경로가 OS 공유 시트뿐이다.
  꾸미기 투자의 회수 지점이 없다.

## 측정

세 시스템 모두 **D1 재방문율**을 1차 지표로 본다. 현재 기준선은 **22%**(109명 중 24명).
각 단계 배포 후 4주 데이터로 판정하고, 움직이지 않으면 다음 단계로 넘어가기 전에 원인을 먼저 찾는다.

A의 성공 기준은 별도로 하나 더 둔다 — **걸어둔 것을 받으러 돌아온 비율**.
이것이 낮으면 D1이 올라도 A 덕분이 아니다.
