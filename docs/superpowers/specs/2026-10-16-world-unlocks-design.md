# 🔓 마을 해금 구조 — 비어 있는 마을을 함께 채워 가기 (설계 초안)

- 상태: **초안 · 사용자 확인 대기**
- 상위 문서: `2026-10-16-world-tree-reworld-design.md` (세계수 세계관 · 서식지+꾸러미)
- 결정(사용자, 2026-10-16): 새 세이브는 NPC·구조물이 **안 보이는 상태**로 시작하고, 퀘스트를 깨며 **우리들의 공간을 만들어 간다**(포코피아식). 기존 유저는 전부 해금 상태.
- 결정(사용자): E3 끝날 때까지 기다리지 않는다. 설계·개발은 바로, 배포는 E3 비교를 깨지 않는 형태로(§7).

## 1. 원칙

1. **처음 10분은 촘촘하게** — 2~3분마다 무언가 하나가 새로 생긴다. 잠긴 게 많아 휑한 게 이탈 1순위 위험.
2. **내 손으로 하는 기본 활동은 처음부터 열려 있다** — 벌목·채굴·텃밭·호수 낚시. 잠그는 건 **이웃(NPC)과 마을 시설**이다. "할 게 없다"가 아니라 "같이 살 사람이 없다"가 출발점.
3. **해금은 저장하지 않고 계산한다** — `unlockedSet(state)` 순수 함수가 기존 진행 필드(houseStage·story·coop·progress…)에서 매번 계산. `STORY_RULES` 와 같은 방식. 따로 저장하는 건 "다리 고침"처럼 기존 필드로 알 수 없는 사건 플래그뿐.
4. **기존 유저는 전부 열림** — `firstDay`/산 해금과 같은 패턴: 세이브에 새 필드가 없으면 레거시 = 전부 해금.
5. **해금 순간은 이벤트다** — 이웃이 마을 가장자리에서 걸어 들어오고 "🧑‍🌾 농부 삼촌이 돌아왔어요" 모달. 포코피아의 귀환 연출.

## 2. 해금 순서

> E3 주의: E3 트리거는 **첫 물고기**. 호수 낚시는 시작부터 열어 둬서 E3 표본 속도에 영향이 없게 한다.

| 단계 | 조건 | 새로 생기는 것 | 비고 |
|---|---|---|---|
| **시작** | — | 🦉 의뢰 올빼미 · 시든 세계수 · 집터 · 🔧 작업대 · 🌾 텃밭 입구 · 🎣 호수(낚시) · ⛏️ 광산 입구 · 나무·돌 | 올빼미는 데일리 의뢰 주는 이라 처음부터 필요 |

| ② | 집 기초 놓기 (`houseStage ≥ 1`) | 👷 목수 아저씨 | "망치 소리를 듣고 돌아왔어" |

## 3. 저장·기존 유저

- 새 필드 `gameState.unlocks = { v: 1, legacy: false, flags: {} }` — `flags.bridge` 같은 **사건 플래그만** 담는다.
- `applySave(saved)` (game.js:2464~) 에 한 줄: `saved.unlocks` 가 없으면 `{ v:1, legacy:true, flags:{} }`. **새 세이브는 applySave 를 안 거치므로** 기본값(legacy:false)이 유지된다 — `resolveFirstDay`(js/mountain/unlock.js) 와 같은 원리.
- 기기·계정 이동(`pickSave`/`progressScore`, js/save-migrate.js)은 state 통째로 옮기므로 그대로 따라간다.
- 오프라인 게스트는 세이브가 없으니 새 유저로 취급(지금도 저장이 안 됨).
- 킬 스위치: `CONFIG.UNLOCKS` = `'on' | 'off'`. off 면 `unlockedSet` 이 전부 열림을 돌려준다.

## 5. 튜토리얼(17단계)과의 정합

| 단계 | 필요한 것 | 해금 후 |
|---|---|---|
| 이동·도구·벌목 | 나무 | 시작부터 OK |
| 판매·시세 | 상인·좌판·시세판 | 벌목 5개 → ① 상인 도착 → OK (순서상 벌목 다음이라 자연스러움) |
| 밭갈기~수확 | 텃밭 | 시작부터 OK |
| 퀘스트 | 의뢰 가능한 NPC | 올빼미(시작) · 상인(①) → OK |
| 채굴·조각·도감·낚시 | 광산·작업대·호수 | 시작부터 OK |
| 집 짓기·입장·꾸미기 | 집터 | 시작부터 OK · ② 목수 귀환이 중간에 끼어듦 |

→ **튜토리얼 순서는 거의 그대로 돌아간다.** 수확 시 "농부 삼촌의 과수원 의뢰"(orchard-onboard.js:40)만 농부 귀환(⑥) 이후로 미룬다.

## 6. 함께 고칠 것

- 챕터 1·2 문구: 1장 = "세계수를 지키는 법"(집 → 다리 → 할아버지), 2장 = 첫 가지 살리기. 7·8장의 "씨앗" 표현 정리.
- 배지 `all_chains`·도감 NPC 칸: 숨은 NPC 는 언젠가 돌아오므로 그대로 둬도 됨(확인만).
- 서버 공지(notices)가 잠긴 장소를 언급하지 않도록 운영 메모.
- 데일리 의뢰가 처음엔 종류가 적어짐(벌목·채굴·낚시·채집 위주) — 풀 최소 크기 테스트.

## 7. 배포·측정

- E3 영향: 호수 낚시가 시작부터 열려 있어 첫 물고기 트리거 경로가 같다. 두 무리에 똑같이 적용 → 비교 유효. E3 실행 기록에 배포 날짜를 남긴다.
- 효과 측정(사용자 선택 대기): (A) 전원 적용 + 배포 전후 D1/D7 비교(빠름·약함, 추천) / (B) E3 종료 뒤 A/B.
- GA4: `unlock` 이벤트(id, 경과 분) — 처음 10분 해금 간격이 실제로 2~3분인지 확인.

## 8. 작업 단계

1. `js/world/unlocks.js` + 테스트(순서·레거시·킬 스위치·데일리 풀 최소 크기) + `applySave` 한 줄
2. NPC 숨김·귀환 연출
3. 시설·입구·지도·퀘스트 풀·안내 배너 게이트
4. 무너진 다리 + 챕터 1·2 대사
5. 세계수 판(서식지·꾸러미) — 별도 스펙
