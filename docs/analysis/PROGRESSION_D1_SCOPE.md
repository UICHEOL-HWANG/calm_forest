# 신규 이용자의 메인 진행과 재방문

2026-11-06 KST · 사용자 지정 분석 범위와 우선순위.

신규 이용자는 최초 실제 게임 시작일이 2026-10-24~2026-11-05 KST에 속하는 기기로 정의하는 방향이다. 시작일 이전 이력을 확인하며, 관측된 이력 이전까지의 신규 여부는 보장할 수 없다. 사용자는 신규 전체를 대상으로 하고 광고 유입을 구분하기로 명시했다. 광고 확정·확인된 비광고·유입 미상을 구분하며 direct나 경로 결측을 비광고로 단정하지 않는다.

코호트 포함 기간과 결과 관찰 기간을 구분한다. 11/05 신규의 D1은 11/06 전체가 끝난 뒤 해당 데이터가 적재되어야 평가할 수 있다. 관측기간이 덜 찬 기기는 미재방문으로 채우지 않는다. 기존 11/04까지의 사전 점검 숫자를 11/05까지의 확정 분석 수치로 재사용하지 않는다.

우선 확인할 질문은 신규 이용자가 메인 진행의 어느 지점까지 도달한 뒤 다음 날 실제 게임에 돌아오지 않았는가다. 사용자가 제시한 집 완성 이전 종료와 도감 수집 1~4종은 점검할 관찰 후보이며, 해당 코호트 전체에 대한 확정 통계로 취급하지 않는다.

기존 H1~H6는 합의된 관찰 가설로 유지한다. 메인 진행의 병목과 도달 기회를 먼저 확인한 뒤 해당 단계에 맞춰 해석한다. 현재 H5의 quest_complete는 주민 의뢰의 보상 수령이고 메인퀘스트 완료는 story_chapter_complete다.

| 확인할 진행 상태 | 현재 코드의 측정 근거 | 주의점 |
|---|---|---|
| 메인퀘스트 시작·완료 | story_chapter_start, story_chapter_complete의 chapter·n | 완료의 retro와 시작의 via=boot 등 소급 기록을 구분 |
| 집 미착수·기초·중간·완성 | house_build의 stage, house_complete | 이벤트 수집이 정상인 경우에만 미관측을 미착수로 해석. 건설 원장 대조 |
| 다리 수리 | bridge_repaired | 새 진행 방식에서는 집 완성이 선행하고 1장 완료와 연결 |
| NPC·시설 해금 | unlock의 id·kind | 현재 새 세이브는 집 기초로 builder, 다리로 museum·curator, 가지 완성으로 후속 NPC·시설 해금 |
| 세계수 가지 진행 | tree_branch_habitat, tree_branch_bundles | 물·밭·부엌·숲 등 분기별로 판정 |
| 실제 콘텐츠 경험 | 각 시설 입장·NPC 상호작용·활동 이벤트 | 해금과 실제 방문·사용을 별도로 측정 |
| 도감 수집 상태 | dex_discover의 category·entry·total 및 가능한 도감 상태 이벤트 | 최대 total과 고유 category+entry를 대조. 초기 지급·자동 등록·저장 복원·리셋 확인 |

현재 코드에서는 집 완성과 메인퀘스트 1장 완료가 항상 같지 않다. 해금이 켜진 새 세이브의 1장 homeBridge는 다리 수리로 완료되고, legacy 경로는 집 완성으로 완료된다. 다른 맵·NPC 해금에도 가지 완성 등 별도 조건이 있다. 모든 이용자에게 동일한 단일 순서를 강제하지 않고 당시 버전·설정·세이브 유형에 맞는 조건 그래프로 판정한다. 현재 코드와 분석 기간 배포본의 일치 여부는 G1에서 확인한다.

첫 단계 산출물은 같은 코호트에 대해 아래 통계표를 만드는 것이다.

| 단위 | 필요한 통계량 |
|---|---|
| 표본 | 신규 기기 수, 플랫폼·유입별 수와 비율, 미상·제외·연결 불가 수 |
| 진행 단계 | 해당 단계에 진입 가능한 기기 수, 실제 도달 수, 다음 단계 도달 수, 전체 대비·직전 단계 대비 비율 |
| 종료 시점 | 첫 세션 종료 시점과 첫날 종료 시점의 마지막 확인 진행 단계, 해당 기기 수 |
| 단계 소요시간 | 도달자 수, 시간 중앙값·P25·P75·P90, 미도달·결측 수. 도달자만의 시간 분포임을 표시 |
| 집과 도감 교차표 | 집 단계별 도감 0종·1~4종·5종 이상·측정 불가의 기기 수와 비율. 원래 종수 분포도 보관 |
| 재방문 | 각 단계의 D1 평가 가능 수·재방문 수·비율·불확실성, 관측 대기 수 |
| 해금 이후 | 해금 수와 실제 입장·상호작용 수, 해금 전이라 시도할 수 없던 기기를 별도 분모로 표시 |

종료·단계 미도달·D1 미재방문은 별도로 기록한다. 첫날 집이 미완성인 기기가 이후 돌아와 완성할 수 있다. 마지막 이벤트 하나를 종료 원인으로 확정하지 않는다. 집·메인 진행 때문에 잠긴 콘텐츠의 미이용은 낮은 선호로 해석하지 않는다. H6의 벌목·농사·호수 낚시·채굴은 현재 기본 경로에서 열려 있으나, 분석 기간에도 접근 가능했는지 검증한다.

광고 수익 분석은 앱 AdMob, 웹 AdSense를 구분해 준비한다. 플랫폼별 일 광고수익을 같은 플랫폼의 실제 일간 활성 기기 수로 나눈 광고 ARPDAU를 보고, 광고를 본 기기만을 분모로 둔 값은 별도 지표로 표시한다. 수익 통화·시간대·유효 노출·활성 기준·플랫폼 간 중복을 확인한다. 앱스토어·Toss·itch의 광고 수익 적용 범위를 임의로 합산하지 않는다.

진행 단계와 광고 노출 시점의 연결에는 광고 형식·지면·요청·노출·보상·수익의 실제 수집 범위가 필요하다. 기기 또는 세션 단위 수익 연결이 없으면 플랫폼 집계 ARPDAU까지만 계산하고 단계별 수익으로 배분하지 않는다. 광고 도입 전이거나 수익 자료가 없으면 해당 지표는 미측정으로 둔다. 수익을 수집하지 않은 기간에 가상 코인 획득량으로 매출을 대체하지 않는다.

LTV는 우선 동일 관찰기간의 누적 광고수익으로 구분하고, 관측된 LTV7·LTV14와 미래 생애수익 예측을 구별한다. 신규 코호트의 진행·재방문 분포를 보고 개선 후보와 광고 노출 후보를 선정한 뒤, 광고 변경의 수익·재방문 효과는 별도 실험으로 평가한다. 이번 범위 합의만으로 광고를 배치하거나 신규 효과 가설을 확정하지 않는다.

G1의 완료 기준은 신규·유입·진행 상태·도감·재방문의 측정 가능 범위와 누락을 문서화하고, 결과 분석에 사용할 표본 및 정의를 고정하는 것이다. 2026-11-06 G1은 한계를 문서화하는 조건으로 완료했다. 주 표본 508개, 첫날 상세 연결 454개이며 연결 불가·소급 진행·도감 자동 등록은 별도 처리한다. [G1 보고서](../../ml/reports/progression_g1_20261106/report.md). 단계별 종료 분포와 D1 비교는 G2에 남아 있다.
