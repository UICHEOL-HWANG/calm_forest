## 1. 콘셉트 한 줄

> 호수 낚시 = 기다림 → 탭 → 🐟 하나
> 바다 낚시 = **노리고 던짐 → 끌려다니며 버팀 → 무게 기록 → 랭킹**

기존 낚시와의 차별점 3축:
1. **조준하는 사냥** — 수면에 어종별 실루엣이 훤히 보이고, 원하는 놈을 노려서 던진다 (RNG 대기 → 선택).
2. **공간 미니게임 "버티기"** — 대어가 걸리면 부두 위에서 실제로 끌려간다. **부두 끝까지 끌려가면 놓침**. 새 동사 = 버티기/감기.
3. **기록 경쟁** — 무게가 남는다. "오늘의 대어"는 날짜 시드 → 전원 동일 조건 → 무게 리더보드(Supabase 리더보드 계획과 연결).

## 2. 위치·구조 (기존 문법 유지)

- **마을 북동쪽(화면 우상단, +x/−z 사분면, 대략 (12~20, −8~−18))에 포구 게이트** — 방파제+등대 소품, 처음부터 있는 장소(해금형 아님, 카페·채굴장 패턴).
- 게이트 → **바다 인스턴스** (넓은 부두 데크 + 수평선). 좌표는 기존 인스턴스(광산 250 / 카페 320 / 도시 480 / 강 −400·코스 620 / 안개숲 −250)와 안 겹치게 구현 때 실측 선정.
- 마을 쪽 티저: 수평선에 대형 실루엣(고래 등) 1~2마리 — "저기 뭔가 크다"의 후킹.

## 3. 미니게임 루프 (sims/sea-sim.html 검증 완료)

**던지기 → 입질!! → 줄다리기(라운드 반복) → 낚아 올림 / 놓침**

- **던지기**: 팔 스윙 + 부표 포물선 비행(0.62s) → 착수는 항상 부두 끝 너머 트인 물. 가장 앞바다 쪽 물고기를 겨냥.
- **줄다리기** — 물고기 상태 2개가 교대:
  - 🔴 **버둥침**: 기다려야 함. 플레이어가 부두 끝으로 끌려감(어종별 drag). 이때 버튼 누르면 역효과(확 끌려감). 부두 끝(빨간 널판 2칸 = 위험 표시) 넘어가면 **놓침** — 부드러운 실패("놓쳤다…! 다음엔 꼭!").
  - 🟢 **"당기세요!!"**: 짧은 윈도우(어종별 win) 동안 버튼 연타 → 진행도 상승(어종별 tap) + 뒤로 물러남 + 크랭크 회전.
- **낚아 올림**: 물고기가 포물선으로 폴짝 데크에 안착(잔인함 없음) → 무게 측정 카드 → **놓아주기 / 담기** 선택.
- 모바일: 엄지 하나(하단 대형 원형 버튼). 데스크톱: Space.

### 연출 (전부 프로토타입 반영·검증됨)
- 카메라: 평상시 와이드 → 싸움 줌인 → 당길 기회에 한 발 더 + 흔들림. 세로 화면은 자동으로 뒤로 빠짐.
- 플레이어가 물고기 쪽으로 몸을 틀되 **로드 쥔 어깨가 물고기를 향하게** −0.45rad 오프셋(줄이 얼굴을 안 가로지름).
- 낚싯줄 처짐(sag): 대기 중 축 처짐 / 싸움 중 팽팽.
- 물고기는 도망 방향(먼바다)으로 머리, 꼬리가 줄 쪽에서 퍼덕임. 몸은 물속(수면 위론 지느러미·물보라만).
- 부두 정면(끝에서 3.5 이내)은 카메라 사각 → 물고기가 항상 옆 물길로 비켜나 싸움.
- 배회 물고기: wander AI(천천히 선회·귀환) + 분리 규칙(3.4, 대어와는 5.2) + 부두 회피 + **싸움 소란을 피해 도망**.
- rAF 워치독(250ms): 패널/탭이 가려져도 진행 유지 — 모바일 앱 전환 대비.

## 4. 어종 로스터 & 난이도 (유저가 고르는 건 "어떤 물고기를 노리느냐")

**줄다리기로 잡는 것 (4종)** — 시뮬 검증값:

| 어종 | 티어 | 출현 | drag(끌기) | win(윈도우) | tap(연타당) | 무게 |
|---|---|---|---|---|---|---|
| 🐟 전갱이 | 입문 | 낮 | 0.45 | 1.35 | 0.060 (~17회) | 1~3kg |
| 🐠 방어 | 중급 | 상시 | 0.72 | 1.05 | 0.042 (~24회) | 6~14kg |
| 🐡 개복치 | 특수(장기전) | 🌙 밤 전용 | 0.50 | 1.10 | 0.020 (~50회) | 40~90kg |
| ⚔️ 참치 | 최상급 | "오늘의 대어" 하루 1마리·날짜 시드 | 0.95 | 0.90 | 0.032 (~31회) | 60~120kg |

- 난이도 선택 UI는 없다(시뮬의 어종 버튼·슬라이더는 검수용). 출현 조건이 진행도 역할.
- 낚싯대·릴 강화(코인+희소재화 싱크)가 win↑/drag↓ 방향으로 완만하게 보정.
- 개복치 전용 조형: 세로로 넓적한 몸 + 위아래 긴 지느러미 + 뭉툭한 꼬리판(clavus).

**잡지 않고 만나는 것 (2종)** — 잔인함 제거의 핵심, 본 구현 때 추가:
- 🐋 **고래**: 수평선에서 등을 내밀고 물을 뿜는 이벤트. 상호작용 = 도감 등록 + 사진. (포유류를 "낚는" 순간 톤 붕괴 → 낚이지 않음)
- 🦈 **고래상어**(상어 대체): 줄을 물면 끊는 게 아니라 잠깐 부두를 끌고 유람 후 놓아줌 — 실패가 아니라 **보너스**(도감 + 희소재화). "놓쳤다"가 아니라 "고래상어를 만났다!".

## 5. 조형 (sims/arm-sim.html 검수 완료)

- **릴 낚싯대 v2** — v1(가는 릴대)은 41° 카메라에서 민대와 실루엣 동일 → 탈락. 확정: **짧고 굵은 보트 로드 + 윈치급 오버사이즈 드럼 릴**(감긴 밧줄 링 + 빨간 크랭크 노브) + 굵은 가이드 링 2개 + 밧줄 라인 + 주황·흰 줄무늬 대형 부표. 팔레트: 기존 GRIP/STEEL/EDGE + NAVY(0x2e4a66)·KNOB(0xd94f4f).
- **참치 실루엣**: 뾰족 주둥이 → 방추형 몸 → 가는 꼬리자루 → **한 덩어리 초승달 꼬리**(굵은 갈래 2 + 가운데 쐐기 — 가는 콘 2개는 뼈처럼 보여 탈락) + 뒤로 휜 지느러미 4종.
- 액션 스타일 "릴 감기": 스윙이 아니라 버티기 — 뒤로 젖힘 + 입질 리듬 당김 + 크랭크 회전 + 팁 휨.

## 6. 경제·리텐션·트래킹 (구현 때)

- 보상: 물고기 + 신규 희소재화(🐚 or 진주 — 인벤 12칸이라 신설 여부는 구현 직전 재결정) → 낚싯대/릴 강화 = 후반 코인 싱크(강 ⭐창고 패턴).
- 날씨 연동: 🌧️비 = 행운 버프 재사용, 태풍 날 출항 불가(날씨 이벤트와 연결).
- 도감 신규 카테고리 `sea`(4종+고래+고래상어) + 배지. 이후 박물관(5장+ 후보) 수족관 전시로 연장.
- GA4: `zone_enter{sea}` `sea_cast` `sea_struggle{round}` `sea_catch{species,weight,duration,accuracy}` `sea_release` `sea_miss{dragged}` `sea_upgrade` — 라운드별 성공/헛당김으로 난이도 튜닝.
- "당기세요" 타이밍 정확도 → 무게 보너스(리더보드 실력 변별력).
