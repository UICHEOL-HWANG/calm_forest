## 디자인 규칙(B)
- 화면 아래 박스, 크림 #fffaf1, 흰 3px 링 + 주민 색 아래 그림자(0 8px 0) + 부드러운 그림자
- 얼굴 원이 박스 위로 튀어나옴(주민 색 연한 바탕), 이름은 주민 색 큰 글씨
- 화면 안 어둡게. 모달 3종은 투명 오버레이로 입력 차단 유지
- 주요 버튼 = 주민 색(대비 보정 ink) + 진한 아래 그림자, 보조 버튼 = 흰 도톰 버튼
- 모바일: 모달 열리면 조이스틱·액션 버튼 숨김. 거울/광부 박스는 기존 자리(조이스틱 위) 유지
