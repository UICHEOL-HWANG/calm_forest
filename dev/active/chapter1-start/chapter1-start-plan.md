# 1장 시작 연출 (B안: 세계수 조망 + 장 제목)

승인: 2026-10-17 사용자 "B안" (시안 dev/active/chapter1-start/mockup.png)

## 왜

- 튜토리얼 1/17부터 코치 카드 머리에 "1장 · 할아버지 만나기"가 붙어, 조작 설명과 메인 목표가 한 화면에서 따로 놀았다.
- 튜토리얼이 끝나도 1장이 시작됐다는 매듭이 없었다(카드가 칩으로 조용히 바뀜).

## 무엇을 바꾸나

1. 튜토리얼 코치 카드에서 1장 목표 줄(#coach-goal)을 뺀다.
2. 튜토리얼이 끝나면(졸업·건너뛰기 모두) 세계수 조망 카메라로 북쪽 시든 세계수를 비추고,
   위아래 검은 띠 + "1장 / 세계수를 지키는 법" + 🦉 시작 대사를 약 4초 보여 준다. 탭·키로 넘김.
3. 연출이 끝나면 1장 칩이 반짝이며 나타난다.
4. 졸업 뒤 이어지던 안내서 배너·과수원 의뢰·알림 안내는 연출이 끝난 뒤로 미룬다.

## 대상

- 해금 켜짐 + 새 세이브(shotsOn)이고, 아직 1장(story.ch === 0)이며, 본 적 없을 때(hintsSeen.treeShot_chapter1) 1회.
- 레거시 세이브·해금 꺼짐은 지금과 같다(바로 후속 안내).
