E1 처치(harvest_start) 첫 화면 시안 3종

실제 게임(워크트리 빌드)에서 다 자란 당근 밭을 깔고 캡처 · 문구는 자리표시(“눌러서 수확하기”) — 문구는 따로 고릅니다

A안 · 프롬프트 줄

밭 한 줄 3칸 · 하단 프롬프트 줄(🚪나가기와 같은 자리) + 모바일 액션 버튼 테두리 깜빡임

  • 👍 기존 HUD 규칙 그대로 · 문 프롬프트와 같은 문법이라 익숙함
  • 👎 글자가 작고 화면 아래라 첫 눈길이 덜 감

B안 · 작물 위 말풍선

2×2 밭 · 다 자란 작물 머리 위에 말풍선(월드 고정) · HUD 추가 없음

  • 👍 “어디를 누르나”가 가장 직관적 · 시선이 바로 작물로
  • 👎 카메라·캐릭터에 따라 말풍선이 가려질 수 있음 · 새 UI 종류

C안 · 코치 카드

2×3 밭 · 상단 컨텍스트 슬롯에 튜토리얼 코치와 같은 카드 + 액션 버튼 깜빡임

  • 👍 튜토리얼과 같은 모양이라 “안내”로 읽힘 · 문장이 길어도 됨
  • 👎 밭에서 시선이 멀다 · 실제 튜토리얼 코치와 헷갈릴 수 있음
