## 1. 한 장 요약 (슬라이드 문구 재료)

**왜** — 신규의 59%가 2분 안에 떠나고, 그중 56%는 플레이 행동 전이었다. 2분 넘게 머문 사람의 86%도 첫 획득 장소에 못 갔다.
첫 주에 획득한 사람의 2~3주 차 재방문율 15.9% vs 못 한 사람 2.0%.

**가설** — 신규가 **다 자란 작물이 있는 밭 앞에서 시작**하면, 진입 5분 안 첫 획득이 **31% → 50% 이상**으로 오른다.

**설계**
| 항목 | 내용 |
|---|---|
| 무리 | 대조(control) = 지금 그대로 · 처치(harvest_start) = 밭 앞 시작 |
| 배정 | 기기 단위 해시 50:50, 웹·토스 따로(층화) · 재방문해도 같은 무리 |
| 대상 | **신규만** (세이브가 있으면 배정 안 함 — 기존 유저는 변화 없음) |
| 주 지표 | 진입 5분 안 첫 획득(획득 행동 16종) |
| 보조 | 2분 안 이탈 · 7일 안 획득 · 8~21일차 획득한 날 · 플랫폼별 효과 |
| 가드레일 | 7일 재방문 하락 없음 · 세이브 실패 0 · 코인 순증가 튀지 않음 |
| 표본·판정 | 무리당 100명(+19%p, α 0.05, 검정력 80%) 도달 시 한 번 판정 · 최대 12주 · 부트스트랩 95% CI 하한 > 0 이면 채택 |
| 기록 | GA4 `exp_exposure`{exp_arm, first} · 획득 이벤트에 `exp_arm` · session_logs counts `e1_<arm>` |

**일정** — 웹 배포일 = 12주 시계 시작(토스는 검수 승인·출시일부터 합류). **배포일 미정**(아래 6. 남은 일).

사전등록 원본(고정): `git show analytics/metrics-framework:dev/active/metrics-framework/first5min-harvest-experiment-prereg.md`

## 3. `2-emoji/` — 밭 위 말풍선 이모지 비교 → **🌾 선택**

`tap-*`(👆) · `wheat-*`(🌾, **채택**) · `carrot-*`(🥕), 각각 `-pc`·`-mo`.
선택 이유: 도구바 🌾농사·밭 수확 배지와 같은 게임 기호. 월드 말풍선은 글자 없이 이모지만(프로젝트 규칙).

## 4. `3-onboarding-cards/` — 시작 안내 카드 시안 → **선택 대기**

사용자 피드백 "바로 밭으로 가는 건 불친절하다" → 처치에만 카드 3장 추가(사전등록 개정 1, 배포 전).
문구(확정, A안):
1. 🌾 여기는 당신의 텃밭이에요 / 당근이 벌써 다 자랐어요
2. 🕹️ 왼쪽으로 걷고, 오른쪽 버튼으로 해요 (PC: WASD로 걷고, Space·클릭으로 해요)
3. 🥕 첫 수확을 해 볼까요? / 거둔 작물로 마을을 키워요 — [시작하기 🌱]

| 파일 | 시안 | 메모 |
|---|---|---|
| `A-*.jpg` | 가운데 카드(기존 환영 모달 모양) | 밭을 가림 |
| `B-*.jpg` | 아래 시트 | **추천** — 밭·🌾 가 같이 보임 |
| `C-*.jpg` | 위 카드(코치 모양) | 상단 HUD 가림 |

(캡처는 카드 ①만. ②③ 은 같은 틀)

## 5. `0-history/` — 폐기된 첫 시안 (과정 슬라이드용)

`text-bubble-{A,B,C}-{pc,mo}.jpg` — 처음엔 "👆 눌러서 수확하기" **글자** 안내였다(A 프롬프트 줄 · B 작물 위 말풍선 · C 코치 카드).
B 를 골랐지만 "월드 말풍선은 이모지만" 규칙에 따라 글자를 빼고 🌾 로 바꿨다. "글자 → 이모지" 변화를 보여 줄 때 쓴다.
