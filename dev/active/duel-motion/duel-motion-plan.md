# 🎬 밤손님 대결 연출(C안) — 계획

사용자 요청(2026-09-27): "대결 때 아예 화면이 멈춰있는데 어색해, 조금 더 움직이는 모션 보여주면서 다이나믹하게"
→ 선택지 A(숨쉬기)/B(+박자 연출)/C(+카메라 연출) 중 **C** 선택.

## 연출 목록
| 때 | 연출 |
|---|---|
| 무대 내내 | 플레이어·동물 숨쉬기(위아래 + 살짝 찌그러짐, 위상 다름) · 카메라 아주 느린 흔들림 |
| 판 시작(🐗) | 카메라 살짝 줌인 |
| 손 고른 뒤(🐗) | ✊ 둘 다 머리 위 주먹 3번 흔들기(가위바위보!) |
| 공개(🐗) | 손 아이콘 팝(오버슈트) |
| 판 결과 | 이긴 쪽 폴짝 · 진 쪽 움찔(뒤로 밀림) + 화면 흔들림 · 비김은 둘 다 갸웃 |
| 결정타 | 줌 펀치 + 잠깐 느리게(0.35배 · 0.5초) |
| 승부 끝 | 이기면 동물 뒤돌아 후다닥 도망(퇴장) · 지면 동물 신나서 두 번 폴짝 |
| 🦝 그릇 | 맞히면 너구리 움찔·플레이어 폴짝 / 틀리면 반대. 그릇 줌은 기준 카메라 자세를 움직여 흔들림과 충돌 없음 |

## 구조
- `js/duel/motion.js` 순수 곡선(테스트 `tests/duel-motion.test.mjs`)
- `js/duel/stage.js` handle 소유 rAF 루프 + 기준 카메라(handle.cam) 합성, 연출 API
- `js/duel/index.js` 흐름에 연출 호출
- 제약: 모바일 375×812 에서 둘이 안 잘릴 것(줌인 최대 8%) · 하단 카드(~35%) 위에서 반응이 보일 것
- 검증: npm test · 헤드리스 캡처 PC+폰 전/후 프레임 비교 · 대결 흐름 재현 스크립트
