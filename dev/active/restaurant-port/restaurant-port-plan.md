# 식당 + 포구 섬 계획

정본 기획: `docs/superpowers/specs/2026-10-31-restaurant-quest-design.md` (2026-11-09 개정)
구현 1단계 계획: `docs/superpowers/plans/2026-11-10-port-island-stage1.md` (Task 0~15)

## 순서
1. 포구 섬 + 길 안내 모듈 (`js/port/*`, `js/guide/*`)
   - 통배 자유 이동, 등불 부표 항로, 바다 낚시터(가까운·먼·밤), 섬 반지름 20·구역 5, 주민 의뢰 4개, 식재료 창고, 첫 방문 뒤 바로 가기
   - 첫 방문 길 안내 12단계(마을 부두 걷기·배 타기 포함) + `guide_step` 깔때기 이벤트
2. 식당 1차 (`js/restaurant/*`): ★1~★2, 메뉴 3종, 팬·냄비, 평판 패널, DDA, 첫 영업 길 안내
3. 식당 ★3~★4: 서빙 직원·팬 추가·바다 전용 재료 메뉴
4. 후속: ★5~6, 정기 배송, 의뢰 날짜 시드·단골, 유료 장식

## 구현 전 선행
- 식당·포구 섬 해금 = 부엌 서식지 완성(확정)
- 포구 섬 진입 위치 결정(기존 바다터 게이트와 관계)
- 새 문구 전부 선검수
- 마이그레이션(서버 저장) 먼저, 배포는 5곳 동시
