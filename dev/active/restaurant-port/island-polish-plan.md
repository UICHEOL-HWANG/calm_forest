# 포구 섬 다듬기 계획 (2026-11-10)

사용자 요청: 섬 도착 뒤 세팅을 섬세하게. ① 주민·소품 통과 금지 ② 도구바를 마을처럼 ③ 섬 건물이 무엇에 쓰이는지 보이게, 쓰임새 있게 ④ 어묵(포장마차) 의뢰를 포함해 모든 의뢰에 화살표 길 안내.

## A. 섬 HUD (시안 비교 먼저)
- A1 마을 HUD 그대로: 도구바 + 행동 버튼. 섬에서 행동 버튼 아이콘은 상황(💬 말 걸기·✋ 줍기·🛒 사기·🛶 배 타기)으로 바뀐다. 도구 고르기는 그대로 되고 섬에선 도구질 대신 상황 행동이 우선.
- A2 마을 HUD 자리 + 도구바 칸에 "섬 바구니"(잡은 재료 🐟🦐🦑🐚🍚🥬 개수).
- A3 지금 둥근 버튼을 마을 행동 버튼 크기·자리로 맞추고 도구바는 숨김.
- PC·가로 폰 나란히 캡처해 고른 뒤 적용.

## B. 건물 쓰임새
- 모든 건물 앞에 마을과 같은 나무 팻말(이름 + 쓰임 한 줄). 가까이 가면 행동 버튼이 그 건물 행동으로 바뀐다.
- 🏮 포장마차: 이미 있음(코인 30 → 쌀 2·채소 2, 방문당 1회). 팻말·버튼만 보이게.
- 🛖 어부 기둥집: 현재 쓰임 없음 → 제안 "잡은 생선 팔기"(코인) 또는 "생선 상자 맡기기"(식당 재료로 마을에 보냄).
- 🗼 등대: 현재 밤 불빛뿐 → 제안 "밤에 불이 켜지면 밤 낚시터가 열린다"를 팻말로 알리고 부엉이 의뢰(밤)와 연결.
- 🥬 밭: 염소 의뢰 장소. 팻말만.

## C. 의뢰마다 길 안내
- 의뢰를 받으면 같은 길 안내 모듈(createGuide)로 "물건 있는 곳 → 하나씩 줍기 → 주인에게 돌려주기"를 안내. 카드 한 줄 + n/N, 금색 ▼, 가장자리 화살표, 발밑 화살촉, 건물 우회 경유점.
- 4개 의뢰 모두(어부 부표 3·포장마차 조개 4·염소 배추 3·부엉이 기름통 1). 받기 전에는 ❗ 주민 쪽으로 가볍게 안내(첫 섬 방문 12단계가 끝난 뒤).
- 화살표 따라가는 봇으로 4개 의뢰 완주 검증. `guide_step` 이벤트 재사용(가이드 id 로 구분, GA4 새 이벤트 없음).
