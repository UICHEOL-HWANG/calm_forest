# 바다터 낚시 손맛 개선 — 시안 비교

목표: 연타뿐인 바다 낚시를 손맛(1)·챔질(2)·어종별 패턴(3)으로 개선. 핵심 입력 방식이 다른 시안 3개를 sims/ 에 만들어 PC+모바일로 나란히 비교받는다.

- A 연타+예고: 지금 규칙 유지. 점프·❗ 예고로 전환 타이밍이 보인다.
- B 꾹 누르기 텐션: 누르면 감기, 내달릴 때 손 떼기. 장력이 꽉 차면 줄이 끊어진다.
- C 링 타이밍: 버튼에 줄어드는 링이 겹칠 때 탭. 어종마다 박자가 다르다.

공통: 찌 입질 → 챔질 창(어종별 0.42~0.6초) · 헛입질 · 너무 이르면 다시 기다리기 / 화면 흔들림·히트스톱·줄 색·로드 휨·진동·합성음·50/80% 이정표·부두 끝 경고 비네트 / 어종 패턴(전갱이 짧고 잦음·방어 옆으로 내달림·개복치 묵직하게 계속 당김·참치 긴 질주+점프+페인트).

산출물: sims/sea-feel-sim.html (?v=A|B|C&sp=&auto=1&embed=1), sims/sea-feel-compare.html (3열 × PC/모바일, 자동 시연 통계).
범위 밖: js/spaces/sea.js 이식(시안 확정 후), 던지기 스윙 모션(변경 금지).
