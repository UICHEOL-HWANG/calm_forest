# 구글 플레이 출시 — 계획

## 목표
calmforest.cloud (PWA 완료) 를 TWA(AAB) 로 감싸 Google Play 에 출시한다.
패키지명 `com.cheorish.lab.calmforest`. PWA 기반은 2026-09-10 main 병합·라이브 완료.

## 갈래
### A. 사용자(플레이 콘솔) — 내가 못 하는 것
1. Android 10+ 실기기로 기기 액세스 검증 (Play Console 앱) ← **진행 중**
2. 앱 만들기 (이름·기본 언어·게임 분류)
3. AAB 업로드 → **앱 서명 키 SHA-256 지문 전달** ← 병목
4. 스토어 등록정보 입력 · IARC 등급 설문 · 데이터 보안 양식
5. 비공개 테스트(테스터 12명 · 14일) → 정식 출시 신청

### B. 내가 준비 (이 문서의 범위)
1. Android SDK/JDK 툴체인 → Bubblewrap 으로 TWA 프로젝트 + **AAB 빌드**
   - ⚠️ 2026-08-31 부터 신규 앱은 **targetSdk 36 (Android 16)** 필수
   - 업로드 서명 키(keystore) 생성 — 저장소 밖 보관, 절대 커밋 금지
2. **개인정보처리방침** 페이지 (`/privacy`) — 플레이 필수. 실제 수집 데이터 기준으로 작성
3. **스토어 자산** — 폰 스크린샷(최소 2장) · 피처 그래픽 1024×500 · 앱 아이콘 512
4. **설명문** — 짧은 설명 80자 / 자세한 설명 (한국어 기본, 영어 병행)
5. 지문 받으면 `assets/pwa/assetlinks.json` 채워 재배포
