# 🪞 거울 마을 다듬기 (2026-10-09, 사용자 실기기 피드백)
1. 🚏 표지판: 흰 판 테두리가 파란 얼굴 뒤로 튀어나와 보임 → 판도 파랑, 얼굴은 판 표면에 붙임
2. 🚃 출발이 너무 빠름 → 탑승 시간표 늘림(첫 회 5.6→≈7.5s, 이후 2.4→≈3.3s)
3. 🌲 가는 길에 뚫고 지나가는 곳이 많음 → 마차 경로가 정류장 지붕을 넘어가게, 카메라가 나무·바위를 뚫지 않게
4. 🚪 모바일 액션 버튼이 뭔지 모름 → 거울 마을 프롬프트별 아이콘(🪞🚏💬💧🎁), 안내만 있는 줄은 문 버튼으로 바꾸지 않음
5. 🎁 찾으면 대사로 끝 → 주워서 들고 돌아가 주민에게 돌려주면 마무리 대사(주민별 말투) + 보상
