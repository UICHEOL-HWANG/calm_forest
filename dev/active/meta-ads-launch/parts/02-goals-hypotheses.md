# 02. 목표 · 가설

[← 목차](../meta-ads-launch-plan.md) · 결과 보기 전 고정 · 판정 방법은 [07](07-decision-next.md)

## 목표와 성공 기준

| 구분 | 지표 | 정의 |
|---|---|---|
| **1차 (판정)** | 클릭률(CTR) | 광고를 본 횟수 중 누른 비율 |
| 2차 (참고) | 랜딩 조회당 비용 | 쓴 돈 ÷ 웹에 실제로 들어온 수 |
| 2차 (참고) | 첫 플레이율 | 웹에 들어온 사람 중 게임을 시작한 비율 |
| 2차 (참고) | 첫 플레이당 비용 | 쓴 돈 ÷ 게임을 시작한 사람 수 |

- 클릭률은 이겼는데 첫 플레이율이 크게 낮으면(누르기만 하고 안 하는 영상) 채택을 보류한다.
- 예산이 작아서 **두 영상의 클릭률이 30~40% 이상 차이 날 때만** 차이를 확실히 말할 수 있다.

## 표본 추정
1주차 기준: 클릭당 약 500원 가정 → 클릭 약 280건(영상당 140) → 웹 도착 영상당 약 100명. 2·3주차는 그 절반. 세그먼트로 쪼개면 칸당 15~50명 → **세그먼트는 전부 탐색용**, n<30 칸은 숫자만 보고하고 결론 내지 않는다.

## 확인용 가설 (판정함, 주차마다 1개)
주차마다 하나씩, 그 주의 영상 비교만 판정한다. 각 주가 서로 다른 소재 결정이라 따로 판정한다. (2026-10-27 변경: 기존엔 H1 하나만 판정)

| # | 가설 | 지표 | 판정 |
|---|---|---|---|
| **H1** | 1주차에 할로윈 영상이 일반 영상보다 **클릭률이 높다** (기간 한정·새 볼거리가 흥미를 끌어 클릭하게 한다) | 클릭 ÷ 노출 (메타 A/B 리포트) | 10/31 한 번 · 1.0% 대 1.4% 이상 차이만 구분 |
| **H6** | 2주차에 B군(바다터 훅, 10/30 수정 · 원래 설산 또는 수집·도감)이 일반 영상보다 클릭률이 높다 | 클릭 ÷ 노출 | 11/7 한 번 · 1.0% 대 1.5% 이상 |
| **H7** | 3주차에 C군(한정 장식 또는 집 꾸미기)이 그때까지의 승자보다 클릭률이 높다 | 클릭 ÷ 노출 | 11/14 한 번 · 1.0% 대 1.5% 이상 |

공통: 두 비율 비교 검정, 양측, 유의수준 5%. 구분 가능한 차이는 노출 1,000회당 5,000원·기준 클릭률 1%로 계산. 그보다 작게 나오면 "그 이하 차이는 이 예산으로 확인 못 함"으로 기록한다.

## 탐색용 가설 (판정 안 함, 방향만)

| # | 가설 | 지표 |
|---|---|---|
| H2 | 할로윈 영상은 클릭은 많아도 **첫 플레이율은 비슷하거나 낮다** (클릭 낚시 점검) | 첫 플레이 ÷ 웹 도착 |
| H3 | 그래도 **첫 플레이당 비용**은 할로윈 영상이 더 싸다 | 쓴 돈 ÷ 첫 플레이 |
| H4 | 할로윈 영상으로 온 사람은 **유령 정원 입장률**이 더 높다 (광고 내용 → 실제 행동) | hw_enter 입장률 |
| H5 | 앱 설치 배너를 보여 주면 **스토어 이동이 늘어난다** | 배너 노출 vs 10% 미노출 그룹의 스토어 이동률 |

## 세그먼트: 광고를 보기 전에 정해지는 것 (영상 효과 차이로 읽을 수 있음)

| # | 가설 | 지표 · 출처 |
|---|---|---|
| S1 나이 | 할로윈 영상의 우위는 **18~24세에서 더 크다** | 연령대별 클릭률 · 메타 분류 |
| S2 성별 | 영상 우위 방향은 **성별에 따라 다르지 않다** | 성별 클릭률 · 메타 분류 |
| S3 노출 위치 | **릴스가 스토리보다 클릭률이 높고**, 영상 간 우위는 위치와 상관없다 | 위치별 클릭률 · 메타 분류 |
| S4 OS | **iOS는 안드로이드보다 첫 플레이율이 낮다** (기존 탐색: iOS·모바일 2분 안 이탈 50~69%, iOS는 크롬 자동 전환 없이 안내만) | 첫 플레이율 · GA4 UA |
| S5 시간대 | **저녁(18~24시) 유입의 첫 플레이율이 높다** (첫 5분 진단 사후 가설 T1 재확인) | 진입 시각별 첫 플레이율 |

## 세그먼트: 들어온 뒤에 정해지는 것 (누구를 데려왔나만 보여 줌, 인과 X)

| # | 가설 | 지표 |
|---|---|---|
| S6 플레이 스타일 | 두 영상 유입자의 **첫날 스타일 분포가 다르다** (할로윈 = 모으기·꾸미기, 일반 = 농사·낚시 비중 높음) | SG1 6종 행동 비율 |
| S7 맛보기 | 할로윈 유입자의 **'맛보기'(첫날 행동 5개 미만) 비율이 더 높다** | 맛보기 비율 |
| S8 튜토리얼 | 광고 유입자도 **절반 가까이 튜토리얼을 바로 건너뛰고**, 건너뛴 사람은 첫 수확률이 낮다 (사후 가설 S1 재확인) | tutorial_skip 비율 · 첫 수확률 |
| S9 기존 유저 섞임 | 광고 유입자 중 **이미 해 본 사람이 섞이고**, 할로윈 쪽이 더 많다 (픽셀은 10/19부터라 기존 방문자 제외 오디언스를 만들 만큼 쌓이지 않음) | GA4 first_visit 유무 → H1~H3를 신규만으로 다시 계산 |
| S10 이벤트 끝 절벽 | 할로윈 유입자는 **11/2 이후 재방문이 일반 쪽보다 크게 떨어진다** | 11/3~11/9 재방문 비율 |

우선순위: **S4 · S6 · S7 · S9 · S10** (S9는 H1~H3 해석을 바꿀 수 있어 필수, S10은 다음 시즌 소재 결정 근거) · S1~S3은 메타 리포트에서 같이 기록 · S5 · S8은 사후 가설 재확인용.

## 결제(Paddle)까지 도달 가능한가
Paddle 결제는 **웹 + 로그인 + 온라인**일 때만 열린다(`js/shop/paddle.js` 29행). 앱(안드로이드·iOS)·토스에는 결제 링크가 없다.

```
광고 → (인앱 브라우저) → 외부 브라우저 전환 → 웹 도착 → 첫 플레이 → 로그인 → 카페 꾸미기 상점
     → 프리미엄 줄 보기 → 결제창 열기 → 결제 단계 → 결제 완료
```

| # | 가설 · 점검 | 왜 | 지표 |
|---|---|---|---|
| P1 | 광고 유입자 중 **결제창을 연 사람은 극소수(1% 미만)**이고, 대부분은 **로그인 단계에서 끊긴다** | Paddle은 로그인 필수인데, 첫 5분 진단에서 웹 로그인 화면이 장벽(H-N1) | 단계별 도달 인원 |
| P2 | 🎀 꾸미기 가게 구경하기 의뢰(튜토리얼 직후 자동, 미니맵 🎀 안내)를 받은 광고 유입자의 **절반 이상이 가게에 들어가고**, 들어간 사람의 다수가 🌱 새싹반 기본템(50~100🪙)을 산다 | 의뢰 전엔 가게 위치를 못 찾음(페르소나 p29 8/10) · 최저가 600🪙 라 살 게 없었음 → 2026-10-20 의뢰·새싹반 3종 추가 | cos_quest offered→visited→done · cosmetic_buy(새싹반 item_id) |
| P3 | **앱 배너를 눌러 앱으로 간 사람은 결제 경로에서 빠진다** (배너와 결제가 서로 경쟁) | 앱에는 결제 링크가 없음 | 배너 노출 vs 미노출 그룹의 상점 진입·결제창 열기 |
| P4 | 인앱 브라우저에 남은 사람은 결제창 진행이 더 자주 끊긴다 | 웹뷰에서 결제창 동작 미확인 | 브라우저 종류별 paddle_step 최대 단계 |

- 이번 예산으로는 **결제 완료가 0~몇 건**일 가능성이 높다 → 매출이 아니라 **"어느 단계에서 끊기는지"**를 보는 용도.
- P3은 다음 라운드 설계에 영향이 크다: 결제가 목적이면 "앱 유도"와 "웹에 남기기"가 충돌한다.
