# 튜토리얼 = 1장 길 (승인 2026-10-23)

16단계 기능 소개 튜토리얼을 1장 목표(집 → 다리 → 할아버지)를 따라가는 11단계로 바꾼다.

① 걷기 → ② 나무 베기 → ③ 상인 맞이·목재 팔기 → ④ 돌 캐기 → ⑤ 집 바닥 → ⑥ 벽 → ⑦ 밭에서 코인 → ⑧ 지붕
→ ⑨ 🎀 집들이 꾸미기(새싹반 꾸미기 하나 달기) → ⑩ 다리 고치기 → ⑪ 할아버지 만나기

- 낚시·광산 외 시설(시세판·조각·도감·낚시·집 들어가기)은 튜토리얼에서 빼고 처음 갔을 때 배너로.
- 꾸미기 가게 의뢰는 지붕 완성 때 건다(튜토리얼 중엔 배너 없이 의뢰만, 코치가 안내).
- 같이 고친 것: 캐릭터 선택창 도감 토스트, 폰 HUD 배너·의뢰창 겹침.
