# 튜토리얼 = 1장 길 (승인 2026-10-23)

16단계 기능 소개 튜토리얼을 1장 목표(집 → 다리 → 할아버지)를 따라가는 11단계로 바꾼다.

① 걷기 → ② 나무 베기 → ③ 상인 맞이·목재 팔기 → ④ 돌 캐기 → ⑤ 집 바닥 → ⑥ 벽 → ⑦ 밭에서 코인 → ⑧ 지붕
→ ⑨ 🎀 집들이 꾸미기(새싹반 꾸미기 하나 달기) → ⑩ 다리 고치기 → ⑪ 할아버지 만나기

- 낚시·광산 외 시설(시세판·조각·도감·낚시·집 들어가기)은 튜토리얼에서 빼고 처음 갔을 때 배너로.
- 꾸미기 가게 의뢰는 지붕 완성 때 건다(튜토리얼 중엔 배너 없이 의뢰만, 코치가 안내).
- 같이 고친 것: 캐릭터 선택창 도감 토스트, 폰 HUD 배너·의뢰창 겹침.

## 후속: 튜토리얼 잠시 닫기·이어보기 (E1 종료 뒤)

- **즉시 계측:** `tutorial_spot_view`를 음영 단계가 실제 표시될 때 단계별 1회 기록한다. `step`에는 `t_move` 같은 단계 키, `step_index`·`step_count`에는 해당 튜토리얼 묶음 안에서의 순서와 전체 단계를 보낸다. 이는 관측만 추가하며 E1 배정·화면 흐름은 바꾸지 않는다.
- **시점:** E1 첫 5분 수확 실험의 결과를 최종 판정한 뒤 적용한다. 실험이 진행되는 동안에는 대조군·처치군의 튜토리얼 흐름을 바꾸지 않는다.
- **대상:** E1 배정군과 관계없이 신규 이용자 모두에게 같은 규칙을 적용한다. 별도 A/B 군은 만들지 않는다.
- **동작:** 이용자가 튜토리얼에서 `게임 계속`을 누르면 안내를 닫고 플레이를 이어간다. 다음 접속 때 자동으로 튜토리얼을 다시 띄우지 않는다. 원할 때 도움말에서 마지막 진행 단계부터 직접 이어본다.
- **보존:** 튜토리얼 진행 단계는 저장해 재개 위치를 유지한다. 완료한 단계는 다시 반복하지 않는다.
- **이유:** 현재 E1은 일반 시작과 밭 앞 시작을 비교하며, 그 외 흐름은 유지하도록 사전등록되어 있다. 진행 중 변경하면 시작 위치 효과와 튜토리얼 동작 변경이 섞일 수 있다.
