# 첫 실행 시간 측정 (boot_timing)

사용자 결정(2026-11-16): "측정부터". iOS 첫 실행 녹화본에서 플레이까지 약 95초(빈 화면 6초 → 불러오는 중 55초 → 낮 배경 마을 → 남색 6초 → 밤 내 마을).

- 단계 기록: b 부팅 스크립트 · m 게임 모듈 · r 렌더러 · w 마을 · h 집·실내 · n 주민 · x 후처리 · W 로딩 화면 걷힘 · s 셰이더 준비 · L 로그인 화면 · e 플레이 진입 · v 세이브 첫 응답 · P 플레이 시작
- GA4 boot_timing 1회(플레이 시작) + 플레이 전 백그라운드면 부분 1회(reached=bg_<단계>)
- 파라미터 5개: first_run · reached · total_ms · world_ms · steps(0.1초 단위 누적, 100자)
- performance.mark('cf_boot_<k>') 도 남겨 Safari 웹 인스펙터로 기기에서 바로 확인
- 측정 못 하는 구간: 앱 아이콘 → 웹뷰 시작(처음 6초). Xcode/시뮬레이터로 따로 잰다

다음: 앱 빌드 배포 → 첫 실행 데이터 모아 가장 긴 단계부터 줄이기. 화면 전환 정리(사용자 요청 "세련되게")는 시안 비교 뒤.
