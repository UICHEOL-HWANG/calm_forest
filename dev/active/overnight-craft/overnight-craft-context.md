## 함정 (시안에서 이미 겪음 — 반복 금지)

- 몸통을 `0x5a5148` 로 두면 낮에 검게 읽힌다 → `0x9a7358`
- 아궁이 입이 **둘**이면 눈이 되어 얼굴로 보인다 → 하나 + 반대쪽 장작단
- 불을 입구 원통 **안쪽**에 두면 밤에 가려진다 → 입 앞턱
- 밀가루 포대를 **세우면** 도자기·등대가 된다 → 눕혀 쌓고 세그먼트 깎기(2,5)
- 불꽃을 원뿔로 만들면 고깔이다 → `LatheGeometry` 프로필 회전체
- 불똥(Points)은 쓰지 않는다 — 끝에서 동그란 점이 튀어 나가 보인다
- 칩 `min-width` 96px 이면 320px 에서 3칸이 2+1 로 흐른다 → **88px**
- 재료 부족을 문장으로 붙이면 320px 에서 마지막 글자가 떨어진다 → **색으로만**
- `#craft-menu` 를 스크롤 허용 목록에 안 넣으면 모바일에서 창 스크롤이 막힌다
- 캡처할 때 `body.playing` 을 손으로 씌우면 미니맵이 빈 채로 찍힌다 → 실제 진입 후

## 구현하며 드러난 것 (계획과 달랐던 점)

| 계획 | 실제 | 왜 |
|---|---|---|
| `js/save-migrate.js` 의 `migrate()` 수정 | `js/game.js:applySave` + 순수 `sanitizeSlots` | 그 파일은 게스트→정식 이관 전용(34줄), `migrate()` 가 없다 |
| 날짜 키 `YYYYMMDD` | **`YYYY-MM-DD`** | `dayStr(:149)` 형식. 정규식이 실제 저장값을 전부 버려 슬롯이 사라졌다 |
| 슬롯을 화덕에 묶기(`st`) | 슬롯 풀 공유 + 용량만 화덕 수로 | 배치 장식은 고유 id 가 없다(세이브가 `{id,x,z,rot}` 만 복원) |
| 미니게임을 `mgView.type` 부엌 무대에 | 가공 창 오버레이 + **화덕 클로즈업 카메라** | 부엌 무대는 KSET 고정이라 화덕 앞인데 조리대가 보인다 |
| 첫 화덕을 스토리 보상으로 | 시작 시 기본 배치 | 1장 완료가 25명(진입의 23%)뿐 — 성공 기준 40% 미달 |
| 드로우콜 채당 5~6 | **9**(실측) | 팻말 2 + 섀도 패스. 정점색 병합으로 15 → 9 |
| `recipeOf` 그대로 import | `craftRecipeOf` 별칭 | 요리용 `recipeOf(:9813)` 와 충돌 — 게임이 통째로 안 떴다 |

## 2단계에서 더 배운 것 (2026-09-21)

| 틀렸던 것 | 맞는 것 | 왜 |
|---|---|---|
| 배럴을 앞뒤(z)로 눕히기 | **좌우(x)** 로 눕힌다 | 앞뒤로 누이면 정면에서 원만 보여 배흘림이 죽는다 |
| X자 받침 교차점을 통 안에 | 교차점을 **통 아래**로 | 위로 숨기면 X 가 안 보여 다리 네 개가 된다 |
| 받침을 통에서 띄우기 | 통 곡면에서 높이 계산 | 띄우면 다리 달린 짐승이 된다 |
| 소품 밑면을 y=0 에 | `LIFT`(0.02)로 띄운다 | 바닥면과 좌표가 같으면 z-fighting |
| 작은 소품도 castShadow | 섀도맵 텍셀보다 작으면 끈다 | 카메라가 움직일 때 그림자가 지글거린다 |
| 흰 트림을 벽면과 같은 평면에 | 0.015 **밖으로** 내민다 | 같은 평면이면 줄무늬가 어른거린다(📐측량소) |
| 나무를 지울 때 obstacles 만 | `removeSolid(userData.collider)` 도 | 안 보이는 나무가 그대로 서서 길을 막는다 |
