# 고요위키 콘텐츠 보강 (애드센스 "콘텐츠 부족" 대응)

## 목표
- 애드센스가 얇다고 본 고요위키(분류 13 + 문서 81 + 대문)를 게임 데이터 기반 공략 텍스트로 두껍게 만든다.
- 위키 표시명 변경: 강가 줍기 -> 배타기, 땅속 보물 -> 광석 캐기 (분류 ID river/dig, URL 유지. 게임 본편 의뢰 제목 js/quests.js 는 그대로).

## 접근 (사용자 승인: 3번 = 분류 대문 + 개별 문서 동시 보강)
1. 분류 대문: 직접 쓴 공략(5절 안팎) + 하루 루틴 + 자주 하는 실수 + 데이터 계산 절(한눈에·조건별·수치 비교) + 자주 묻는 질문.
2. 개별 문서: 조건 문단 + 데이터 비교 문단 2~4개 + 항목별 팁 + 역링크 문단 + 박물관 문단. 본문 md 는 수정하지 않는다.
3. 대문(/wiki/): 소개, 처음 읽는 순서, 분류별 한 줄 안내.
4. 사실 근거는 wiki/content/*.md 와 loadWiki() facts 만. 코드에 근거 없는 수치·확률은 쓰지 않는다.

## 배포는 하지 않았다
- 작업 트리에 위키와 무관한 미커밋 변경(game.js, index.html 등)이 많아 web 배포 시 같이 나간다. 사용자 확인 후 진행.
