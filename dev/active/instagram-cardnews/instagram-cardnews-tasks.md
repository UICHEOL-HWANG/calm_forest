## Phase 6. 스케줄 — **3일 간격** (사용자 결정 2026-09-11)
"매일매일 업로드는 좀 부담스러울테고 3일에 한번씩으로"

- [x] **KV TTL 7일 → 30일.** 3일 간격이면 큐 N번째 덱은 3N일 뒤에 나간다.
      7일로 두면 큐 3번째(9일 뒤)부터 이미지가 발행 전에 먼저 사라진다.
      덱 하나 ~600KB → 10개 물어도 6MB(KV 무료 1GB).
- [x] **Cron Trigger 배포 완료** (2026-09-11) — `"crons": ["10 0 * * *"]` 매일 09:10 KST.
      `*/3` 같은 day-of-month 식은 월말(31→1)에 간격이 하루로 줄어 쓰지 않았다.
      `functions/cardnews-cron.js` 가 `오늘 - lastPublishedAt >= 3` 을 직접 판정한다.
- [x] **큐 = KV `state` 키 하나.** `{lastPublishedAt, lastSlug, queue:[{slug,caption,urls}]}`
      · 로컬 쓰기 `tools/cardnews/queue.mjs` · 크론 읽기 `cardnews-cron.js` — **같은 키를 두 곳이 쓰므로
        형태를 queue.mjs 주석에 단일 기재**했다.
      · ⚠️ 캡션에 줄바꿈·해시태그·`$`·백틱이 들어간다. 인자로 넘기면 셸이 먹는다 →
        임시파일 + `--path`. **왕복 테스트로 바이트 동일 확인**(42자 그대로).
      · 같은 덱 중복 넣기·이미 발행한 덱 다시 넣기를 거부한다.
