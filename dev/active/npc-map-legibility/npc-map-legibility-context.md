## 의사결정
- **색은 채도를 올리되 hue 를 최대한 벌린다** — 기존 파스텔 6색 중 3명이 "베이지 블롭"으로 뭉쳤다.
  초록/테라코타/보라/파랑/흑백/황금.
- **색만으로는 부족** — 모자 모양이 전부 같으면 색약·역광·야간에 다시 뭉친다. look 별 소품 필수.
- **이름표는 거리 페이드**(11~18) — 항상 띄우면 화면이 시끄럽다. 동물의숲은 이름을 안 띄우지만
  우리 주민은 종이 아니라 직업이라 이름이 필요하다고 판단.
- **이름표 재질은 `fog:false, toneMapped:false`** — 안개·톤매핑이 배지 색을 바래게 하면
  "이 색 = 이 사람" 구분이 통째로 사라진다.
- **미니맵에 한글 지명을 직접 넣지 않는다** — 108px(모바일 82px)에 랜드마크 16곳.
  미니맵은 이모지 아이콘까지, 지명은 탭해서 여는 전체 지도가 맡는다.
- **전체 지도 범위는 지명이 있는 데까지만**(`WM_BOX` x0 -26 / z0 -20 / span 52).
  미니맵의 R=30 을 그대로 쓰면 바다만 넓고 마을 중앙 라벨이 서로 겹쳤다.
- **라벨은 자동 회피** — 아이콘 자리를 먼저 예약하고 18개 후보 오프셋 중 안 겹치는 곳에 놓은 뒤
  캔버스 안으로 clamp. 고정 오프셋으로는 화면 크기마다 겹치는 곳이 생긴다.
- **말풍선 높이** — 이름표 추가로 주민 2.15→2.45, 카페 손님 2.3→2.62 로 올림(겹침 방지).

## 함정
- `updateNPC(dt, t)` 안의 `t` 는 **경과 시간**이지 i18n `t()` 가 아니다. 번역은 스프라이트를 만들 때만.
- `makeCafeGuest` 는 몸 비율이 주민의 0.868배·+0.242 다. 이 매핑을 깨면 모자가 머리에서 뜬다.
- 지명을 추가하면 `js/i18n-en.js` 에도 넣어야 한다(한국어 원문 = 키). `node scripts/i18n_check.mjs` 로 확인.
- `js/game.js` 의 `?farm=1` 디버그 줄은 이 작업 전부터 있던 미커밋 변경이다(내 변경 아님).
