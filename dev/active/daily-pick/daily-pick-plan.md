# 오늘의 꾸미기 (1차 겨울 8종) 계획

승인된 설계 전문: `docs/superpowers/specs/2026-11-20-daily-pick-design.md`

요약
- 꾸미기 가게 맨 위 B안 금빛 카드 1장. 매일 1종(8일 순환, 로컬 날짜 기준, 모두 같은 아이템).
- 새 8종은 오늘의 칸에서만 판매. 앱·토스 광고 배정 그룹은 광고 보면 그날 반값, 웹·대조군은 정가.
- 1차 겨울 8종(캐릭터 4 + 가구 4), 2차 숲 동물 8종은 1차 지표 본 뒤.

순서
1. 겨울 8종 조형 시안(각 3안) → 사용자 선택
2. 데이터·규칙 모듈 + 테스트(TDD)
3. 카탈로그 등록·조형 이식
4. 카드 UI + 광고 연결 + 세이브
5. 측정 이벤트 + 영어 문구
6. PC·모바일 화면 검증 + 코드 리뷰
7. 5곳 동시 배포(사용자 확인 후)
