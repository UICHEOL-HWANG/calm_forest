# C6 로그인 유저 vs 게스트 — 누가 다시 오나 (G0 초안, 결과 보기 전)

**작성** 2026-10-12 · 상태: ✅ G0 서명(2026-10-12) · G1 통과(칸 작음) · 결과가 나와도 기준은 고치지 않는다
연결: `analysis-candidates.md` C6 · E2 실험(웹 로그인 화면 건너뛰기 → 게스트가 늘어남, 가드레일에 '나중 계정 연결 비율') · 첫 5분 R1~R5 와 같은 재방문 정의

## 0. 분석 목적
1. **문제** — E2 는 웹 첫 방문을 로그인 없이 게스트로 시작하게 한다. 게스트가 계정 로그인 유저보다 덜 돌아온다면, E2 로 진입은 늘어도 재방문이 깎일 수 있다
2. **왜 중요한가** — E2 가드레일(7일 재방문)을 읽을 기준선이 없다. 지금 게스트와 계정 유저의 재방문 차이를 알아야 E2 결과에서 '게스트가 늘어서 생긴 차이'를 구분할 수 있다
3. **무엇을 결정하나** — E2 에 '나중 계정 연결 유도'(저장 안내 시점·문구)를 얼마나 무겁게 붙일지
4. **성공 기준** — 진입 시 계정 로그인한 사람과 게스트의 재방문 차이를, 첫 5분 획득으로 층을 나눠서도 숫자로 말할 수 있다
5. **범위 밖** — 인과 판정(로그인은 스스로 고른 것 — 열성 유저가 로그인한다) · 토스(항상 토스 계정으로 자동 로그인이라 비교 불가)

## 3. 미리 밝혀 두는 한계
- **자기 선택 편향** — 로그인을 고른 사람은 처음부터 오래 할 생각이었을 수 있다. C6-b 가 일부만 맞춘다
- **측정 편향(게스트에 불리)** — 계정 유저는 다른 기기로 와도 같은 사람으로 잡히지만, 게스트는 같은 기기·같은 저장소로 와야만 이어진다 → 게스트 재방문이 낮게 잡힌다. 차이가 나도 일부는 이것
- 웹 계정 로그인은 소수일 수 있다 → C6-b 는 방향만이 될 가능성이 큼
