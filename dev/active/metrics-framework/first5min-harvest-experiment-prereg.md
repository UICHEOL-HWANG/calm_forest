# E1 첫 5분 수확 실험 — 사전 기준 (결과 보기 전 고정)

**고정** 2026-10-12 · 사용자 승인(A안 · 웹·토스 둘 다) · 결과가 나와도 아래 기준은 고치지 않는다
근거: `first5min-hypotheses.md` G2 결과 · 분석 목적 `analysis-candidates.md` §0 · 원장 `docs/analysis/ANALYSIS_GATES.md`

## 가설
신규의 59%가 2분 안에 떠나고(B3) 그중 56%는 플레이 행동 전이었으며(B3-a), 2분 넘게 머문 사람의 86%는 획득 장소에 가지 못했기 때문에(B1), **첫 화면을 다 자란 작물이 있는 밭 앞에서 시작**하게 하면 진입 신규의 **5분 안 첫 획득이 31%에서 50% 이상으로** 오를 것이다.

## 처치
| 무리 | 내용 |
|---|---|
| 대조 (A) | 현재 그대로 |
| 처치 (B) | 신규는 게임 첫 화면부터 **다 자란 작물이 있는 밭 앞**에서 시작. 첫 안내는 "눌러서 수확하기" 하나. 그 밖의 흐름(튜토리얼·의뢰·마을)은 바꾸지 않는다 |

## 설계
| 항목 | 내용 |
|---|---|
| 배정 단위 | 기기 — 첫 게임 시작 시 기기 ID 해시로 50:50, 재방문 시 같은 무리 유지 |
| 층화 | 플랫폼(웹·토스)별로 따로 50:50 |
| 대상 | 신규만 (기존 세이브가 있으면 배정하지 않음) |
| 기록 | 배정 직후 GA4 이벤트에 `exp_arm`(control / harvest_start) — **모든 조기 반환보다 먼저 배정**(옛 `variant` 무효 사고 재발 방지) · GA4 파라미터 한도(코드 키 23개) 안에서 기존 키 재사용 |
| 독립성 | 힌트 배너 실험(세션 단위 `arm`)과 별개로 배정 |
| 플랫폼 | 웹 · 토스 (안드로이드·iOS 앱은 플랫폼 태깅이 갖춰지면 별도 결정) |

## 지표
| 구분 | 지표 |
|---|---|
| **주 지표** | 진입 5분 안 첫 획득 (사람 단위, 정의서 §2 의 16가지 행동) |
| 보조 (판정 미사용) | 2분 안 이탈 · 7일 안 획득 · 8~21일차 획득한 날 · 첫 주 두 번째 분야 경험(R3) · 첫 주 코인 사용(R4) · 플랫폼별 효과 |
| 가드레일 | 7일 재방문이 대조보다 떨어지지 않음 · 복구 안 된 세이브 실패 0 · 코인 순증가가 튀지 않음 |

## 표본·기간·판정
- 목표 효과 +19%p (31% → 50%), 양측 α 0.05, 검정력 80% → **무리당 100명** (대조·처치 각 100명)
- 판정은 **무리당 100명 도달 시 한 번만** — 중간에 결과를 보고 멈추지 않는다. **최대 12주** (도달 못 하면 그 시점 표본으로 판정하고 검출 가능 최소 효과를 함께 보고)
- 채택: 처치 − 대조 95% 신뢰구간(사람 단위 부트스트랩 2,000회) 하한 > 0 · 신뢰구간이 0 포함 → 판정 불가 · 상한 < 0 → 처치가 해로움
- 중간 확인(매주): 가드레일과 배정 비율(50:50 이탈 여부, 이항 검정 p < 0.01 이면 배정 오류 점검)만

## 사전에 밝혀 두는 한계
- 메타 광고·스토어 출시로 실험 중 유입 구성이 바뀔 수 있다 → 배정은 무작위라 비교는 유효하지만, 기간별 유입 구성을 함께 보고
- 처치가 첫 획득을 "주는" 구조라 주 지표가 오르는 것은 어느 정도 예상된다 → 진짜 질문은 보조 지표(8~21일차 획득한 날·재방문)가 따라오는지
- 기존 유저에게는 아무 변화가 없어야 한다 (구현 테스트로 보장)
