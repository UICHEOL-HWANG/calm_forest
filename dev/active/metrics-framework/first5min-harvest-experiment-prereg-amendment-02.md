E1 고정(10/12) 뒤에 실험 환경을 바꾸는 일이 두 번 있었다. 둘 다 원본에 적혀 있지 않다.

| 날짜 | 변경 | 커밋 | E1에 미치는 영향 |
|---|---|---|---|
| 2026-10-13 | 웹 → 앱 유도 배너 켬 (`storeLive` android·ios true, 10% 홀드아웃) | `5ff9bb92` | 배너는 첫 `harvest_crop` 직후 뜬다(수확이 없으면 300초 뒤). **처치군은 밭 앞에서 시작해 대조군보다 배너를 더 일찍, 더 많이 본다.** 배너를 눌러 앱으로 간 사람은 웹 재방문에서 빠진다 |
| 2026-10-23 | 온보딩 정리 · 튜토리얼 1장 동선 | `5fec5aa9` · `25da7929` | 두 무리 모두의 첫 세션이 바뀌었다. 무작위 비교는 유효하지만 31% 기저율은 더 이상 맞지 않을 수 있다 |

## 2. 바뀌는 것

| 항목 | 원본 | 개정 |
|---|---|---|
| 가드레일 "7일 재방문" 정의 | 정의 없음 (웹·토스 세션 기준으로 읽힘) | **웹 + 앱 합산 재방문**: 배정 뒤 2~7일차에 웹·토스 세션이 있거나, 같은 `user_id` 의 앱(안드로이드·iOS) 세션이 있으면 재방문. 웹 단독 재방문도 같이 보고하되 가드레일 판정은 합산으로 한다 |
| 연결 못 하는 앱 이동 | — | 게스트가 배너를 누르고 앱에서 다른 계정으로 시작하면 `user_id` 로 이을 수 없다. 이 사람 수(`app_banner_click` 후 웹 재방문 없음)를 무리별로 따로 센다. 이 수가 무리 간에 크게 다르면 합산 재방문도 "하한"으로만 읽는다 |
| 보고 층 (판정 아님, 기술) | 플랫폼별 효과 | 아래 다섯 층을 추가로 보고한다 |

추가 보고 층

| 층 | 나누는 기준 | 이유 |
|---|---|---|
| 배너 노출 | `app_banner_shown` 있음 / 없음 / 홀드아웃(`app_banner_holdout`) | 배너가 처치에 더 많이 뜨는 구조. 웹에서만 해당(배너는 PLATFORM 'web' 전용, 토스 층은 영향 없음) |
| 홀드아웃 층의 처치 − 대조 재방문 | 홀드아웃(배너 안 뜸)인 사람만 | 앱 이동이 섞이지 않은 재방문 비교. 표본이 약 10%라 **방향만** 적는다 |
| 배포 기간 | 배정 시각이 2026-10-23 00:21 KST(`5fec5aa9`) 이전 / 이후 | 첫 세션 구성이 바뀐 경계 |
| 유입 | 첫 접속 `utm_source = meta` / 그 외 | 광고 유입은 기저율이 다를 수 있다 |
| 광고 주차 | `utm_content` 앞부분 `w1_` / `w2_` / `w3_` | 주마다 소재가 바뀐다. 게임 코드는 `utm_term` 을 저장하지 않으므로 광고 이름(`w{주차}_{소재}_v{버전}`)이 들어가는 `utm_content` 에서 뽑는다 |

## 3. 바뀌지 않는 것

- 주 지표(진입 5분 안 첫 획득) · 목표 효과 +19%p · 무리당 100명 · 한 번만 판정 · 최대 12주 · 95% CI 부트스트랩 2,000회 채택 규칙
- 판정은 **층을 나누지 않은 전체 표본**으로 한 번 한다. 10/23 이전 표본도 포함한다
- 배정(기기 해시 50:50, 웹·토스 층화) · 대상(신규만) · 개정 1의 처치 정의(밭 앞 시작 + 안내 카드 3장)
- 나머지 가드레일(복구 안 된 세이브 실패 0 · 코인 순증가)

## 4. 주 지표는 배너 영향이 작다

배너는 첫 수확 **뒤에** 뜨고, 수확이 없을 때의 대체 트리거도 300초(= 5분)라서 "5분 안 첫 획득"이 정해진 뒤에 나온다. 그래서 배너가 주 지표를 직접 바꾸지는 않는다. 영향을 받는 것은 가드레일(재방문)과 보조 지표(7일 안 획득, 8~21일차 획득한 날)다. 보조 지표도 위 배너 층과 함께 보고한다.

## 5. 해석 규칙 (미리 적어 둔다)

| 결과 | 읽는 법 |
|---|---|
| 합산 재방문 가드레일 통과, 웹 단독 재방문만 처치가 낮음 | 처치가 앱 이동을 늘린 것이다. 재방문 손실로 읽지 않는다 |
| 합산 재방문도 처치가 낮음 | 가드레일 실패. 홀드아웃 층 방향을 함께 적는다 |
| 10/23 전·후 층에서 효과 방향이 반대 | 판정은 전체 기준 그대로 두고, "온보딩 변경과 상호작용 가능성"을 한계로 적는다. 사후에 한쪽 기간만 골라 판정하지 않는다 |
| 광고 유입 층과 그 외 층의 효과 크기 차이 | 기술로만 보고. 광고 유입 쪽만 따로 채택하지 않는다 |

## 6. 이유와 승인

- 배너 겹침은 2026-10-13 배너를 켤 때 사용자가 "지금 설계대로 켬"으로 결정하면서 알고 있던 문제다. "E1 분석 때 배너 공변량을 넣고 사전등록 개정에 적는다"는 메모가 있었지만 개정은 쓰이지 않았다. 광고 유입이 들어오기 전에 적는다.
