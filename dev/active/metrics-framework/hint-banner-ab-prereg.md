# 힌트 배너 A/B — 사전 기준 (결과 보기 전 고정)

**고정 시각** 2026-10-08 · 결과가 나와도 아래 기준은 고치지 않는다.

## 실험
- 이탈 예측 모델이 "곧 나갈 것"으로 판단(`churn_events.intervene=true`)하면 treat 세션은 힌트 배너 노출, control 세션은 보류
- 배정: 세션 단위 50:50 (`churn_events.arm`), 기간 2026-09-06 ~ 2026-10-06

## 대상
- 개입 판단이 1번 이상 있는 세션, 배정 그대로 비교 (ITT — 실제 노출 여부와 무관)
- 제외: origin 이 localhost·빈 값 / `variant` beta_A·beta_B / 페르소나 P1 (user_id 중 client_id 4개+ & 첫 등장 ≥ 9/28) / itch
- 관찰 확보: 첫 개입 판단 시각 t0 가 session_logs 마지막 데이터보다 7일 이상 앞선 세션만
- arm 이 섞인 세션(1건) 제외

## 주 지표
- **7일 내 재방문** = 같은 주민(혼합 키: 로그인 세션은 `u:`+user_id, 아니면 `c:`+client_id)이 t0 이후 7일 안에 **다른 세션을 시작**했는가
- 주민 키는 session_logs 의 user_id·is_guest 로 만든다. session_logs 와 연결되지 않는 세션은 client_id 로 센다

## 보조 지표 (판정에 쓰지 않음)
1. 60초 지속: session_logs 최신 `updated_at` − t0 ≥ 60초
2. t0 이후 남은 세션 시간 (분, 중앙값 비교)

## 검정
- 통계량: treat 재방문율 − control 재방문율 (세션 단위)
- **randomization 검정**: 세션별 arm 을 10,000회 무작위로 섞어 양측 p 값 (배정이 세션 단위 독립이므로 유효)
- 95% CI: 주민 단위 클러스터 부트스트랩 2,000회 (한 주민의 여러 세션을 함께 뽑음)
- **판정: p < 0.05 이면 효과 있음 (방향은 부호대로). 아니면 "이 표본으로는 판정 불가" + CI 와 검출 가능 최소 효과 보고**

## 민감도 (판정에 쓰지 않음)
- 주민당 첫 개입 세션 1개만 남긴 결과
