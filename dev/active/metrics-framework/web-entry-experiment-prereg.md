# E2 웹 로그인 화면 건너뛰기 실험 — 사전 기준 (결과 보기 전 고정)

**고정** 2026-10-12 · 사용자 승인(A안 · 주 지표 첫 세션 플레이 행동) · 결과가 나와도 아래 기준은 고치지 않는다
근거: `web-entry-hypotheses.md` G2(판정 불가 — 사후 민감도는 설계 근거로만) · H-N1 G2(토스 자동 로그인이 끊기면 진입 −30%p) · 원장 `docs/analysis/ANALYSIS_GATES.md`
기저율·표본 계산: `validation/e2_baseline.py`

## 가설
웹 첫 방문 기기 중 진입하지 못한 사람의 다수가 로그인 화면에서 0~2초 만에 떠났고(사후 민감도, localhost 제외·한국), 토스는 자동 로그인 덕에 진입 89%를 낸다. 그러므로 **웹 첫 방문 기기를 로그인 화면 없이 바로 게스트로 시작**하게 하면 **첫 세션에 플레이 행동을 한 기기 비율이 31%에서 56% 이상으로** 오를 것이다.

## 처치
| 무리 | 내용 |
|---|---|
| 대조 (A) | 현재 그대로 — 첫 방문 기기는 로그인 화면(Google · 이메일 · 게스트로 둘러보기)을 본다 |
| 처치 (B) | 첫 방문 기기는 로그인 화면 없이 바로 게스트로 시작. 로그인은 기존 저장 안내(`login_nudge`)·메뉴로만 유도. **익명 계정은 첫 입력(이동·탭) 뒤에 만든다** — 크롤러가 계정을 만들지 않게 |

바꾸지 않는 것: 기존 세션이 있는 기기 · 초대 링크 하트핀 흐름(로그인 필요 안내는 처치에서도 유지 방식을 구현 때 정함) · 토스 · 안드로이드/iOS 앱 · itch

## 설계
| 항목 | 내용 |
|---|---|
| 배정 단위 | 기기 — 첫 방문 시 기기 ID 해시(E1 과 다른 솔트)로 50:50, 재방문 시 같은 무리 |
| E1 과의 관계 | 서로 독립 배정(2×2). E1 판정은 E2 무리별로 나눠 함께 보고, E2 판정은 E1 무리를 층으로 함께 보고 |
| 대상 | 웹(`platform` 이 toss·android·ios·itch 가 아님) 첫 방문 기기 · 저장된 세션이 없는 기기만 배정 |
| 분석 모집단 | 배정된 기기 중 **localhost·127.0.0.1 접속 제외 · 국가 한국만** · 페르소나·개발자 계정 제외 (웹 진입 G2 오염 교훈, 데이터 보기 전 고정) |
| 기록 | 사용자 속성 `exp_entry`(control / skip_login) — **로그인 화면 판단보다 먼저 배정**(옛 `variant` 무효 사고 재발 방지) · GA4 이벤트 파라미터 한도와 무관 |
| 분석 방식 | 배정 기준(ITT) — 처치 무리에서 게스트 시작 전에 떠난 기기도 처치로 셈 |

## 지표
| 구분 | 지표 |
|---|---|
| **주 지표** | 첫 세션(첫 방문의 `ga_session_id`)에 플레이 행동 1회 이상 — 씨 뿌리기·물 주기·낚싯대 던지기·바다 던지기·나무 베기·땅 파기·요리 시작·판매 + 획득 16가지 (`e2_baseline.PLAY_E2`). 이동·장소 진입·대화·의뢰·상점 둘러보기 제외 |
| 보조 (판정 미사용) | 방문자 기준 5분 안 첫 획득 · 진입률(처치는 기계적으로 오름 — 참고만) · 첫 세션 길이 · 7일 재방문 |
| 가드레일 | 7일 재방문이 대조보다 떨어지지 않음 · 나중 계정 연결(Google·이메일) 비율 · 익명 계정 생성 속도(주간, 처치 시작 전 4주 대비) · 복구 안 된 세이브 실패 0 |

## 표본·기간·판정
- 기저율 31% (과거 같은 모집단 68대, 9/4~10/11) · 진입한 기기의 플레이 비율 68% = 처치가 닿을 수 있는 천장 근처
- 목표 효과 +25%p (31% → 56%, 천장까지 거리의 약 2/3), 양측 α 0.05, 검정력 80% → **무리당 61대** (합 122대)
- 유입 주 약 13대 → 약 10주. **최대 12주** (도달 못 하면 그 시점 표본으로 판정하고 검출 가능 최소 효과를 함께 보고). 메타 광고가 집행되면 앞당겨짐
- 판정은 **무리당 61대 도달 시 한 번만** — 중간에 결과를 보고 멈추지 않는다
- 채택: 처치 − 대조 95% 신뢰구간(기기 단위 부트스트랩 2,000회, 기기 정렬 후) 하한 > 0 · 0 포함 → 판정 불가 · 상한 < 0 → 처치가 해로움
- 중간 확인(매주): 가드레일과 배정 비율만 (이항 검정 p < 0.01 이면 배정 오류 점검)

## 사전에 밝혀 두는 한계
- 메타 광고가 실험 중 시작되면 유입 구성이 바뀐다 → 배정은 무작위라 비교는 유효, 기간별 유입 구성을 함께 보고
- 국가·접속 주소 필터는 GA4 값 기준 — VPN·해외 거주 한국인은 빠질 수 있다
- 처치는 진입을 기계적으로 올리므로 진입률은 판정에 쓰지 않는다
- 로그인을 미룬 유저는 기기를 바꾸면 세이브가 이어지지 않는다 → 계정 연결 비율을 가드레일로 본다
- 기존 유저·토스·앱에는 아무 변화가 없어야 한다 (구현 테스트로 보장)
