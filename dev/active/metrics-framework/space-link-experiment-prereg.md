# E3 공간 연결 실험 — 사전 기준 (결과 보기 전 고정)

**고정** 2026-10-16 · 사용자 승인(공간 연결 묶음 · 광고 유입으로 A/B) · 결과가 나와도 아래 기준은 고치지 않는다
근거: `validation/space_vs_minigame.py` (탐색, 판정 아님) · 기능 스펙 `dev/active/fish-tank-link/pond-spec.md`
기저율·표본 계산: `validation/e3_baseline.py`

## 가설
첫날 많이 논 신규 중 집을 지은 사람은 7일 안에 38% 돌아왔고 안 지은 사람은 11%였다. 같은 조건에서 미니게임을 한 사람과 안 한 사람은 22% 대 21%로 차이가 없었다(탐색, 자기 선택 섞임). 그러므로 **미니게임의 결과가 내 마을에 눈에 보이게 남으면**(첫 슬라이스: 잡은 물고기가 사는 마당 연못) **첫 물고기를 잡은 신규의 7일 재방문이 32%에서 52% 이상으로** 오를 것이다.

## 처치
| 무리 | 내용 |
|---|---|
| 대조 (`off`) | 지금 그대로 — 물고기는 도감·코인·판매로만 남는다 |
| 처치 (`on`) | **공간 연결 묶음** 켜짐. 시작 시점 내용 = 마당 연못(스펙 §2). 로드맵 2~6번(요리·조각·천문대·밤손님·안개/반딧불)이 배포되면 **처치 무리에만** 더해진다 |

바꾸지 않는 것: 이 배포 전부터 있던 기기(전원 `on`, 배정·분석 제외) · 낚시 난이도·보상·도감 · 대조 무리의 어떤 화면도

## 설계
| 항목 | 내용 |
|---|---|
| 배정 단위 | 기기 — 첫 방문 시 기기 ID 해시(솔트 `e3:`)로 50:50, `localStorage cf_e3` 로 재방문에도 같은 무리 |
| 다른 실험과의 관계 | E1(`e1:`)·E2(`e2:`)와 독립 배정. E3 판정은 E1·E2 무리를 층으로 함께 보고 |
| 대상 | 이 배포 이후 새 기기 · 전 플랫폼 (분석은 GA4 가 있는 웹·토스·안드로이드·iOS) |
| **트리거** | 배정 후 **첫 물고기 획득**(`fishing_catch` 또는 `sea_catch`)한 날 T. 두 무리는 그 순간까지 화면이 똑같으므로 트리거 집단은 편향되지 않는다 |
| 분석 모집단 | 트리거한 배정 기기 · 페르소나·개발자 계정 제외 · localhost·127.0.0.1 접속 제외 · 국가 한국만 (E2 와 같은 규칙, 데이터 보기 전 고정) |
| 기록 | 사용자 속성 `exp_space`(off/on) — 어떤 분기보다 먼저 배정 · 이벤트 `pond_created`·`pond_fish_added`·`pond_view` |
| 분석 방식 | 배정 기준(ITT) — 처치 무리에서 연못을 실제로 안 본 기기도 처치로 셈 |
| 유입 | 메타 광고(웹 경유 단일 깔때기)로 신규를 모은다. 광고 소재·예산은 두 무리에 똑같이 적용되므로 비교는 유효 |

## 지표
| 구분 | 지표 |
|---|---|
| **주 지표** | 트리거 기기의 **T+1~T+7일 중 하루라도 접속** (이벤트 1개 이상, KST 달력일) |
| 보조 (판정 미사용) | 배정된 새 기기 전체의 1~7일차 재방문(희석된 ITT) · 8~21일차 획득한 날 · 트리거 후 7일 안 두 번째 물고기 종 · `pond_view` 횟수(처치만) · 로드맵 배포 시기별 주 지표 |
| 가드레일 | 첫날 획득률(배정 기기)이 대조보다 떨어지지 않음 · 복구 안 된 세이브 실패 0 · 드로우콜 증가 ≤ 15(배포 전 측정) · 배정 비율 |

## 표본·기간·판정
- 기저율 **32%** (트리거 신규 38명, 7/27~10/8, 95% 구간 19~47%) · 웹 27% (26) · 토스 42% (12)
- 목표 효과 **+20%p** (32% → 52%), 양측 α 0.05, 검정력 80% → **무리당 95명** (합 190명)
- 자연 유입으로는 주 1.8명(9/15 이후) → 약 106주. **광고 유입 필수** — 신규 진입 기기의 약 27% 가 트리거하므로 진입 신규 약 700명이 필요
- 기간: 광고 시작일부터 **최대 12주**. 도달 못 하면 그 시점 표본으로 판정하고 검출 가능 최소 효과를 함께 보고
- 성숙 규칙: T+7 이 데이터 마지막 날 이전인 트리거만 센다 (§5-6) — "95명"도 성숙한 트리거 기준
- 판정은 **무리당 95명 도달 시(또는 12주) 한 번만** — 중간에 결과를 보고 멈추지 않는다
- 채택: 처치 − 대조 95% 신뢰구간(기기 단위 부트스트랩 2,000회, 플랫폼 층화, 기기 정렬 후) 하한 > 0 · 0 포함 → 판정 불가 · 상한 < 0 → 처치가 해로움
- 중간 확인(매주): 가드레일과 배정 비율만 (이항 검정 p < 0.01 이면 배정 오류 점검)

## 사전에 밝혀 두는 한계
- **묶음 효과다** — 로드맵 기능이 중간에 처치 무리에 더해지면 판정은 "공간 연결 묶음"의 효과이고 연못 단독 효과가 아니다. 배포 시기별 주 지표는 보조로만 본다
- 트리거가 첫 물고기라서, 물고기를 안 잡는 신규에게 처치가 닿는 경로(이후 요리·조각 연결)는 주 지표에 덜 잡힌다 → 희석 ITT 를 보조로 본다
- 이웃 구경에서 대조 무리 집주인의 연못이 남에게 보일 수 있다 (집주인 본인 화면은 영향 없음)
- 광고 유입은 자연 유입과 구성이 다르다 → 기저율 32% 는 자연 유입 기준. 결과는 광고 유입 신규에 대한 효과로 해석한다
- 국가·접속 주소 필터는 GA4 값 기준 — VPN·해외 거주 한국인은 빠질 수 있다
- 기저율 표본이 38명이라 32% 자체의 불확실성이 크다(19~47%) → 판정은 기저율이 아니라 두 무리의 차이로 한다
