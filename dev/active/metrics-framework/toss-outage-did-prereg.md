# H-N1 토스 인증서 사고 이중차분 — 사전 기준 (결과 보기 전 고정)

**고정** 2026-10-12 · 사용자 서명(G0) · 결과가 나와도 아래 기준은 고치지 않는다
배경: `natural-experiments-timeline.md` 1순위 · 정의서 A1(웹 로그인 장벽) 가설의 첫 근거

## 가설
토스 진입률 89%는 자동 로그인 덕분이다. 자동 로그인이 끊긴 사고 기간에는 토스 신규의 진입률이 떨어졌을 것이다.

## 처치 (자연 발생)
- 2026-09-05 14:13 ~ 09-13 18:30 KST: 토스 mTLS 인증서 삭제 → `anon-key/verify` 가 진짜 키에도 4010 → 신규 토스 기기는 자동 로그인 대신 "바로 플레이하기" 화면을 거쳐 게스트로 시작
- 기존 토스 유저(세션 복원)는 영향 없음 · 웹은 정상

## 판정
- Δ < 0 이고 신뢰구간 상한 < 0 → **지지**
- 신뢰구간이 0 포함 → **이 표본으로 판정 불가** + 검출 가능 최소 효과(MDE) 보고
- Δ > 0 이고 하한 > 0 → **반대 방향**

## 보조 지표 (판정에 쓰지 않음)
1. 진입자의 5분 안 첫 획득
2. 7일 재방문 — 9/13 저녁 "게스트→정식 계정 진행도 이관" 배포가 섞여 해석 한계
