# X2-P 난이도 반응 모델 (페르소나 시뮬레이션 기반) — 사전 기준 (결과 보기 전 고정)

**고정** 2026-10-12 · 사용자 서명 · 결과가 나와도 아래 기준은 고치지 않는다
배경: 난이도 probe(`docs/superpowers/specs/2026-09-22-difficulty-probe-design.md`)는 실제 유저가 게임별 3~5명이라 사람 기준 판정 불가(G1) → 판마다 팔이 무작위로 배정된 페르소나 플레이로 게임별 반응 곡선을 만든다 (사용자 결정)

| 항목 | 내용 |
|---|---|
| 데이터 | 9/23 이후 페르소나 계정(Supabase `auth.users` 이메일 `persona-…`, 목록은 메모리에서만 사용)의 미니게임 판 — 낚시(`fishing_catch`/`fishing_miss`) · 바다(`sea_catch`/`sea_miss`) · 안개(`mist_soothe`/`mist_soothe_miss`, 연습 판 제외) · 요리(단계별 배열을 풀 수 있으면) |
| 단위 | **게임별** 분석 (유저·페르소나 유형별 분해는 하지 않음 — 사용자 결정) |
| 모델 | 게임별 판 단위 로지스틱 회귀 "성공 ~ log(ease)" · `ease` 는 int/double 둘 다 받음 · 낚시는 낚싯대 업그레이드(`rod`) 공변량 |
| 불확실성 | 같은 계정의 판을 묶어 계정 단위 부트스트랩 2,000회 95% CI |
| 판정 | 기울기 CI 하한 > 0 → **손잡이가 작동** · CI 0 포함 → **판정 불가** · 상한 < 0 → **반대** |
| 결정에 쓰는 값 | 손잡이가 작동한 게임은 설계 문서의 목표 성공률이 되는 `ease` 를 회귀선에서 읽어 기본 난이도 상수 이동 제안 |
| 검증 (판정 미사용) | 실제 유저 판(낚시 361·안개 90)이 모델 예측과 같은 방향인지 |
| 보조 (판정 미사용) | 팔별 포기율(`minigame_abandon`) · `probe_v` 1 vs 2 |
| 한계 | 봇은 AI 가 화면을 보고 누르는 방식 → 반응 속도가 사람과 다름 → "시뮬레이션 난이도 곡선"으로만 해석 |
