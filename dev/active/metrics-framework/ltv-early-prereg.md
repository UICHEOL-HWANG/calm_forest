# 참여 LTV 조기 예측 — 첫날 행동으로 28일 가치를 맞힐 수 있나 (G0 초안, 결과 보기 전)

**작성** 2026-10-12 · 상태: ✅ G0 서명(2026-10-12) · G1 통과 · 결과가 나와도 기준은 고치지 않는다 · G1 뒤 고정: 머문 시간·획득 행동 수·세션 수는 log1p 후 표준화
연결: Airflow 예비명단 ④(과금 LTV → 참여 LTV 로 형태 변경, 결제 0 이라서) · 정의서 §5-3 참여 LTV · 첫 5분 진단 · B4 · C6

## 0. 분석 목적
1. **문제** — 참여 LTV(첫 28일 동안 획득한 날)는 신규가 들어오고 4주가 지나야 안다. 광고·실험 판단은 그보다 빨라야 한다
2. **왜 중요한가** — 첫날 행동만으로 28일 가치를 어느 정도 맞힐 수 있다면 ① 광고 채널 비교를 4주 기다리지 않고 첫날 신호로 할 수 있고 ② E1·E2 의 보조 지표("그다음 2~4주에 더 돌아오나")를 일찍 읽을 수 있다
3. **무엇을 결정하나** — 광고·실험 판독에 '첫날 예측 LTV'를 선행 지표로 쓸지 · 쓴다면 어떤 첫날 행동이 신호인지
4. **성공 기준** — 첫날 행동 모델이 '아무것도 안 쓰는 기준'과 '단일 신호 기준'보다 28일 가치를 더 잘 줄 세우는지 교차검증으로 말할 수 있다
5. **범위 밖** — 금전 LTV(결제 0) · 인과(어떤 행동을 시키면 LTV 가 오르나 — 실험의 몫) · 운영 배포(이번엔 모델 판정까지)

## 1. 구조 확인 (결과 아님)
- 첫 진입 7/27~9/13 코호트 160명 (28일 관찰 가능: 9/13 + 28 = 10/11)
- 8~28일차에 획득한 날이 있는 사람 10명 · 1~28일차 25명 · 1~7일차 21명 → 0/1 분류는 양성이 너무 적어 **획득한 날 수를 그대로 예측하는 회귀**로 설계

## 2. 대상·정의
| 항목 | 정의 |
|---|---|
| 대상 | 진입 신규, 첫 진입 2026-07-27 ~ 09-13 (GA4 코호트, 페르소나·개발자 제외, ID 통합 — LTV 와 같은 원천 `ltv_engagement.ga4_person_days`) |
| 목표값 y | **1~28일차 획득한 날 수** (첫날=0일차 제외 → 첫날 행동으로 첫날을 맞히는 동어반복 방지) |
| 특징 (첫날=0일차만) | 첫날 획득한 날 여부 · 첫날 획득 행동 수 · 첫날 분야 수 · 5분 안 첫 획득 · 첫날 세션 수 · 첫날 머문 시간 · 코치(튜토리얼) 시작 · 계정 로그인 진입 · 플랫폼(토스) · 첫날 코인 사용 |
| 모델 | **M0** 평균(아무것도 안 씀) · **M1** 단일 신호(첫날 획득 행동 수) · **M2** 포아송 회귀(위 특징 전부, L2 규제, 규제 세기는 안쪽 교차검증으로) |
| 평가 | 반복 5-겹 교차검증(20회) 밖 예측으로 **스피어만 순위상관**(y 와 예측) · 보조: 상위 20% 예측자가 실제 획득한 날의 몇 %를 차지하나(포착률) · 포아송 이탈도 |

## 3. 가설과 판정 기준 (결과 보기 전 고정)
| # | 가설 | 지지 | 판정 불가 | 반대 |
|---|---|---|---|---|
| **L1** | 첫날 행동 모델(M2)은 28일 가치를 줄 세울 수 있다 | M2 스피어만 > 0 이고 사람 단위 부트스트랩 95% CI 하한 > 0 | CI 가 0 포함 | CI 상한 < 0 |
| **L2** | M2 가 단일 신호(M1)보다 낫다 | 스피어만 차이(M2 − M1) CI 하한 > 0 | CI 가 0 포함 | CI 상한 < 0 |

- 부트스트랩 2,000회(교차검증 밖 예측을 고정한 채 사람을 다시 뽑음, 사람 정렬 후) · y > 0 인 사람 < 30 → **방향만** (현재 25명 → 방향만 예상)
- 특징 중요도(계수)는 보고만, 판정에 쓰지 않음

## 4. 미리 밝혀 두는 한계
- y > 0 이 25명뿐 — 상위 소수(LTV 상위 15%가 74%)가 순위상관을 좌우한다 → 방향만일 가능성이 크다
- 게스트는 다른 기기로 오면 이어지지 않아 y 가 낮게 잡힌다(C6) — 계정 로그인 특징이 이 측정 편향을 일부 학습할 수 있다
- 코호트 기간(7/27~9/13)에 게임이 크게 바뀌었다(코인 첫 루프 9/5 등) → 같은 첫날 행동의 의미가 기간마다 다를 수 있다
- 예측이지 인과가 아니다 — "코치를 시작하게 하면 LTV 가 오른다"로 읽지 않는다
