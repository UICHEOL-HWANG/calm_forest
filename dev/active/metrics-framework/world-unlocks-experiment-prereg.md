# E4 세계수 해금 실험 — 사전 기준 (초안, 미확정)

**초안** 2026-10-17 · 2026-10-18 데이터 분석과 함께 정의 예정 · 아래 수치·기준은 전부 미확정

## 가설 (초안)
신규가 빈 마을에서 시작해 세계수를 살리며 이웃을 되찾는 목표를 가지면(해금 켬) 처음부터 전부 열린 마을(해금 끔)보다 7일 안 재방문이 높아진다. 반대로 시작이 비어 보여 첫날 이탈이 늘 수 있다(가드레일).

## 무리 (초안)
- 대조 `open`: 해금 끔, 전부 열림. 세계수 판·꽃피우기는 선택 콘텐츠
- 처치 `unlocks`: 해금 켬, 이웃·시설이 진행에 따라 돌아옴

## 구현 메모
- 지금은 `CONFIG.UNLOCKS = 'on'` 이 전원에게 켜져 있다 → 새 기기 50:50 배정 스위치 필요(솔트 `e4:`, `unlocks.legacy` 로 무리 고정, E2 `decideE2` 구조 재사용)
- 사용자 속성 `exp_world` + session_logs counts

2. 주 지표(1~7일차 재방문) · 보조 · 가드레일(0일차 이탈 기준)
3. 목표 표본(초안: 무리당 150명, 기저 15%면 검출 최소 약 +11.5%p) · 최대 기간
4. E1·E3 판정을 E4 뒤로 미룰지
