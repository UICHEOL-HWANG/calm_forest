# 메인 퀘스트 노가다 빈 곳에 보상형 광고 붙이기

사용자 요청(2026-11-11): "빈곳에 각각 붙여볼래?" — 단계별 대조 보고에서 광고가 없던 네 곳.

1. 다리 수리(1장 끝, 🪵10 🪨5) — 집터 부족 카드를 장소 목록형으로 넓혀 다리 앞에도 같은 카드+광고
2. 세계수 가지 꾸미기(2~5장) — 판 안 안내 카드 부족 줄 아래 광고 버튼(slot branch_<가지>)
3. 밭 넓히기(6장, 🪵40 🪨20 🪙150) — 측량소 앞 부족 카드+광고(slot farm<단계>)
4. 카페 주문(3장) — 손님 카드 부족 줄 아래 광고 버튼(slot cafe_order)

규칙은 집 카드와 같다: 모자란 만큼, 재료별 상한(🪵10 🪨6 ⚫1 🪙40), 횟수 제한 없음, 50:50 광고 무리만, PREPASS_ON 스위치·애드몹 제공자 조건 그대로.
