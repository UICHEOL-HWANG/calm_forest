## 이 작업이 존재하는 이유

BigQuery 조회에서 **고급 작물 채택률이 0%** 로 확인됐다(2026-09-14~15, 파종 13대 중 고급 0대,
`seed_select` 0건, 고급 씨앗 구매 0건). 상점까지 간 기기는 5대인데 씨앗 도구를 두 번 눌러본
기기가 한 대도 없었다 — 발견 실패지 재미 실패가 아니다.
과수원은 그 위에 "돌아와서 따는 자산"을 얹어 리텐션 구멍을 메운다.

## 좌표 (실측 전 잠정)

- 마을 입구 `ORCHARD_GATE (22, 0, 2)` — 여덟 방향 중 유일하게 빈 정동쪽
- 인스턴스 `ORCHARD (0, 0, 160)` — 텃밭(84)과 광산(250) 사이
- **구현 때 `isBlocked(22,2)` 로 실측하고 결과를 스펙 §1 에 적어 넣을 것**

## 함정 (이미 당한 것들)

1. **worker 라우트 등록** — `functions/api/` 를 신설하면 `worker/index.js` 에 라우트를 같이 등록한다.
   빠뜨리면 404. `dex-notes`·`daily-quests` 가 이것으로 죽었다.
2. **GA4 예약 파라미터** — `source` `medium` `campaign` `term` `content` 금지.
   물 출처는 `method` 로 보낸다. 2026-09-14 에 30일 세션의 38% 가 오염됐다.
3. **식별자 통일** — 자리 번호(`slot:3`)로 종류를 대신하지 않는다. `courier:3` 9건이 복원 불가로 남았다.
4. **세이브 덮어쓰기** — 과수원 필드만 따로 저장하는 길을 새로 만들지 않는다.
   기존 `js/save-guard.js` 경로를 그대로 탄다.
5. **GA4 검증은 다음 날** — export 가 일별이라 당일엔 확인이 안 된다. 배포 다음 날 한 번 더 본다.
6. **드로우콜** — `shared()` 키에 색을 넣어야(`orchard.leaf.mat.${color}`) 재질이 그루마다 새로 안 생긴다.
