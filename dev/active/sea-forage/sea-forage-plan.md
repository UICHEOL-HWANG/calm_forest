## 1단계: 갯벌 캐기 시뮬 (sims/mudflat-dig-sim.html)
- 한 판 = 밀물이 다 차오를 때까지(기본 60초). 물이 바다 쪽에서 천천히, 마지막 15초는 빠르게 밀려옴
- 갯벌 위를 걸어다니며 뽀글거리는 숨구멍 찾기 → 가까이 가서 [캐기]
- 캐기 방식 3시안(?v=A|B|C, 비교 후 하나 선택)
  - A 한 번에 캐기: 탭 1번 → 바로 나옴 (가장 느긋)
  - B 깊이만큼 파기: 숨구멍 크기 = 깊이, 큰 구멍은 여러 번 파야 하지만 큰 조개
  - C 숨 쉴 때 캐기: 거품이 올라오는 순간 탭하면 성공, 놓치면 조개가 한 번 더 숨음
- 어종(가칭): 바지락·꼬막·맛조개·가리비·낙지(희귀). 잔인함 없이 바구니에 담기
- 월드 표시는 이모지만(🫧✨💦), 글자는 HUD 버튼·카드에만
- 결과 카드: 바구니 내용·다시 하기
- 조작: PC 방향키/WASD + 스페이스, 모바일 땅 탭으로 이동 + 오른쪽 아래 캐기 버튼
