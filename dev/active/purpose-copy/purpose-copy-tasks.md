### 검증 함정 기록
- `--top-inset` 은 `body` 에 정의된다(index.html:68). `getComputedStyle(document.documentElement)` 로 읽으면 빈 값이라
  `calc()` 가 무효로 보인다 — 진단이 틀린 것이지 CSS 가 틀린 게 아니다.
- 서비스워커가 오프라인 폴백을 캐시한다. dev 서버가 죽은 뒤 재접속하면 게임 대신 오프라인 카드가 뜬다.
  측정 전 `getRegistrations().unregister()` + `caches.delete()` 필요.
- `#toast` 는 `transition: top .2s` — 측정은 `getComputedStyle().top`(목표값)으로 읽거나 300ms 이상 기다릴 것.
