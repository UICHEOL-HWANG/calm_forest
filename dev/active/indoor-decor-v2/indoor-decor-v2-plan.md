# 실내 꾸미기 v2 — 승인된 계획 (2026-09-09)

베타 피드백(허유빈) 3건 + 사용자 결정으로 확정.

## 배경
- 방 14×14 에 비해 가구가 작아 꾸미기가 허전하다 → 가구 ×1.5 (스크린샷 비교 후 승인)
- 캐릭터가 가구를 통과한다 → 실내 충돌(커밋 48dd47c)
- 놓아둔 가구를 **어떻게 옮기는지** 알 길이 없다 → 근접 프롬프트 + 액션 (이 계획)
- 가구 종류가 적다 → 9종 추가 (문구 검수 완료)
- 철거 대신 **창고 보관** (사용자 결정)

### B. 고스트 따라오기 거리
발 앞 1.3 고정 → `max(1.3, 반깊이 + PLAYER_R + 0.15)` (침대·큰 식탁 돌려 놓을 때 놓는 순간 캐릭터가 튕기던 것 제거)

### C. 옮기기 발견 가능성
1. **근접 프롬프트**: 실내에서 놓아둔 가구 ~1 유닛 안 → 프롬프트 줄에 `🛋️ 소파 · 옮기기`, 액션(Space/오른쪽 버튼) = 들기. 탭으로 드는 경로는 유지.
2. **강조 링**: 프롬프트 대상 가구 밑에 호박색 링(고스트 초록 링과 같은 형태).
3. **첫 배치 직후 안내**: 기존 가구 가이드 ④ "옮기는 법"(6초 카드)이 이미 있음 → 새 토스트를 추가하지 않고 ④ 문구를 새 방법(가까이 가서 버튼)에 맞게 고친다.

### D. 창고 보관
- 상태 `gameState.house.stored = { [id]: n }` (saveGame 이 gameState 통째로 저장 → 자동 포함, applySave 복원만 추가)
- 들고 있는 동안 꾸미기 메뉴 하단 `🧺 보관하기` → 메시·레코드·콜라이더 제거, stored[id]++, 토스트 `🛋️ 소파를 창고에 넣었어요`
- 메뉴 아이템에 `보유 n` 배지, 보유분은 무료 배치(placeDecor free 경로) 후 stored[id]--

## 모바일 제약 (사용자 명시)
안내는 **컨텍스트 슬롯 또는 프롬프트 줄에만**, 새 고정 좌표 금지(memory: mobile-hud-layout).
- 프롬프트 → `ui.setDoorPrompt`(프롬프트 줄, nowrap → 문구 짧게)
- 첫 안내 → 기존 `#decor-guide` 카드(컨텍스트 슬롯) 문구 수정
- 보관 버튼/배지 → 기존 `#decor-menu` 패널 안(스크롤)
- 링 → 월드 공간
