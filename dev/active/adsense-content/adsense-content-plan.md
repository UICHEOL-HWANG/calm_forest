# 애드센스 재신청 준비 (가치 없는 콘텐츠 거절 대응)

## 배경
2026-11-18 애드센스 사이트 검토 거절: "가치가 별로 없는 콘텐츠".
라이브 측정: 첫 화면 보이는 글은 게임 UI 문구뿐. 위키 개별 문서 95쪽은 직접 쓴 본문이 쪽당 평균 207자(최대 366자)이고 나머지는 틀로 찍은 반복 문단.
GA4 10/18 이후 위키 개별 문서 검색 유입은 네이버 1명뿐 → 색인에서 빼도 손해 거의 없음.

## 범위 (사용자 승인: 1~3번)
1. 첫 화면: 위키·안내서 링크는 이미 있음. 소개(/about) 링크만 로그인 화면 링크 줄에 추가.
2. /about 페이지 신설: 만든 사람·만든 이유·문의처·업데이트 소식 경로. SEO_PAGES·sitemap 포함.
3. 위키
   - 개별 문서 95쪽에 noindex + sitemap 제외 (분류 14쪽·대문은 유지)
   - 직접 쓴 긴 공략 글 8편: wiki/articles/<slug>.md → /wiki/guides/<slug>, 대문에 목록, sitemap 포함
   - 글 규칙: 한다체, 숫자·엠대시·"놀다" 금지, [[cat/id]] 링크는 유효한 것만, 사실은 게임 코드로 확인한 것만

## 하지 않는 것
- 첫 화면 게임 UI 변경, 숨김 텍스트(클로킹 위험)
- 위키 개별 문서 삭제(게임 안 링크·내부 링크 유지)
- 배포·재신청(사용자 확인 뒤)
