# E6 안내 개편 실험 사전등록

작성 2026-11-11 · 코드 js/exp-e6.js, js/exp-e6-boot.js

## 무엇을 비교하나
- old(20%): 예전 안내. 목표 화살표·짧은 시점 이동, 2·3장 단계 카드, 집 재료 부족 카드, 세계수 판 안내 카드·추천 줄, 상인 목재 지키기 안내가 모두 꺼진다
- new(80%): 위 안내가 모두 켜진다
- 양쪽 공통(교란 요인으로 기록): 상인이 8초 뒤 플레이어 옆으로 와서 말 걸기, 첫 수확 네 칸까지 말풍선 유지·가입 안내 뒤 튜토리얼, 세계수 판 새 가지 탭 자동 선택, 베타 A군 튜토리얼 순서(집 1단계를 채광 앞으로), 기존 집 안내 실험(hguide), 광고 실험(prepass)의 반복 자리(텃밭·화덕·판매·출석)
- old 군에는 집 재료 부족 카드가 없어서 광고 실험의 집 자리(house1~3)도 없다

## 누구를 넣나
- 배포 뒤 처음 실행한 기기만(client_id 를 이번에 새로 만든 기기). 기존 기기·dev 세션은 실험 밖이고 새 안내를 본다
- 배정은 기기 단위 해시(`e6-guide:` 접두), localStorage `cf_e6` 에 고정
- 광고 실험(`prepass-v1:`)·E3 와 해시가 독립이라 겹쳐도 각각 따로 분석한다

## 기록
- GA4 사용자 속성 `exp_guide` = old | new (이벤트 파라미터 한도와 무관)
- Supabase session_logs counts 에 `e6_old` / `e6_new`

## 지표
- 주 지표: 첫날(설치 당일) 집 3단계(지붕) 완성 기기 비율
- 보조: 2장·3장 도달 비율, D1·D7 재방문
- 가드레일: 첫날 세션 길이, 첫 10분 이탈
- 메타 유입은 유입 경로(UTM·설치 경로)로 따로 잘라 한 번 더 본다

## 판정
- 메타 광고 시작 전에 이 스위치가 먼저 배포돼 있어야 한다
- 표본: 무리별 최소 기기 수는 배포 뒤 일일 신규 수로 다시 계산해 이 문서에 적는다
- 판정 전에 지표·기간을 바꾸지 않는다
