## 3. 장면 (낮/밤 x PC 1280x720@2 / 폰 360x640@3)
스크린샷 8장: `dev/active/halloween-coin-decor/look/part2-ingame-{day,night}-{pc,mobile}-{indoor,outdoor}.png` + 메뉴 2장 `part2-menu-mobile-{decor,outdoor}.png`.
- 실내: 탁자 위 유령 촛불, 바닥 미니 묘비·마녀 솥. 야외: 정원등 2, 묘비 울타리 4, 거미줄 아치.
- 눈으로 본 판정:
  - 촛불 몸체 블룸(낮): 수정 전 emissiveIntensity 0.5 에서 낮 실내에 몸통이 하얗게 날아가고 탁자로 번지는 후광, 얼굴이 흐림 = 명확한 블룸. 0.25 로 낮춤(승인된 조치) → 후광 없음, 눈·입 선명. 밤은 수정 전후 모두 번짐 없음.
  - 정원등: 낮에는 발광 없음, 밤에 청록 등빛이 작게 빛나고 번지지 않음.
  - 면 겹침(z-fighting) 줄무늬: 모든 캡처에서 없음.
  - 그림자 지글거림: 플레이어를 0.06씩 3번 옮겨(카메라 이동) 4장 비교 — 촛불·탁자 모양이 안정적, 지글거림 없음. 단 실내 조명에서 촛불 그림자 자체가 거의 안 보임. 정지 캡처 4장 비교일 뿐 실시간 움직임은 못 봄. 그래서 `NO_SHADOW_DECOR` 는 적용하지 않음.
  - 실내 왼쪽의 반투명 원형 계단 윤곽은 ?house=6 집의 기존 구조(빈 방에서도 동일)이며 할로윈 장식이 아님.
  - 폰 실내: 미니 묘비가 액션 버튼 뒤에 일부 가림(배치 위치 탓, 모델 문제 아님). 폰 밤 야외: NPC 말풍선·대화 버튼이 일부를 가림.

## 5. 묘비 울타리는 방어 울타리가 아님
`gravefence` 4개를 놓은 뒤 `gameState.outdoor.filter(o => o.id === 'fence').length` = 0 → 0(불변). 소스 `js/spaces/night-visit.js:184` 가 `o.id === 'fence' && near(o, 9)` 만 센다 — gravefence 는 id 가 달라 판정에 안 들어감. PASS.

## 6. 세이브 왕복
`__pet.roundTrip()` = `applySave(JSON.parse(JSON.stringify(getGameState())))` 실제 복원 경로를 6종 배치 상태에서 실행. 가구 레코드 5개(침대·탁자·촛불·묘비·솥) 전부 동일 복원, 촛불 y=1.19·onSurface=true 유지. 야외 레코드는 복원 경로가 기존 배열에 덧붙이는 구조(applySave 는 부팅 시 빈 상태 전용)라 같은 페이지 재생에서는 7→14로 두 배가 됨 — 6종 때문이 아닌 기존 동작(야외 전체가 그러함). 한계: 오프라인 게스트라 저장이 서버에 안 나가서 실제 새로고침 후 복원은 검증 못 함 — 직렬화 + 복원 함수 재생까지만 확인.
