## 의존성·함정

- ⚠️ **블룸 임계 0.85** — `0xd9` 초과 색은 후광이 번져 형태를 삼킨다. 금은 색으로만(`metalness 0`)
- ⚠️ **주민 도구**(`js/game.js:11327`)도 같은 `toolMesh` 를 탄다. 등급 인자를 넣을 때 주민은 0단계로 고정하지 않으면 마을 전체가 금빛이 된다
- ⚠️ **드로우콜** — 등급마다 파츠가 는다(2단계는 무늬 링 3 + 보석 1 = +4). 손에 든 도구는 1인분이라 무해하지만, 주민 9명이 들면 곱해진다(위 항목으로 차단)
- ⚠️ `heldToolMesh` 는 도구를 바꿀 때만 다시 만든다 — **업그레이드를 산 직후 손에 든 도구를 갱신**하지 않으면 다음 도구 전환까지 옛 모습이 남는다
- 🌾 밭 확장 7단계(`feat/farm-stage`)가 병합돼 밭이 많아졌다 — "잘 드는 낫"의 가치가 그만큼 크다
- 🔨 목수 증축 체인(main `791eef8`)과 묵직한 망치가 서사로 이어진다
