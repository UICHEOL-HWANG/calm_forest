# 모바일 의뢰·친해지기 아이콘 (C안) · 계획

## 목표
터치 기기에서 왼쪽 위 의뢰 패널(의뢰 카드 + 호감도 카드)이 차지하는 공간을 줄인다. 아이콘 버튼 두 개(의뢰·친해지기)로 바꾸고, 누르면 아래 시트로 카드를 보여 준다. PC는 지금 패널을 그대로 둔다.

## 사용자가 정한 것 (2026-11-14)
- 시안 C: 진행 고리 + 아래 시트.
- 아이콘 스타일 ③ 색 원판 위 아이콘(그린 SVG, 이모지 아님).
- "간격 잘 맞춰줘라": 8px 격자. 버튼 48(고리 4, 원 40, 아이콘 24), 미니맵·버튼 사이 8, 왼쪽 끝 12. 시트 안쪽 16, 탭 44, 탭과 닫기 사이 8.
- 기존·신규 유저 온보딩을 갖춘다.

## 범위
1. 아이콘 버튼 두 개와 아래 시트(의뢰/친해지기 탭, 닫기). `body.is-touch`일 때만.
2. 진행 고리: 의뢰 진행도(초록), 다음 편지까지 호감도(분홍). 배지(진행 숫자, 새 편지 빨간 점).
3. "방금 진행됨" 빛남: 이전 값과 비교해 오르면 3초 빛남 + 주변 살짝 어둡게.
4. 시트는 내용 높이만, 조이스틱 위 8px에서 멈춤. 가로 폰은 가운데 344px 카드. 조이스틱을 잡거나 바깥을 누르면 닫힘.
5. 숨김 규칙: 지금 `#quest-panel`을 숨기는 모든 곳(index.html 여러 곳, yard-guide, sled-hud, neighbors/ui, 음악회)에서 새 버튼과 시트도 숨긴다.
6. 레이아웃: hud-shell.js `layoutLeft()`에서 미니맵을 맨 위, 버튼 둘, 그 아래 이야기 칩.
7. 온보딩: 기존 유저 전환 연출 1회, 신규 유저 의뢰 버튼 소개 1회, 친해지기 버튼 소개 1회. 금색 CSS 화살표 + 한 줄 HUD 안내. 다른 첫 안내와 겹치지 않게 순서(온보딩 전수 조사 결과에 맞춰 확정).
