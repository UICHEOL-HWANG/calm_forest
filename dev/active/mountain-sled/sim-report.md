## 기준 검증

1. 도토리 3개에서 p50(0.3) − p50(0.9) ≥ 1.5초: 39.0 − 36.0 = 3.1초, 통과.
2. 단조성 p50(0.3) > p50(0.6) > p50(0.9) (도토리 3): 39.0 > 36.8 > 36.0, 통과.
3. 도토리 6개 이득(skill 0.7) 3~9초: 6.1초, 통과.
4. 평균 충돌 skill 0.9 < skill 0.3 (도토리 3): 0.04 < 2.84, 통과.
5. 숙련(0.9)·도토리 6 p50 ≥ 30초: 33.4초, 통과.
6. 초보(0.3)·도토리 0 p90 ≤ 60초: 43.0초, 통과.

완벽한 플레이(skill 0.9, 도토리 3 이상)는 충돌 0 에 깃발 12개를 모두 통과한다.

## 조정 내역

- 장애물 중심선 옆 오프셋(course.js): 2.6~3.6 → 0.6~1.0 (교대 부호). 이전에는 장애물이 최적 경로 밖이라 회피 선택이 없었다.
- 깃발 half 폭(course.js): 3 → 2.2. 장애물을 피하느라 벗어난 선이 깃발 선택과 충돌하게 한다.
- PHYS.hitSlowMult: 0.55 → 0.5, PHYS.hitRecoverMs: 900 → 1500. 충돌 한 번의 시간 손실이 약 0.35초라 숙련 차이가 시간에 거의 안 나타났다.
- 물리 테스트(`mountain-sled-physics.test.mjs`)는 수정하지 않았고 모두 통과한다.
- 봇 로직 변경(sled-sim.mjs): 장애물 인지·회피, CLI 가드를 `pathToFileURL` 로 교체.
