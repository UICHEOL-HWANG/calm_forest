## 3. 메모

- **도어 프롬프트**는 기존 규칙(`☕ 카페에 들어가기`·`🏛️ 박물관에 들어가기`)과 같은 모양으로 맞춘 1안을 추천.
- **주문 버튼**: 설계서 초안 `[오늘 밤 빚어 주세요]`는 공백 포함 11자라 버튼 8자 규칙을 넘는다 → `빚어 주세요`(6자) 추천, 맥락("오늘 밤")은 접수 대사가 맡는다.
- **AI 표기**: 스토어 AI 생성물 고지를 겸하므로 "AI"를 반드시 남긴다. 1안은 "밤사이"로 기다림의 이유까지 함께 설명.
- **금칙어 대사**는 무엇이 걸렸는지 말하지 않는다(우회 학습 방지) — 세 후보 모두 동일.
- **대체 레시피 대사**는 실패를 숨기지 않되 "실패" 단어를 쓰지 않는다. 결과가 카드 재료 그대로이므로 1안이 사실과 가장 가깝다.
- **모양 `dot`**: "동글"(추천)은 다른 9종이 사물 이름이라 혼자 형용사처럼 보일 수 있다 — 대안 "빛방울"도 검토 바람.
- **높이 `body`**: "몸 둘레"(4자, 공백 포함)가 모바일 칩 폭에서 가장 길다. 대안 "허리께"는 3자.
- 모바일 폭 실측은 승인된 문구로 Task 8·9 UI 구현 때 시트에 넣어 390px 캡처로 확인한다(이 문서 단계에서는 글자 수로만 1차 거름).
