# 북쪽 물가 넓히기 + 지도 맞추기 (저녁 경매 무대 이전)

2026-11-10 사용자 확정: 시안 `sims/north-expand-compare.html` 의 **안 3 · 연못과 후미 사이 넓히기**.
"넓히면 미니맵이랑 본맵도 싱크 맞춰야겠지?" → 지도도 실제 지형에서 그린다.

## 목표
1. 바다터(입구·후미·등대·돌다리)를 동쪽으로 옮겨 나루터 연못과 후미 사이를 넓히고, 경매 무대를 그 사이로 옮긴다.
2. 옮긴 후미 바깥(북동)까지 걸을 수 있게 걷기 한계를 넓힌다.
3. 미니맵·전체 지도의 섬 모양과 물을 실제 3D 지형과 같은 값에서 그린다. 걷기 한계와 지도가 같은 함수를 쓴다.

## 작업 순서
1. walk-bounds 모듈 + 테스트(경계값·클램프·연속성) → game.js 클램프 교체(halloween-garden-wiring 테스트의 `const maxR = 42` 앵커도 함께 갱신).
2. places.js 이동(SEA_GATE·HOMI_STALL) + auction.js 무대 좌표 + observatory-place 테스트의 하드코딩 좌표 갱신. 기존 테스트(homi-stall·gate-walk·observatory·mountain-place)는 소스값을 읽어 자동 검사.
3. village-map 모듈 + 테스트(지도 물 = 3D 물 상수, 지도 땅 = walkLimit, 모든 VILLAGE_PLACES 가 MAP_VIEW 안·땅 위) → index.html paintIsland·MAP_VIEW 교체.
4. 실게임 검증: 위에서 본 렌더(전/후), 게임 카메라에서 무대·바다터·호미 가게, 돌다리 건너 입장, 호미 가게 프롬프트, 북동 끝까지 걷기, 미니맵·전체 지도 PC+모바일.
5. 리뷰 → 커밋(로컬만). 배포는 경매와 함께 5곳 동시(사용자 승인 후).
