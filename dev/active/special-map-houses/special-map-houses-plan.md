# 특수맵 집 디자인 개선 — 계획

- 거울 마을: 집 3채를 시안 B(거울 지붕집)+C(비튼 2층 탑집) 혼합으로 교체. 1층 + 비튼 2층 + 들린 곡선 지붕 + 거꾸로 뜬 거울 지붕 + 타원 거울 + 아치 문.
- 꿈의 숲: 집이 없던 메인 섬 북쪽에 시안 C(달 탑집) 신축. 장식용(문은 열리지 않음), 원형 충돌체 COTTAGE.
