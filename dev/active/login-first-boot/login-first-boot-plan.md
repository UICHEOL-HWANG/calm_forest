# 로그인 화면 먼저 띄우기 (A+C) — 승인된 계획

배경: iPhone 웹의 14%가 첫 화면 전에 나간다. "고요한 숲 불러오는 중"은 3D 마을 전체(bootWorld, 맥 기준 1.13초 한 덩어리)를 지은 뒤에야 로그인 모듈(Supabase)을 받기 시작한다.

- C: Supabase 모듈을 부팅 맨 처음부터 미리 받는다(한 번만, 실패하면 다음 호출에서 다시)
- A(웹, 저장된 로그인 세션 없음): 인증 → 로그인 화면을 정지 배경(시안 1: 3D 첫 장면 사진 assets/social/login-bg.webp) 위에 먼저 → 그 뒤 3D 마을 짓기 → 다 되면 배경이 3D로 페이드
- 저장된 세션이 있는 재방문자·앱·토스·itch: 지금 순서 유지(마을 먼저), 단 Supabase 는 미리 받는다
- enterPlay 는 마을이 다 지어질 때까지 기다린다(로그인 화면이 먼저 뜨므로)
