# 베타 피드백 r5 — 승인된 계획

출처: 사용자 피드백 4건(2026-09-15). 펫은 **수익화 요소로 보류**(이번 범위 제외).

## A. 작업대 탭 높이 고정 (CSS)
`#cook-menu` 은 바닥 고정 + 높이 auto 라 탭마다 항목 수가 달라지면 창 윗변이 튄다.
- 목록 4개(`#tool-items` 등)에 `min-height` 부여 → 네 탭이 같은 높이
- `#cook-hint` 2줄 고정 → 안내문 줄수 차이로 생기는 잔떨림 제거
- 좁은 화면 미디어쿼리에서 min-height 하향

## B. 퀘스트 패널 — 진행 중 전부 표시 (버그)
`refreshQuestPanel()` 이 `trackedNPC` 한 명만 표시 → A 수락 → B 수락 → B 완료 시
`trackedNPC=null` 로 패널이 비고, A 는 근처로 다시 가야 보인다.
- 수락된 의뢰 **전원**을 배열로 넘김. ✅완료 → 진행률 순 정렬
- 상위 3건(모바일 2건) + "외 N건"
- `trackedNPC` 는 "맨 위 고정" 용도로만 남김
- `ui.setQuest` 는 배열·단일·null 모두 수용(기존 호출부 방어)

## C. 의뢰 있는 주민을 지도에
- `md.npcs` 에 `q: npcGlyph(o)` 한 글자 추가
- 미니맵: `!` 노란 테두리, `✓` 초록 테두리
- 전체 지도: 아이콘 옆 ❗/✅ 배지 + 하단 "📜 의뢰: 이름…" 요약
- i18n 키 추가
