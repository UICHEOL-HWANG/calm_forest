# 게임 목적 전달 + 텍스트 압축

## 배경
베타 피드백: **"이 게임의 목적이 뭔지 모르겠다"**, **"게임 내 텍스트가 너무 길다"**

## 진단
목적 체계는 이미 있다(`STORY` 4장, js/game.js:1232). 전달이 안 될 뿐:
1. 인트로 19초 자막이 분위기만 — 목표도 질문도 없이 마을에 떨궈진다
2. 튜토리얼 17단계가 조작법 나열 — "어떻게"만 있고 "왜"가 없다
3. 그 17단계 내내 `body.coaching`이라 스토리 칩이 `display:none` (index.html:735)
   → 목적을 알려주는 유일한 상시 UI가 초반 30분 동안 꺼져 있다
4. 코치 카드 모바일 폭 213px에 40~71자 → 4~6줄로 터진다

## 범위 (A~D + 압축)
- **A** 인트로 4번째 자막 "그런데 이 잎사귀… 누가 보낸 걸까?" — 4장 회수를 첫 20초에 질문으로 심는다
- **B** 코치 카드 안에 현재 장 목표 줄(`#coach-goal`) 상시 노출 — **새 고정 좌표를 만들지 않는다**(모바일 3단 규칙)
- **C** 인트로 직후 📖 이야기 모달 1회 — 4장 지도를 먼저 보여준다(잠긴 장도 아이콘·제목은 보임)
- **D** TUT_STEPS 문구를 1장 목표에 연결 + 전 문구 압축
- **압축** 코치 ≤30자(2줄), 시설 모달 ≤2줄·줄당 ≤22자, 토스트 ≤30자

## 제약
- 모바일: 컨텍스트 슬롯(12,162)·프롬프트 줄 외 새 자리 금지 → B는 코치 카드 내부에 얹는다
- i18n: 한국어 원문이 사전 키 → 문구가 바뀌면 js/i18n-en.js 키도 같이 바꾼다
- i18n 글루 함정: 조각난 텍스트 뒤 조사는 영어값에 선행 공백 필요
- 문구는 코딩 전 사용자 검수 (ui-copy-review-first)
