# 🐾 펫 4종 확장 + 상점 화면 개편 — 계획

**세운 날:** 2026-09-23

## 목표
펫이 🍃잎사귀 정령 한 종뿐이라 상점에 한 줄만 떠서 "나머지는 해금이냐"는 오해가 난다.
나머지 3종(✨정령·🐦새·🫘흙꼬마)을 게임에 넣고, 고를 수 있게 화면을 바꾼다.

## 단계

### 1. 조형 이식 — `sims/pet-sim.html` → `js/pet/art.js`
시뮬에 3종 조형이 **이미 다 있다**(`buildSpirit`·`buildBird`·`buildGolem`). 옮기기만 한다.
- `PET_PALETTE` 에 세 종의 색을 합친다. **블룸 임계 0.85 검산**을 다시 돌린다.
- `matsFor` 에 `glow`·`film` 추가 — ✨정령 전용이라 지금은 시뮬에만 있다.
- `BUILD` 표를 4종으로. `buildPet(THREE, kind, stage)` 시그니처는 **안 바뀐다**.
- 시뮬은 옮긴 쪽을 import 하게 고친다(복제본을 남기면 갈린다 — 낚싯대 사고).
- ⚠️ ✨정령은 `updatePetAnim` 의 `orbit`/`pulse`/`air`/`ring` 규약을 쓴다 —
  **움직이는 파츠는 병합에서 빼야 한다.**
- ⚠️ 재질별 병합 키에 roughness·metalness 포함(이미 그렇다).
- 검증: 종·단계 12칸 캡처 · 드로우콜 실측 · 무릎 높이 · 실루엣 3단계 구분

### 2. 상점 화면 개편 — 펫 탭에서 4종을 고르게
지금은 안 샀으면 한 줄(`🐾 동행하기`), 샀으면 한 줄(진행도)뿐이다.
- 안 샀을 때: 4종을 줄로 깔고, 줄을 누르면 **프리뷰가 그 종으로 바뀐다**(꾸미기의 "입어보기"와 같은 결).
  고른 종을 사는 버튼 하나.
- 샀을 때: 내 펫의 진행도. 나머지 종은 어떻게 보일지 → **소유 모델 결정 필요**(아래).
- i18n: 종 이름 3개 + 새 문구. 키는 화면에 보이는 한국어 원문 그대로.

### 3. 👣 발자국을 이펙트로 (사용자 지시)
발자국은 몸에 입는 게 아니라 월드 이펙트다. 상점 프리뷰에서 캐릭터 발밑에 두 개 까는 지금 방식
(`makeCharacterPreview` 의 `marks`)이 맞는지 재확인하고, 아니면 이펙트로 보여 준다.
→ **정확한 요구를 사용자에게 다시 확인한다.**

## 열린 결정
- **소유 모델**: 한 마리만 키우는가(구매 시 종 확정), 아니면 종마다 사서 바꿔 데리고 다니는가?
  - 한 마리: 세이브 스키마 그대로(`gameState.pet = {kind, works, ...}`). 3,000🪙 결정이 되돌릴 수 없다.
  - 여러 마리: `pets` 맵 + 마이그레이션 필요. 코인 싱크가 늘고 꾸미기(소유/착용)와 결이 같다.

## 안 하는 것
- 펫 능력 확장 — 성장은 **외형만** 바꾼다(`js/pet/rules.js` 머리말). 종마다 능력을 다르게 하지 않는다.
- 오프라인 정산 — 일꾼 경제가 무너진다.
