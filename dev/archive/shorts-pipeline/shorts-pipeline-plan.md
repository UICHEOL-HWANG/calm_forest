# 🎬 쇼츠 파이프라인 — 계획

## 목표
카드뉴스(3일 1회)에 더해 **쇼츠 릴스를 4일 1회** 자동 발행한다.
생성은 aside 루틴이, 조립·발행은 기존 카드뉴스 인프라가 맡는다.

## 확정된 결정 (2026-09-14)

| 항목 | 결정 | 근거 |
|---|---|---|
| 영상 생성 | **Flow 웹 + aside CLI** (Veo API 아님) | 무료 등급 일 50크레딧, 편당 10 → 월 $0. API 는 월 ~$13 |
| 발행 채널 | **인스타 릴스만** | 기존 IG 토큰 재사용, 새 시크릿 0개 |
| 화풍 유지 | **게임 캡처를 참조 이미지로 업로드** | AI 티·브랜드 이탈 방지. 실측으로 유지 확인됨 |
| 구성 | **Veo 3컷 + 게임 플레이 녹화 꼬리** | 카드뉴스 서사(회사→숲) 이식 + 실물 보증 |
| 주기 | 쇼츠 4일 / 카드뉴스 3일 | 사용자 지정 |
| 승인 | 생성 후 검토 메일 → 사람 승인 → 큐 | 기존 `publish.mjs --queue` 원칙과 동일 |

## 워터마크 (해결 안 됨, 감수하기로 함)
한국은 Flow 출력에 가시 워터마크가 **강제**되고 스위치가 비활성이다.
제거하지 않는다 — 지역 AI 표시 의무이고, SynthID 비가시 워터마크가 따로 박혀
있어 가시 로고만 지워도 인스타의 AI 라벨은 그대로 붙는다.
깨끗한 영상이 필요해지면 Veo API(월 ~$13)로 갈아타는 것이 유일한 경로다.

## 흐름

```
[aside 루틴 · 4일마다]
   shoot.mjs        참조 스틸 캡처 (기존)
   flow.mjs         Flow 생성 → 720p 다운로드      × 3컷
   record.mjs       게임 플레이 녹화 (신규)         × 1컷
   reel.mjs --build ffmpeg 이어붙이기 + 자막 + 리사이즈
        ↓ 검토 메일
   [사람 승인]
        ↓
   publish.mjs --queue   KV 호스팅 + state 큐 (기존 확장)
        ↓
[Cloudflare 크론]  publishReel() — media_type=REELS
```

## 측정값 (2026-09-14 스파이크)

- 크레딧 **10개/편**, 일 50개 → 하루 5편
- 생성 1분 이내 + **큐 대기 별도**(무료 등급, 이날 약 4분)
- 무료 등급 해상도 상한 **720p** (1080p·4K 는 업그레이드 전용)
- 생성 중 reCAPTCHA 안 뜸
- 참조 이미지로 게임 화풍 유지됨 ✅
