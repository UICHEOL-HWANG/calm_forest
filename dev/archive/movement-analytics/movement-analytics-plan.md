# 이동 분석 확장 (2026-10-18)

사용자 승인 순서:
1. **A. 밀도맵 시간대 필터** — 새벽 0–6 · 오전 6–12 · 오후 12–18 · 저녁 18–24. 롤업 표 `cf_heat_slot`(day, slot, map, persona, gx, gz, hits)를 cf_rollup 에서 heat 와 같은 판정으로 채움. RPC `heat_slot` 은 압축 배열 [map, gx, gz, slot, hits]. 화면은 밀도맵에 시간대 버튼(전체=cf_heat_day 전 기간, 시간대=10/12 이후).
2. **B'. 구역 간 이동 흐름** — 마을을 구역(광장·밭·나루터·집·상점 등)으로 나누고 '그 외'를 바다터·설산·실내로 쪼갠다. 구역 → 구역 전이 집계(신규/복귀·이탈/잔존·시간대 분할). **구역 경계 시안을 먼저 보여주고 확정받은 뒤 구현.**
3. **세션 동선 재생** — B'에서 고른 세션만 여는 확인용(관리자 전용, 원본 7일).

배경: 개별 동선만으로는 유저가 많으면 볼 수 없다(사용자 지적) → 집계가 주, 재생은 드릴다운.
