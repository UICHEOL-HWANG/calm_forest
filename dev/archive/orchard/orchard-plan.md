## 승인 경위

2026-09-17 브레인스토밍에서 사용자와 합의해 확정했다.

| 질문 | 결정 |
|---|---|
| 어디에 두나 | 마을 밖 독립 공간 (입구 정동쪽 22,2 · 인스턴스 0,160) |
| 나무를 어떻게 얻나 | 상점에서 묘목 구매 |
| 나무의 성격 | 물을 줘야 열리는 나무 (죽지 않음) |
| 내부 배치 | 자연형 숲 과수원 (오솔길 + 시냇물) |
| 물주기 부담 | 시냇가 면제 + 후반 광역 물조리개 |
| 과일 종류 | 5종 — 사과·배·복숭아·감·밤 |
| 진입 | 해금 (고급 작물 1회 수확) |

사용자 지시 원문: "그것들 유저가 따로 농장을 만드는게 어떠냐", "포도농장 같은 과일농장",
"과수원은 해금으로하고 잠금 처리된 액션에서 해금되면 유저별로 열리는 것도 추가",
"데이터 트래킹 설계 잘해야한다", "스펙 문서로 정리해주고 바로 진행해".
