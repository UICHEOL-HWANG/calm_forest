# 🍳 요리 코스 개편 — 승인된 계획

베타 피드백 4건 + 드로우콜 최적화를 한 번에 처리한다.

## 피드백
1. 요리 미니게임이 너무 어렵다
2. 다양성이 적다 (미니게임 2종뿐)
3. 만든 음식을 직접 보관하고 싶다
4. 카페 안에서도 미니게임을 하고 싶다 (카페 퀘스트 ↔ 요리 연결)
5. 카페 안 NPC가 마을 NPC와 겹친다 (방랑 상인이 밖에도 있고 카페에도 앉아 있음)
6. (추가 요청) 드로우콜 최적화 — 모바일 호환 고려

## 확정된 설계 (사용자 승인: A안 "코스 요리")

### ① 미니게임 4종 + 스테이지 모듈화
| id | 이름 | 입력 | 실패의 모습 |
|---|---|---|---|
| pot | 🍲 끓이기 (기존) | 왕복 바늘을 초록 구간에서 탭 | 구간 밖 |
| chop | 🔪 썰기 (기존) | 흘러오는 노트를 칼 아래서 탭 | 지나침 |
| grill | 🔥 굽기 (신규) | 한 방향 게이지를 "노릇" 구간에서 탭해 뒤집기 ×2~3 | 태움(되돌아올 기회 없음) |
| season | 🧂 간 맞추기 (신규) | **홀드-릴리스** — 누르고 있다가 목표선에서 떼기 | 짜짐/싱거움 |

각 미니게임을 `{ start(cfg), tap(t), release(t), frame(t) } → { pts, judges, offsets }` 인터페이스로 분리하고,
**스테이지 러너**가 코스 순서대로 돌린다. (이 리팩터가 작업의 핵심 — 나머지가 여기 얹힌다)

### ② 코스 = 난이도 (★1~★3)
레시피에 `stages[]`, `diff` 를 싣는다. 난이도는 **판정창 배율로만** 조절.
- ★1 = 1판, ×1.35 (지금보다 확실히 관대 → "너무 어렵다" 해결)
- ★2 = 2판, ×1.15 → ×1.0
- ★3 = 3판, ×1.05 → ×0.95 → ×0.85

같은 판이라도 코스 뒤로 갈수록 좁아지는 것이 "단계별 난이도 상승".
한 단계 망쳐도 코스는 끝까지 진행, 점수만 깎임(뒤 단계 가중치 ↑).
레시피 5종 → 8종으로 늘려 각 미니게임에 배분.

### ③ 음식 아이템화
`gameState.pantry = [{ id, tier, score }]`, **찬장 6칸 한도**.
- 요리 결과 화면: `지금 먹기` / `🧺 보관하기`
- 가방 🍱 탭에서 먹으면 저장 당시 등급 그대로 버프 발동
- 신선도·유통기한 없음 (관리 부담만 늘고 재미 없음)

### ④ 카페 — 그 자리에서 조리 + 손님 캐스트 분리
서빙 3단 분기:
1. 찬장에 주문과 같은 요리 → 미니게임 없이 즉시 서빙 (보관 기능의 실용적 이유)
2. 재료만 있으면 → 그 자리에서 코스 미니게임 → 완성 즉시 서빙
3. 둘 다 없으면 기존 부족 안내

팁 = `CAFE_PAY × tier.mult`. 무대는 주방 세트 재사용 + 배경만 카페 카운터.

**손님 = 마을 주민과 완전 분리.** 외지 손님 캐스트 8명 신설.
> 근본 원인: 주민 6명 중 courier 만 빼고 5명이 손님 풀인데 하루 손님은 4명 —
> 마을 인구의 80%가 매일 카페에 복제된다. 중복 제거로는 못 고친다.
> 주민을 마을에서 빼는 방식은 퀘스트·상점 NPC가 사라져 진행이 막힌다.

새 손님은 도감(`npc` 카테고리)에 등록 → 수집 재미. Gemini 생성기의 `npcs` 목록도 교체.

### ⑤ 드로우콜 (모바일 호환)
- **카페 홀**: 테이블 1세트 14메시 × 4 + 컵 7 + 펜던트 9 + 창·화분 → 재질별 `mergeGeos()`
- **손님**: 서빙마다 재생성 + `disposeTree()` → **풀링(최대 4개 재사용)**.
  dispose 가 사라지니 공유 지오메트리 함정을 피하면서 손님도 병합 가능 (15메시 → 3~4메시)
- **주방 무대**: 정적 파츠 병합. 움직이는 것(칼·국자·거품·불꽃·노트)은 제외
- 홀 펜던트 `PointLight` 3개 → 1개 + emissive
- 신규 무대 소품(grill/season)도 처음부터 병합 전제로 설계
- 측정: `?dbg=1&weather=clear&time=0.32` → `__tp` → `__perf()`, 카페 홀 기준 전후 비교

### ⑥ 문구·i18n
