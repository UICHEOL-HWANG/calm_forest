# 가로 모드 레이아웃 + 튜토리얼 코치 개편 — 계획 (승인 2026-10-14)

## 원인
레이아웃이 폭(640/760)만 보고 폰/PC를 가른다. 폰을 눕히면 폭 844 → PC 배치, 높이는 390 → PC 높이 전제로 짠 창이 넘친다.

## 해결
1. '가로 폰' 모드: `(orientation: landscape) and (max-height: 500px)` 한 조건 (+ JS body.land 필요한 곳만). PC·태블릿·세로 폰 무변경.
2. 공통 규칙
   - 가운데 카드 창(.tut-card 22개·.fb-card·.npc-card): 높이 화면 안, 제목 상단·버튼 하단 고정, 가운데만 스크롤
   - 패널 창(가방·☰·도감·문의·상점·주방·카페·꾸미기…): 시안 비교 후 일괄 적용
   - HUD: 상단 바·자원 바·미니맵 압축, safe-area 좌우(노치)
3. 튜토리얼 코치 개편(17개 점 → 환공포증·폰 불편 피드백): 시안 3개 비교 후 적용, 세로·가로 모두
4. 자동 검사: 헤드리스로 패널 전부 열고 667×375·844×390·915×412(+토스 52px) 넘침/겹침 목록 → before/after 0건
5. 토스: 세로 고정 — ⚙️ '가로 모드' 토글(Screen.setOrientation) 문구 검수 후
6. 실기기 → 4곳 배포(웹·토스·Play·iOS·itch)
