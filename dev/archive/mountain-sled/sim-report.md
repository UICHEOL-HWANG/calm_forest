## 2026-10-16 재조정: 충돌 판정을 화면과 맞춤 (task 10e)

판정이 코스 단위(z)로 이뤄져 화면의 바위보다 z 창이 약 4.7배 좁았다(썰매가 바위를 통과해 보임). 이제 로컬 미터로 판정한다.

- z 거리 × `SLOPE_M_PER_UNIT`(= SLOPE_RUN / COURSE.length = 70/330 ≈ 0.212 m) 로 미터 변환.
- 장애물 반지름 = 그림과 같은 몸통 반지름 `obstacleRadius(o) = o.r × OBSTACLE_BODY[kind]` (바위 0.8, 눈덩이 0.75, 난이도 배율 포함).
- 썰매 몸통 `SLED_HALF = { w: 0.43, l: 0.75 }` 사각형과 원의 겹침으로 판정(이전: |dx|<r, |dz|<r 코스 단위).
- z 판정 창: 약 ±1.1 단위 → 약 ±7.4~7.7 단위. 50 ms 클램프 프레임에서 최고 속도 24 단위/s 로 1.2 단위씩 이동하므로 놓치지 않는다(테스트).
- COURSE_V·PHYS_V 는 1 유지(미출시). 장애물 오프셋·반지름·충돌 페널티는 바꾸지 않았다(기준 6개 모두 통과).

봇 변경(sled-sim.mjs): 장애물 인지·회피 계획을 `hitReach(o)`(판정 창, 코스 단위)로 계산하고, 회피 목표를 절대 x 로 잡으며(중심선이 휘어도 어긋나지 않게), 장애물 앞 깃발은 게이트 안으로 조준한다. `perfectLine()` 은 장애물마다 좌·우를 탐색해 깃발 12개·충돌 0 인 선을 찾는다(테스트 오라클).
