# NPC 식별성 + 지도 지명 라벨 — 승인된 계획

## 배경 (베타 피드백 2건)
1. "NPC 색이나 모습들이 다들 각자 비슷해서 누가 누군지 모른다" → 색으로 구분
2. "지도를 봐도 어디가 어딘지 모르겠다" → 미니맵에 지명 표시
벤치마크: 동물의숲 섬 지도(라벨이 달린 일러스트 맵)

## 현상 (2026-09-09 실측)
- NPCS 6명 중 5명이 동일 메시(정이십면체 몸 + 머리 + 챙모자), 색만 다름.
  게다가 그 색이 전부 저채도 파스텔 — builder(0xd6b48a)/courier(0xb8a98e)/chef(0xe8e4dc)
  가 화면에서 전부 "베이지 블롭"으로 보인다. 이름 표시도 없음(머리 위는 !/…/✓ 글리프뿐).
- 미니맵 108px(모바일 82px)에 마을 랜드마크가 색점으로만 찍힘. 14곳을 구분 불가.

## 승인된 방향 (사용자 선택)
- NPC: **색 + 실루엣 + 이름표** 3종 세트
- 지도: **미니맵 이모지 아이콘 + 탭하면 열리는 전체 지도(한글 지명 라벨)**

## 설계
### A. NPC
1. 채도 높은 고유색 6색(hue 최대 이격) — 게임의 클레이 톤은 유지
   농부 초록 / 목수 테라코타 / 상인 보라 / 낚시꾼 파랑 / 판다 흑백 / 올빼미 황금
2. `def.look` 분기로 실루엣 차별화 (기존 'peddler' 분기 확장)
   - farmer: 넓은 밀짚모자 + 밀짚 끈
   - builder: 안전모 + 어깨 각목
   - angler: 버킷햇 + 낚싯대 + 흰 수염
   - chef: 요리사 토크 + 검은 귀 + 눈 패치(판다)
   - courier: 귀깃 + 날개 + 큰 눈테(올빼미)
   - peddler: 현행 유지
3. 머리 위 이름표 스프라이트 — 거리 16 안에서 페이드 인.
   기존 퀘스트 말풍선은 y 2.15 → 2.45 로 올려 겹침 방지.

### B. 지도
1. 미니맵 마을 뷰: 색점 → 이모지 아이콘. `pri` 로 우선순위를 두어
   모바일(82px)에서는 pri 1 만 그린다(겹침 방지).
2. `#worldmap` 모달 신설 — 캔버스 1장에 섬·호수·길 + 아이콘 + **한글 지명 라벨** + 현재 위치.
   진입: 미니맵 탭 / ☰ 메뉴 "🗺️ 지도".
3. 지명은 i18n 원문 키 규칙에 따라 `t()` 통과 + js/i18n-en.js 에 영문 추가.

## 검증
- 데스크톱/모바일(375px) 양쪽 스크린샷으로 겹침·가독성 확인
- NPC 6명 한 화면 비교 샷
