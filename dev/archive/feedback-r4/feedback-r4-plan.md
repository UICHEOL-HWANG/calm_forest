# 피드백 r4 — 광산·작물 속도·야외 장식 회전

베타 피드백(2026-09-11) 4건 중 3건 처리. 일일퀘스트·카페 미니게임은 사용자가 별도로 신규 제작.

## 1. 광산 우상단 = 광물만 + ⛏️괭이 자동 선택
- 우상단 자원칩: 광산 안에서 🪵🌰🥕 → 🪨⚫💎 로 교체(🪙코인은 유지, 4칸 그대로)
- 광산 진입 시 도구를 ⛏️괭이까지 자동 선택(지금은 🌾농사 '세트'만 자동 전환)
- 광산에서 농사 세트의 다른 도구로 액션 → 괭이로 바꿔 바로 채굴

## 2. 작물 속도 (사용자 확정 수치)
- `WET_TIME` 5 → 9초 (물 주는 간격 = 자라는 속도)
- `WILT_TIME` 22 → 60초 (마른 뒤 시들기까지)
- 성장량(물 3번 = 수확)은 유지

## 3. 야외 장식 회전
- 원인: ↻회전 버튼·R키는 이미 뜨지만 `placeOutdoor` 가 `decorRot` 을 무시 → 눌러도 아무 변화 없음
- 저장 레코드에 `rot` 추가 + 메시 회전 적용 + 복원·들어옮기기에 방향 유지
- 실내 가구와 같은 🫥고스트 미리보기를 야외에도 → "회전이 어떻게 되는지" 눈으로 보이게
